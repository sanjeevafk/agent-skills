# Media Production Skills Collection

A curated collection of programmatic video creation, animation, AI generation, and video editing skills.

## Included Skills

- **remotion-video-creation**: React-based programmatic video rendering and animation.
- **manim-video**: Python vector animations via 3Blue1Brown's Manim mathematical engine.
- **fal-ai-media**: AI text-to-video, audio generation, and media synthesis via Fal.ai APIs.
- **video-editing**: Automated FFmpeg video pipelines, subtitle burning, and clip composition.
- **videodb**: Video indexing, scene search, transcription, and streaming infrastructure.
- **screenshot**: System screen and window capture utility.
- **diagrams**: Scribbly hand-drawn whiteboard visual sketches.
