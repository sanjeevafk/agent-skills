Done. Created `secure_webhook.py` with all vulnerabilities fixed:

**Key security improvements:**

1. **Signature first** — `await request.body()` gets raw bytes; HMAC verified before any JSON parsing
2. **Persistent replay ledger** — Redis `SET NX` with TTL survives restarts and works across workers
3. **Atomic idempotency** — `acquire_idempotency_lock()` uses Redis SET NX to prevent TOCTOU races
4. **Constant-time comparison** — `hmac.compare_digest()` prevents timing attacks
5. **Sanitized errors** — Generic 500 response; details logged server-side only
6. **Secret rotation** — Tries current then previous secret for zero-downtime rotation
