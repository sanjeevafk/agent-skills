### Key Engineering Standards Applied

| Standard | Implementation |
|----------|---------------|
| **Data Types** | `bigint` for IDs, `timestamptz` for timestamps, `text` for strings |
| **Index Design** | Equality-first composites, covering indexes with `INCLUDE`, partial indexes, GIN for JSONB |
| **Lock Safety** | `lock_timeout`, `statement_timeout`, 50ms pause between batches |
| **Keyset Pagination** | `WHERE id > last_id` for O(1) batch processing |
| **Concurrent Indexes** | `CREATE INDEX CONCURRENTLY` - no locks |
| **Migration Safety** | Forward-only, dual-write trigger, idempotent batches |
| **Monitoring** | Control table tracks progress, pg_jobman integration |

```sql

LOCK TABLE audit_logs IN ACCESS EXCLUSIVE MODE;
LOCK TABLE audit_logs_new IN ACCESS EXCLUSIVE MODE;
-- Final sync of any missed rows
```
