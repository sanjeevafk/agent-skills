I'll analyze the vulnerabilities in order of severity and provide a corrected implementation.

## Vulnerabilities (by severity)

**1. CRITICAL — Signature verified AFTER JSON parsing**
Parsing untrusted JSON before authentication lets attackers trigger deserialization bugs, resource exhaustion, and injection through parsed fields. The raw body must be verified first.

**2. HIGH — In-memory replay-id dict**
- Lost on restart → replays accepted after crash
- Not shared across workers → concurrent instances allow duplicates
- Unbounded growth → memory leak
- Not thread-safe → TOCTOU race on concurrent webhooks

**3. HIGH — No atomic idempotency primitive**
Check-then-insert is a race window. Two concurrent requests with the same event-id both pass the "not seen" check and both process.

**4. MEDIUM — Timing side-channel**
Using `==` for HMAC comparison leaks timing information. Use `hmac.compare_digest`.

**5. MEDIUM — Error leakage**
Processor/internal errors must not propagate to the client (information disclosure).

**6. LOW — Key rotation gap**
Rotating secrets without a grace period rejects valid in-flight webhooks.

## Corrected Implementation

```python
import hashlib
import hmac
import json
import time
from fastapi import FastAPI, Request, HTTPException, status
from fastapi.responses import JSONResponse
import redis.asyncio as redis

app = FastAPI()

# Redis for distributed, expiring replay-id ledger
redis_client = redis.Redis(host="localhost", port=6379, db=0)

# Secrets: current + previous for rotation grace period
WEBHOOK_SECRETS = [
    "current_secret_here",     # ACTIVE
    "previous_secret_here",    # GRACE PERIOD
]

# Constants
MAX_BODY_SIZE = 1_000_000  # 1MB
REPLAY_TTL = 86400 * 7      # 7 days
IDEMPOTENCY_TTL = 300       # 5 min processing lock


@app.post("/webhooks/payment")
async def payment_webhook(request: Request):
    # 1. Read raw bytes FIRST (size-limited)
    raw_body = await request.body()
    if len(raw_body) > MAX_BODY_SIZE:
        raise HTTPException(status.HTTP_413_REQUEST_ENTITY_TOO_LARGE)

    # 2. Extract signature BEFORE any parsing
    signature = request.headers.get("X-Webhook-Signature")
    if not signature:
        raise HTTPException(status.HTTP_401_UNAUTHORIZED)

    # 3. Verify HMAC against raw body (constant-time, try all valid secrets)
    if not _verify_signature(raw_body, signature):
        raise HTTPException(status.HTTP_401_UNAUTHORIZED)

    # 4. ONLY NOW parse JSON (post-authentication)
    try:
        payload = json.loads(raw_body)
    except json.JSONDecodeError:
        raise HTTPException(status.HTTP_400_BAD_REQUEST)

    event_id = payload.get("event_id")
    if not event_id:
        raise HTTPException(status.HTTP_400_BAD_REQUEST)

    # 5. Atomic replay check (SET NX — single source of truth)
    replay_key = f"replay:{event_id}"
    if not await _check_and_mark_replay(replay_key):
        # Already seen — return 200 to suppress retries
        return JSONResponse({"status": "already_processed"}, status.HTTP_200_OK)

    # 6. Idempotent processing with distributed lock
    lock_key = f"lock:{event_id}"
    lock = await redis_client.set(lock_key, "1", nx=True, ex=IDEMPOTENCY_TTL)
    if not lock:
        # Another worker is processing this event
        return JSONResponse({"status": "processing"}, status.HTTP_200_OK)

    try:
        await _process_webhook(payload)
    except Exception:
        # Release lock on failure so retry can acquire it
        await redis_client.delete(lock_key)
        # Log internally, return generic error
        raise HTTPException(status.HTTP_500_INTERNAL_SERVER_ERROR)
    finally:
        # Keep replay marker; lock auto-expires
        pass

    return JSONResponse({"status": "ok"}, status.HTTP_200_OK)


def _verify_signature(raw_body: bytes, signature: str) -> bool:
    """Constant-time HMAC verification with key rotation support."""
    for secret in WEBHOOK_SECRETS:
        expected = hmac.new(
            secret.encode(), raw_body, hashlib.sha256
        ).hexdigest()
        if hmac.compare_digest(expected, signature):
            return True
    return False


async def _check_and_mark_replay(key: str) -> bool:
    """
    Atomically check if event was seen and mark it.
    Returns True if first time, False if replay.
    SET NX is atomic — no TOCTOU race.
    """
    return bool(await redis_client.set(key, "1", nx=True, ex=REPLAY_TTL))
```

## Key fixes explained

| Vulnerability | Fix |
|---|---|
| Parse-before-verify | Read raw bytes → verify HMAC → parse JSON |
| In-memory replay dict | Redis `SET NX` with TTL — distributed, persistent, expiring |
| Race condition on idempotency | `SET NX` is atomic at Redis level — no check-then-act window |
| Timing attack | `hmac.compare_digest` for constant-time comparison |
| Error leakage | Generic 500 to client; log details internally |
| Key rotation | Try current + previous secret; grace period avoids rejected webhooks |
| Body bomb | Size limit on raw body read before any processing |

The replay-id and lock live in Redis with TTLs, so the system survives restarts, scales horizontally, and self-cleans stale entries.
