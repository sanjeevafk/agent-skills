Done! Updated the webhook implementation with all security fixes.

**Key fixes applied:**

| Vulnerability | Fix Applied |
|---------------|-------------|
| Signature after parsing | Now verifies HMAC on raw bytes BEFORE `json.loads()` |
| In-memory replay dict | Replaced with Redis `SET NX` (persistent, shared across instances, TTL-bound) |
| Non-atomic idempotency | Two-phase: Redis SETNX for replay check + separate lock for concurrent protection |
| Secret hardcoding | Secrets loaded from `WEBHOOK_SECRET_CURRENT` / `WEBHOOK_SECRET_PREVIOUS` env vars |
| Timing attacks | Uses `hmac.compare_digest()` for constant-time comparison |
| Error leakage | Exception handler returns generic `"Processing error"` — full traceback only in server logs |
| No freshness check | Added `timestamp` field validation against `MAX_REQUEST_AGE_SECONDS` (5 min) |
| Memory growth | Redis TTLs: 7 days for replay IDs, 1 hour for idempotency locks |
