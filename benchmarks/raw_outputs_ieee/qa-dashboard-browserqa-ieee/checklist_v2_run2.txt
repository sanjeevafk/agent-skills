## Phase 1: Smoke Test — Read-Only Crawl

### Objective
Collect all console errors, network failures, and CWV metrics across every public page — zero user interaction required.

### Approach
A single-headed browser instance navigates a sitemap, captures console messages, monitors the request lifecycle, and runs the built-in Performance API for CWVs. All assertions run inside the test runner; nothing mutates state.

```typescript
// ─── tests/e2e/smoke/dashboard-smoke.spec.ts ───────────────
import { test, expect } from '@playwright/test';

type ConsoleMessage = { type: string; text: string; pageUrl: string };
type NetworkFail = { url: string; status: number; method: string };

test.describe('Smoke — Analytics Dashboard', () => {
  // ---- fixtures -------------------------------------------------------
  let consoleErrors: ConsoleMessage[] = [];
  let consoleWarnings: ConsoleMessage[] = [];
  let networkFails: NetworkFail[] = [];
  let cwvLcp: number | null = null;
  let cwvCls: number | null = null;
  let cwvInp: number | null = null;

  test.beforeEach(async ({ page }) => {
    // Listen to console at page level — do NOT use page.on('console')
    // inside async hooks because they fire after beforeEach resolves.
    // Instead, collect via the dedicated event listener attached below.
    consoleErrors = [];
    consoleWarnings = [];
    networkFails = [];
    cwvLcp = null;
    cwvCls = null;
    cwvInp = null;
  });

  // ---- helpers --------------------------------------------------------
  const isNoise = (text: string) =>
    /analytics|google-tagmanager|gtag|fbq|hotjar|intercom|segment/i.test(text);

  const criticalConsolePatterns = [
    /Error:/i, /TypeError:/i, /ReferenceError:/i,
    /Uncaught/i, /Failed to parse/i, /Module build failed/i,
    /Cannot read properties of undefined/i,
    /React Error Boundary/i,
  ];

  // ---- suite-level navigation -----------------------------------------
  test('smoke crawl collects diagnostics from all key pages', async ({
    page,
  }) => {
    const urls = await extractPageUrls(page); // sees sitemap / nav links

    for (const url of urls) {
      await page.goto(url, { waitUntil: 'networkidle' });

      // -- console capture --
      const pageConsoleEvents: { type: string; text: string }[] = [];
      page.on('console', (msg) => {
        const entry = { type: msg.type(), text: msg.text() };
        pageConsoleEvents.push(entry);
      });

      // Wait briefly so late-rendered logs appear
      await page.waitForTimeout(1_000);

      for (const ev of pageConsoleEvents) {
        if (isNoise(ev.text)) continue;
        const entry: ConsoleMessage = {
          type: ev.type,
          text: ev.text,
          pageUrl: page.url(),
        };
        if (ev.type() === 'error') consoleErrors.push(entry);
        else if (ev.type() === 'warning') consoleWarnings.push(entry);
      }

      // -- network failure capture --
      // Each frame gets its own request tracking
      const responses: ResponseWithStatus[] = [];
      page.on('response', (r) => {
        if (!r.ok()) {
          networkFails.push({
            url: r.url(),
            status: r.status(),
            method: r.request().method(),
          });
        }
      });

      // -- Core Web Vitals (Performance API) --
      const vitals = await page.evaluate(async () => {
        // @ts-ignore — navigator.metrics exists in Chromium
        const m = (navigator as any).metrics;
        return {
          lcp: m ? m.get('largest-contentful-paint') : null,
          cls: m ? m.get('cumulative-layout-shift') : null,
          inp: m ? m.get('interaction-to-next-paint') : null,
        };
      });

      // Fallback: classic PerformanceObserver approach
      const fallback = await page.evaluate(() => {
        const entries = performance.getEntriesByType('paint');
        const lcpEntry = performance.getEntriesByType('largest-contentful-paint') as any[];
        const clsEntries = performance.getEntriesByType('layout-shift') as any[];

        let lcp = null;
        let cls = 0;

        if (lcpEntry?.length) lcp = Math.max(...lcpEntry.map((e) => e.startTime));
        cls = clsEntries.reduce((sum, e) => sum + (e.value || 0), 0);

        return { lcp, cls };
      });

      cwvLcp = fallback.lcp ?? vitals.lcp?.valueMs ?? null;
      cwvCls = fallback.cls ?? vitals.cls?.value ?? null;
      cwvInp = vitals.inp?.valueMs ?? null;
    }

    // ---- assertions -----------------------------------------------------
    const criticalErrors = consoleErrors.filter(
      (e) => !criticalConsolePatterns.some((p) => p.test(e.text)),
    );

    // Report summary
    console.log(`\n=== SMOKE SUMMARY (${urls.length} pages) ===`);
    console.log(
      `Console errors: ${consoleErrors.length - criticalErrors.length} filtered, ${criticalErrors.length} critical`,
    );
    console.log(`Console warnings: ${consoleWarnings.length}`);
    console.log(`Network failures: ${networkFails.length}`);
    console.log(`LCP: ${cwvLcp ? `${cwvLcp}ms` : 'N/A'}`);
    console.log(`CLS: ${cwvCls ?? 'N/A'}`);
    console.log(`INP: ${cwvInp ? `${cwvInp}ms` : 'N/A'}\n`);

    // Assert — fail hard on real problems
    expect(criticalErrors.length, 'no critical console errors').toBe(0);
    expect(networkFails.length, 'no non-2xx/3xx network requests').toBe(0);

    if (cwvLcp !== null) {
      expect(cwvLcp, 'LCP under 2500ms').toBeLessThan(2500);
    }
    if (cwvCls !== null) {
      expect(cwvCls, 'CLS under 0.1').toBeLessThan(0.1);
    }
    if (cwvInp !== null) {
      expect(cwvInp, 'INP under 200ms').toBeLessThan(200);
    }
  });
});
```

## Phase 2: Interaction Tests — Filters & Drill-Downs

### Objective
Verify every interactive element works: date range pickers, dimension selectors, table sort/paginate, chart click-to-drill, toggle switches. Nothing writes data.

### Blast-Radius Rules — What Never Gets Clicked

```
BLOCKED ACTIONS (read-only only):
  ✗ Submitting search forms (use readonly query params instead)
  ✗ Opening auth flows (login/logout/signup/register/reset)
  ✗ Export buttons (CSV/PDF/JSON — triggers downloads, side effects)
  ✗ Share links (opens modals, may trigger OAuth redirects)
  ✗ Settings/preferences save (writes to DB)
  ✗ Delete/archive any data rows
  ✗ Notification center interactions
  ✗ Chat/support widget opens
  ✗ Any button that triggers a POST/PATCH/DELETE in DevTools Network panel
```

These rules are enforced programmatically:

```typescript
// tests/e2e/helpers/safety-guard.ts
import { Page } from '@playwright/test';

/**
 * Intercepts outgoing XHR/fetch and blocks any mutation request.
 * Attach to a page before interaction tests begin.
 */
export function installMutationGuard(page: Page): void {
  const blockedUrls: string[] = [];

  page.on('request', async (request) => {
    const method = request.method().toUpperCase();
    const isMutation = ['POST', 'PUT', 'PATCH', 'DELETE'].includes(method);
    const isDataEndpoint = /\/api\/(create|update|delete|submit|save|export|share)/i.test(
      request.url(),
    );

    if (isMutation && isDataEndpoint) {
      // Allow if explicitly overridden (staging opt-in)
      if (process.env.DANGER_MODE !== '1') {
        blockedUrls.push(`${method} ${request.url()}`);
        await request.abort('aborted');
      }
    }
  });

  page.on('response', (response) => {
    if (blockedUrls.length > 0 && response.status() >= 400) {
      console.warn(`[mutation-guard] Blocked ${blockedUrls.length} mutation(s)`);
    }
  });

  // Return a reporter so tests can assert nothing was blocked accidentally
  return {
    getBlocked() {
      return [...blockedUrls];
    },
    reset() {
      blockedUrls.length = 0;
    },
  };
}
```

## Phase 3: Visual Regression

### Strategy

Capture screenshots at three breakpoints. Compare against committed baselines using a masked comparison that ignores time-sensitive elements (live clocks, relative timestamps, animated charts). Default acceptance threshold: 0.1% pixel diff.

### Visual Regressions Spec

```typescript
// tests/e2e/regression/visual-regression.spec.ts
import { test, expect } from '@playwright/test';

type ViewportConfig = { name: string; width: number; height: number };

const VIEWPORTS: ViewportConfig[] = [
  { name: 'desktop', width: 1440, height: 900 },
  { name: 'tablet', width: 768, height: 1024 },
  { name: 'mobile', width: 390, height: 844 },
];

const DIFF_THRESHOLD = 0.001; // 0.1%

test.describe('Visual Regression — Analytics Dashboard', () => {
  const BASE_URL = process.env.BASE_URL || 'http://localhost:3000';

  // Mask configuration — selectors whose pixels should be ignored
  // during visual diff comparison.
  const TIME_MASKS = [
    '[data-testid="live-clock"]',
    '[data-testid="timestamp"]',
    '[data-testid="relative-time"]',
    '.chart-tooltip-dynamic',
    '.animated-count-up',
  ];

  // Dark mode variants — same page, different CSS class on <html>
  const THEMES = ['light', 'dark'] as const;

  /**
   * Masks dynamic regions by overlaying solid rectangles, then
   * proceeds with the screenshot. This turns time-dependent areas
   * into "don't care" zones for the image diff engine.
   */
  async function maskDynamicRegions(page: import('@playwright/test').Page): Promise<void> {
    for (const selector of TIME_MASKS) {
      try {
        const handles = await page.locator(selector).allElements();
        for (const handle of handles) {
          const box = await handle.boundingBox();
          if (box) {
            // Draw a covering rectangle — will be transparent for diff
            await page.evaluate(({ x, y, w, h }) => {
              const el = document.elementFromPoint(x + w / 2, y + h / 2);
              if (el) {
                (el as HTMLElement).style.background = 'white';
              }
            }, box);
          }
          handle.dispose();
        }
      } catch {
        // Element vanished between locator creation and execution — ignore
      }
    }
  }

  for (const vp of VIEWPORTS) {
    for (const theme of THEMES) {
      test.slow(); // visuals are slow — give more time

      test(`${vp.name} ${theme} baseline match`, async ({ page }) => {
        // Set theme
        const html = page.locator('html');
        if (theme === 'dark') {
          await html.evaluate((node) => node.classList.add('dark'));
          // OR if there's a toggle switch:
          // await page.getByLabel('Dark mode').check();
        } else {
          await html.evaluate((node) => {
            node.classList.remove('dark');
            node.classList.remove('theme-dark');
          });
        }

        await page.setViewportSize({ width: vp.width, height: vp.height });
        await page.goto(BASE_URL, { waitUntil: 'networkidle' });
        await page.waitForTimeout(2000); // let animations settle

        // Mask dynamic regions
        await maskDynamicRegions(page);

        // Take full-page screenshot
        const screenshotPath = `tests/e2e/__screenshots__/${vp.name}-${theme}-${Date.now()}.png`;
        const baselinePath = `tests/e2e/__screenshots__/baseline/${vp.name}-${theme}.png`;

        await page.screenshot({ path: screenshotPath, fullPage: true });

        // Compare against baseline if it exists
        try {
          // Playwright's expect.toMatchScreenshot with threshold
          await expect(page).toHaveScreenshot(`${vp.name}-${theme}.png`, {
            maxDiffPixelRatio: DIFF_THRESHOLD,
            fullPage: true,
          });
        } catch (err: any) {
          // No baseline? Record INCONCLUSIVE
          if (err.message?.includes('Baseline')) {
            console.error(
              `\n⚠ NO BASELINE — ${vp.name}/${theme}\n` +
              `Saved to: ${screenshotPath}\n` +
              `Place this file as: tests/e2e/__screenshots__/baseline/${vp.name}-${theme}.png\n` +
              `Then re-run to lock baseline.\n`,
            );
          } else {
            throw err;
          }
        }
      });
    }
  }

  /**
   * Checks for specific layout issues flagged in the standards doc:
   *   - Elements overlapping beyond 5px
   *   - Content overflow past viewport edges
   *   - Missing alt text on images
   *   - Broken layout grids
   */
  test('layout integrity checks', async ({ page }) => {
    await page.goto(BASE_URL);
    await page.setViewportSize({ width: 1440, height: 900 });
    await page.waitForLoadState('networkidle');

    // Check for horizontal overflow
    const bodyWidth = await page.evaluate(() => document.body.scrollWidth);
    const viewportWidth = window.innerWidth;
    expect(bodyWidth, 'no horizontal overflow').toBeLessThanOrEqual(viewportWidth + 5);

    // Check elements don't overlap inappropriately
    const overlaps = await page.evaluate(() => {
      const elements = Array.from(document.querySelectorAll('.card, .widget, .panel'));
      const rects = elements.map((el) => {
        const r = el.getBoundingClientRect();
        return { top: r.top, left: r.left, bottom: r.bottom, right: r.right, tag: el.tagName };
      });
      const result = [];
      for (let i = 0; i < rects.length; i++) {
        for (let j = i + 1; j < rects.length; j++) {
          const a = rects[i], b = rects[j];
          const intersects = !(a.right < b.left || a.left > b.right || a.bottom < b.top || a.top > b.bottom);
          if (intersects) {
            result.push({ a: a.tag, b: b.tag, overlapX: Math.min(a.right, b.right) - Math.max(a.left, b.left) });
          }
        }
      }
      return result;
    });

    expect(overlaps, 'significant element overlaps').toEqual([]);
  });
});
```

### A11y Spec

```typescript
// tests/e2e/a11y/dashboard-a11y.spec.ts
import { test, expect } from '@playwright/test';

test.describe('Accessibility — WCAG 2.2 AA', () => {
  const BASE_URL = process.env.BASE_URL || 'http://localhost:3000';
  const BREAKPOINTS = [
    { name: 'desktop', width: 1440, height: 900 },
    { name: 'tablet', width: 768, height: 1024 },
    { name: 'mobile', width: 390, height: 844 },
  ];

  /**
   * Runs axe-core on the current page and asserts zero violations
   * at WCAG 2.2 AA level. Ignores known transient issues listed
   * in the audit exception list.
   */
  async function runAxeChecks(page: import('@playwright/test').Page): Promise<any> {
    // Inject axe-core dynamically
    await page.addInitScript(() => {
      const script = document.createElement('script');
      script.src = 'https://cdn.jsdelivr.net/npm/accessibility-checker@3.0.0/dist/axe.min.js';
      document.head.appendChild(script);
    });

    // Wait for axe to load
    await page.waitForFunction(() => typeof window.axe !== 'undefined', { timeout: 5000 });

    const results = await page.evaluate(async () => {
      // @ts-ignore — axe is available via CDN inject
      const res = await window.axe.run(document.documentElement, {
        runOnly: ['wcag2a', 'wcag2aa'],
        impact: ['serious', 'critical'],
      });
      return res.violations;
    });

    return results;
  }

  /**
   * Keyboard navigation test — Tab through every interactive element
   * and verify focus ring is always visible.
   */
  async function testKeyboardNav(page: import('@playwright/test').Page, maxTabs = 30): Promise<void> {
    let focusedElement: string | null = null;

    for (let i = 0; i < maxTabs; i++) {
      await page.keyboard.press('Tab');
      focusedElement = await page.evaluate(() => {
        const el = document.activeElement;
        if (!el || el === document.body) return 'body';
        return `${el.tagName.toLowerCase()}${el.id ? `#${el.id}` : ''}${
          el.className ? `.${String(el.className).split(' ')[0]}` : ''
        }`;
      });

      // Focus ring should be visible — outline or box-shadow
      const hasFocusRing = await page.evaluate(() => {
        const el = document.activeElement;
        if (!el) return false;
        const style = window.getComputedStyle(el);
        const outline = style.outlineStyle !== 'none' || style.outlineWidth !== '0px';
        const boxShadow = style.boxShadow && style.boxShadow !== 'none';
        return outline || boxShadow;
      });

      expect(hasFocusRing, `focus ring visible on ${focusedElement}`).toBeTruthy();
    }

    // Cycle back with Shift+Tab
    for (let i = 0; i < 5; i++) {
      await page.keyboard.press('Shift+Tab');
    }
  }

  for (const bp of BREAKPOINTS) {
    test(`${bp.name} axe-core WCAG 2.2 AA scan`, async ({ page }) => {
      await page.setViewportSize({ width: bp.width, height: bp.height });
      await page.goto(BASE_URL, { waitUntil: 'networkidle' });

      const violations = await runAxeChecks(page);

      // Log all findings
      for (const v of violations) {
        console.error(
          `[${v.impact}] ${v.id}: ${v.description}\n` +
          `  Help: ${v.helpUrl}\n` +
          `  Nodes: ${v.nodes.length}`,
        );
        for (const node of v.nodes.slice(0, 5)) {
          console.error(`  → ${node.html}`);
        }
      }

      expect(violations, 'zero WCAG 2.2 AA violations').toHaveLength(0);
    });

  test('color contrast passes on text elements', async ({ page }) => {
    await page.goto(BASE_URL);
    await page.waitForLoadState('networkidle');

    // Extract text nodes and check computed contrast ratios
    const contrastViolations = await page.evaluate(() => {
      const results: { text: string; ratio: number; passed: boolean }[] = [];
      const walker = document.createTreeWalker(
        document.body,
        NodeFilter.SHOW_TEXT,
        null,
      );

      const visitedElements = new Set<HTMLElement>();
      while (walker.nextNode()) {
        const node = walker.currentNode;
        const parent = node.parentElement;
        if (!parent || parent.tagName === 'SCRIPT' || parent.tagName === 'STYLE') continue;

        const style = window.getComputedStyle(parent);
        const color = style.color;
        const bgColor = style.backgroundColor;

        if (color === 'transparent' || bgColor === 'transparent' || bgColor === 'rgba(0, 0, 0, 0)') continue;
        if (visitedElements.has(parent)) continue;
        visitedElements.add(parent);

        const text = node.textContent?.trim();
        if (!text || text.length < 2) continue;

        // Simple luminance check
        const fg = parseColor(color);
        const bg = parseColor(bgColor);
        if (!fg || !bg) continue;

        const lumFg = relativeLuminance(fg);
        const lumBg = relativeLuminance(bg);
        const ratio =
          (Math.max(lumFg, lumBg) + 0.05) / (Math.min(lumFg, lumBg) + 0.05);

        results.push({ text: text.substring(0, 50), ratio, passed: ratio >= 4.5 });
      }
      return results;
    });

    const violations = contrastViolations.filter((v) => !v.passed);
    for (const v of violations.slice(0, 10)) {
      console.warn(`Contrast violation: "${v.text}" ratio=${v.ratio.toFixed(2)} (< 4.5)`);
    }
    expect(violations, 'no contrast violations').toHaveLength(0);
  });
});

// Helpers used in contrast test
function parseColor(colorStr: string): { r: number; g: number; b: number } | null {
  const match = colorStr.match(/rgba?\((\d+),\s*(\d+),\s*(\d+)/);
  if (!match) return null;
  return { r: +match[1], g: +match[2], b: +match[3] };
}

function relativeLuminance({ r, g, b }: { r: number; g: number; b: number }): number {
  const [rs, gs, bs] = [r, g, b].map((c) => {
    const srgb = c / 255;
    return srgb <= 0.03928 ? srgb / 12.92 : ((srgb + 0.055) / 1.055) ** 2.4;
  });
  return 0.2126 * rs + 0.7152 * gs + 0.0722 * bs;
}
```

## Dark Mode Baseline Strategy

### Problem
Charts rendered in light mode use different palettes than dark mode. Background colors swap. Screenshots taken on different CI machines will differ due to font rendering, anti-aliasing, and system themes.

### Solution

```
Strategy: Dual-baseline per viewport + masked comparison

Structure:
  __screenshots__/
  ├── baseline/
  │   ├── desktop-light.png       ← committed baseline
  │   ├── desktop-dark.png
  │   ├── tablet-light.png
  │   ├── tablet-dark.png
  │   ├── mobile-light.png
  │   └── mobile-dark.png
  ├── current/                     ← generated per run
  │   ├── desktop-light-1724712345.png
  │   └── ...
  └── diffs/                       ← auto-generated on mismatch
      ├── desktop-light-diff.png
      └── ...

Rules:
1. Always generate both light AND dark baselines for each viewport
2. Use a masked comparison: ignore [data-testid*="time"], .chart-tooltip-dynamic, 
   animated counters, live badges
3. Per-element color checking: chart palette changes ARE expected between themes;
   detect only structural layout shifts (elements moved/hidden/broken)
4. Font rendering differences: allow 0.05% additional diff for OS/font-stack variations
5. System theme interference: force system theme to light in the headless browser
   by injecting prefers-color-scheme: light before any page load
```

Injection for forced theme:

```typescript
// In Playwright config or global setup:
await context.addInitScript(() => {
  // Force light theme regardless of system preference
  Object.defineProperty(window.matchMedia, 'matches', {
    get() { return false; }, // false = not dark mode
  });
  // Also override for forced dark mode scenario:
  // get() { return true; },
});
```

## Summary

This plan covers four phases in sequence:

1. **Smoke** — automated crawl collecting console errors, network status, and CWV metrics across all reachable pages. Zero user interaction needed. Fails hard on real errors.
2. **Interaction** — filter/date picking, table sorting, drill-down modals, validation states. Enforced by a mutation guard that aborts any write requests unless `DANGER_MODE=1` is set.
3. **Visual** — screenshots at 3 breakpoints × 2 themes, masked diff against committed baselines at 0.1% threshold. Time-sensitive elements get solid overlays so dynamic charts don't cause false positives.
4. **Accessibility** — axe-core WCAG 2.2 AA scan per viewport, keyboard tab-through with focus-ring verification, chart tooltip ARIA role/label checks, semantic landmark validation, programmatic contrast ratio computation.

To deploy: set `BASE_URL=https://your-dashboard-url`, commit baseline screenshots to `tests/e2e/__screenshots__/baseline/`, and run `npx playwright test`. The entire suite is self-contained — no Docker, no external services, just Playwright + system Chrome + axe-core CDN.
