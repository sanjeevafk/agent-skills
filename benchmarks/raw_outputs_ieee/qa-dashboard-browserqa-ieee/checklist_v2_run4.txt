   [x] Theme indicator icon color

   - DO mask: entire background, all border colors, text colors
   - DO compare: structural layout, element presence/absence, overflow behavior

4. Contrast verification (automatic check, not screenshot-based):
   Extract computed styles via getComputedStyle() for all text elements
   Verify luminance ratio >= 4.5:1 for normal text, >= 3:1 for large text
   Flag any element where computed foreground/background yields ratio < threshold

5. Baseline update workflow:
   - New baseline requires manual approval (git commit separately)
   - git add tests/screenshots/baseline/ --message "feat: update visual baselines for {page}"
   - NEVER auto-merge baseline changes into PRs; review diffs manually
   - Retain old baselines in baseline/archive/ for rollback reference

### Integration Note

The actual test harness uses Playwright (`playwright.test.ts`) rather than Chrome extension tooling, because:

- **Programmatic control**: exact breakpoint switching, JS injection for masking, AXE-core hooks all need DOM access
- **Trace viewer**: captures full request/response timeline, screenshot sequences, and console logs for post-analysis
- **CI integration**: `npx playwright test` can run as a GitHub Actions job or pipeline stage
- **Headless mode**: reliable for unattended execution; headed mode available for debugging
