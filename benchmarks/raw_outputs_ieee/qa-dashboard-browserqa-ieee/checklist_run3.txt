### PHASE 1: Read-Only Smoke Crawl

**Goal**: Collect console errors and failed network requests without any user interaction. Spin up each viewport, navigate to `/analytics`, wait for idle, then snapshot errors.

```python
# smoke_crawl.py — run before any manual or automated interaction
import asyncio
from playwright.async_api import async_playwright

PORTALS = {"desktop": (1440, 900), "tablet": (768, 1024), "mobile": (390, 844)}

class SmokeCrawl:
    def __init__(self, base_url="http://localhost:3000/analytics"):
        self.base_url = base_url
        self.console_errors = []
        self.failed_requests = []

    async def crawl_viewport(self, label, width, height):
        async with async_playwright() as pw:
            browser = await pw.chromium.launch(headless=True)
            context = await browser.new_context(
                viewport={"width": width, "height": height},
                device_scale_factor=2 if label == "mobile" else 1,
            )
            page = await context.new_page()

            # Capture errors
            page.on("console", lambda msg: self.console_errors.append({
                "viewport": label,
                "level": msg.type,
                "text": msg.text,
            }) if msg.type in ("error", "warning") else None)

            page.on("requestfailed", lambda req: self.failed_requests.append({
                "viewport": label,
                "url": req.url,
                "status": req.status,
                "method": req.method,
            }))

            await page.goto(self.base_url, wait_until="networkidle")
            await page.wait_for_timeout(2000)  # settle lazy-loaded charts

            # Screenshot baseline for comparison later
            await page.screenshot(path=f"baselines/{label}_smoke.png")
            await context.close()
            await browser.close()

    async def run_all(self):
        for label, (w, h) in PORTALS.items():
            print(f"[SMOKE] Crawling {label} @ {w}x{h}")
            await self.crawl_viewport(label, w, h)

        # Report
        critical_errors = [e for e in self.console_errors if e["level"] == "error"]
        failed = [f for f in self.failed_requests if f["status"] >= 400]

        report = {
            "total_console_errors": len(critical_errors),
            "errors": critical_errors,
            "total_failed_requests": len(failed),
            "failed_urls": list(set(f["url"] for f in failed)),
            "pass": len(critical_errors) == 0 and len(failed) == 0,
        }
        print(f"\n[RESULT] Errors: {report['total_console_errors']} | Failed reqs: {report['total_failed_requests']} | Pass: {report['pass']}")
        return report


asyncio.run(SmokeCrawl().run_all())
```

**Smoke Crawl Exit Gates**:
- Zero JS runtime errors (`console.error`)
- Zero failed XHR/fetch requests (exempt: analytics pixel failures are OK)
- All chart data endpoints returned 200 within 3s
- First Contentful Paint < 2s on mobile

### PHASE 3: Visual Regression

**Strategy**: Use pixel diffing with masked regions around time-dependent widgets (live clocks, timestamp badges, real-time counters). Threshold: 0.1% diff allowed for anti-aliasing variance.

```yaml
# percy.yaml or chromatic.json configuration
visual_regression:
  threshold: 0.1          # 0.1% pixel diff tolerance
  diff_tool: resvg       # or pixelmatch/sharp
  mask_rules:
    - selector: '[data-testid*="timestamp"], [data-testid*="clock"], [data-testid*="live"]'
      action: blur_region_radius_4px  # Gaussian-blur these areas before diff
    - selector: 'canvas[data-chart-canvas]'
      action: screenshot_and_compare_as_svg   # Compare vector render instead of raster
  
  baseline_branch: main
  compare_branches: true
  
  viewports:
    - name: desktop
      width: 1440
      height: 900
    - name: tablet  
      width: 768
      height: 1024
    - name: mobile
      width: 390
      height: 844

  screenshots:
    paths:
      - "/analytics"                          # Full dashboard
      - "/analytics?category=pageviews"       # Filtered state
      - "/analytics?q=some_search"            # Search/filter applied
      - "/analytics/drilldown?dimension=page&id=123"  # Drill-down modal open
```

**Masking Rules Summary**:
| Mask Target | Selector | Technique | Rationale |
|---|---|---|---|
| Timestamp badges | `[data-testid*="timestamp"]` | Blur 2px + reduce opacity | Changes every second |
| Live session counter | `[data-testid*="live"]` | Blur 4px | Real-time WebSocket updates |
| Clock/timer widgets | `[data-testid*="clock"]` | Full coverage mask | Time-sensitive UI |
| Chart SVGs | `<svg>` inside charts | Compare as vectors | Canvas rasterizes differently |

### BLAST-RADIUS RULES

**What never gets clicked (protected operations)**:

| Category | Protected Area | Why | Rule |
|---|---|---|---|
| Destructive | Export buttons | Trigger actual file generation → side effects | Skip in CI, mock in local |
| Destructive | Delete/archive actions | Modify persisted data | Block behind confirmation dialog verification only |
| Auth-dependent | User settings pages | Require authenticated session | Guard: verify `window.__authToken` exists before targeting |
| Cost-sensitive | API-heavy drill-downs with deep pagination | Could trigger excessive backend calls | Limit pagination clicks to max 2 levels deep |
| Rate-limited | Search input auto-complete | Triggers debounced API calls → rate limit hits | Use `input` event assertion, don't trigger real search |
| Third-party | Analytics pixels, ad integrations | External dependencies can fail non-deterministically | Exclude from error collection |
| Payment | Billing/order history | PCI/compliance boundary | Completely isolated from test scope |
| Production DB | Any endpoint not in staging | Safety — never point tests against prod | Explicit environment guard in test harness |

```typescript
// blast-radius-guard.ts
const PROTECTED_SELECTORS = [
  '[data-action="export"]',          // Never auto-click exports
  '[data-action="delete"]',          // Never confirm deletions
  '[data-action="archive"]',         // Never archive records
  '[data-testid="payment-info"]',    // PCI boundary
];

const MAX_PAGINATION_DEPTH = 2;

function isProtectedSelector(selector: string): boolean {
  return PROTECTED_SELECTORS.some((p) => selector.includes(p.split('"')[1]));
}

// Usage in any test helper:
if (isProtectedSelector(element.toString())) {
  throw new Error(`ABORTED: Blocked click on protected element: ${element}`);
}
```

### DARK MODE BASELINE STRATEGY

Dark mode requires separate baselines, not just inverted colors. Different chart palettes and background treatments mean each theme needs its own reference.

**Strategy**:
1. Maintain **two baseline sets**: `baselines/light/` and `baselines/dark/`
2. Theme detection uses CSS `prefers-color-scheme` media query as fallback
3. Toggle persists to `localStorage` — verify persistence across reload
4. Validate contrast independently for each theme (light mode passes → doesn't guarantee dark mode passes)

```typescript
// dark-mode-baseline.spec.ts
test.describe("Dark Mode Baseline", () => {
  const viewports = [
    { name: "desktop", w: 1440, h: 900 },
    { name: "tablet", w: 768, h: 1024 },
    { name: "mobile", w: 390, h: 844 },
  ];

  viewports.forEach(({ name, w, h }) => {
    test(`${name}: persistent theme toggle`, async ({ page }) => {
      await page.setViewportSize({ width: w, height: h });
      await page.goto("/analytics", { waitUntil: "networkidle" });

      // Set dark mode
      await page.getByRole("button", { name: /dark mode|theme toggle/i }).click();
      await expect(page.locator("html")).toHaveAttribute("class", /dark/);

      // Reload page — dark mode should persist
      await page.reload({ waitUntil: "networkidle" });
      await expect(page.locator("html")).toHaveAttribute("class", /dark/);

      // Verify localStorage
      const storedTheme = await page.evaluate(() => localStorage.getItem("theme"));
      expect(storedTheme).toBe("dark");

      await page.setViewportSize({ width: w, height: h });
      await page.goto("/analytics", { waitUntil: "networkidle" });
      
      // Switch light → dark
      await page.getByRole("button", { name: /dark mode/i }).click();
      
      // Should transition smoothly — no intermediate white/background flash
      // Screenshot at 100ms, 300ms, 600ms post-toggle
      await expect(page).toHaveScreenshot(`transition-100ms-${name}.png`, {
        threshold: 0.001,
        animationDuration: 0,
      });
    });

    test(`${name}: chart colors adapt to theme`, async ({ page }) => {
      await page.setViewportSize({ width: w, height: h });

      // Backgrounds must differ
      expect(lightBg).not.toBe(darkBg);
      
      // Chart grid lines must remain visible against both backgrounds
      const gridLines = page.locator('.chart-grid-line');
      await expect(gridLines.first()).toBeVisible();
    });
  });
});
```
