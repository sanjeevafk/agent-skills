# QA Plan — Redesigned Analytics Dashboard

## Pre-flight: Blast-Radius Rules

These rules apply to **every phase**. Violation = immediate abort of that phase.

| Rule | Scope | Rationale |
|------|-------|-----------|
| **Never** click `Delete`, `Export CSV` (write path), `Deploy`, `Revoke Access` | All pages | Mutating actions; must only be exercised manually against staging |
| **Never** submit auth forms with real credentials | Login / SSO pages | Use the CI service account (`ci-test@internal.test` / stored secret) |
| **Never** change date range beyond `[today - 90d, today]` | Date filters | Prevents API rate limits from large historical queries |
| **Never** drill below the 3rd level (dashboard → chart → row detail) without explicit opt-in | Drill-down flows | Some drill endpoints return unpaginated result sets |
| All mutating interactions run against the **staging environment only** unless `QA_FORCE_PROD=1` is set | All phases | Safety net enforced by a pre-check script |


2. **Masking of time-dependent widgets** — apply a regex-based SVG overlay before comparison:
   ```js
   // mask_time_sensitive.js — inject over Chart.js / D3 elements that show timestamps
   function maskTimeSensitiveElements(page) {
     await page.addStyleTag({ content: `
       [data-widget="live-ticker"],
       [data-widget="realtime-metric"],
       [data-testid="timestamp-label"],
       .chart-tooltip__time,
       .metric-card__delta {
         opacity: 0 !important;
       }
     ` });
   }
   ```

3. **Diff threshold**: fail only when `pixelmatch` reports > 0.1% differing pixels **after** masking. Everything else is treated as cosmetic noise (sub-pixel anti-aliasing differences between runs).

4. **Dark mode baselines**: capture under `prefers-color-scheme: dark`. Store separately; do **not** mix light/dark baselines in the same diff directory. If no dark baseline exists, mark the dark-mode visual regression as `INCONCLUSIVE` rather than silently passing.

5. **Fallback rule**: if *no* baseline folder exists for a given breakpoint + theme combo, report `INCONCLUSIVE` for that lane only. Other lanes can still PASS/FAIL independently.

```js
// smoke_test.spec.ts
import { test, expect } from '@playwright/test';

test.describe('Smoke — Analytics Dashboard', () => {
  const PAGES = [
    '/dashboard',
    '/dashboard/metrics/click_rate',
    '/dashboard/tables',
    '/dashboard?segment=new_users&period=7d',
  ];

  const CRITICAL_ERROR_PATTERNS = [
    /^(TypeError|ReferenceError|SyntaxError)\b/,
    /\bUNHANDLED_REJECTION\b/,
    /React\.createElement.*is not a function/,
  ];

  for (const pagePath of PAGES) {
    test(`${pagePath} — no critical console errors & clean network`, async ({ page }) => {
      const errors = [];

      // Collect console messages
      page.on('console', (msg) => {
        if (msg.type() === 'error') {
          const text = msg.text();
          const isNoise = /analytics|googletagmanager|facebook-trk|clevertap/i.test(text);
          if (!isNoise && CRITICAL_ERROR_PATTERNS.some(p => p.test(text))) {
            errors.push(text);
          }
        }
      });

      // Collect failed requests
      const failedRequests = [];
      page.on('requestfailed', (req) => {
        failedRequests.push({ url: req.url(), status: req.status() });
      });

      await page.goto(pagePath, { waitUntil: 'networkidle' });

      // Above-the-fold screenshot @ 1440px
      await page.setViewportSize({ width: 1440, height: 900 });
      await expect(page.locator('[data-testid="kpi-header"]')).toBeVisible({ timeout: 10_000 });
      await page.screenshot({ path: `benchmarks/screenshots/smoke/${pagePath.replace(/\//g, '_')}_desktop.png`, fullPage: false });

      // Core Web Vitals via performance timing
      const metrics = await page.evaluate(async () => {
        const paintEntries = performance.getEntriesByType('paint');
        const lcpEntry = performance.getEntriesByType('largest-contentful-paint')?.[0];
        const inpEntries = performance.getEntriesByType('navigation')
          .flatMap(() => []); // INP needs observer below
        return { paintEntries, lcpEntry };
      });

      // LCP via PerformanceObserver workaround
      const cwv = await page.evaluate(() => new Promise(resolve => {
        let lcp = null, cls = 0, inpValues = [];
        try {
          new PerformanceObserver(list => {
            list.getEntries().forEach(e => { if (e.kind === 'largest-contentful-paint') lcp = e.startTime; });
          }).observe({ type: 'largest-contentful-paint', buffered: true });
        } catch {}
        try {
          new PerformanceObserver(list => {
            list.getEntries().forEach(e => inpValues.push(e.renderTime || e.loadTime));
          }).observe({ type: 'event', buffered: true });
        } catch {}
        const clsObserver = new PerformanceObserver(() => {});
        try { clsObserver.observe({ type: 'layout-shift', buffered: true }); } catch {}
        setTimeout(() => resolve({ lcp, cls, inp: inpValues }), 2500);
      }));

      // Assert thresholds
      expect(cwv.lcp).toBeDefined();
      expect(cwv.lcp).toBeLessThan(2500); // ms → 2.5 s
      expect(cls).toBeLessThan(0.1);
      const avgInp = inpValues.length ? inpValues.reduce((a, b) => a + b, 0) / inpValues.length : 0;
      expect(avgInp).toBeLessThan(200);

      // Network assertions
      expect(failedRequests).toHaveLength(0);
      expect(errors).toHaveLength(0);
    });
  }

  // Mobile viewport @ 390px
  test('Overview — mobile viewport loads', async ({ page }) => {
    await page.setViewportSize({ width: 390, height: 844 });
    await page.goto('/dashboard', { waitUntil: 'networkidle' });
    await expect(page.locator('[data-testid="nav-toggle"]')).toBeVisible();
    await page.screenshot({ path: 'benchmarks/screenshots/smoke/_mobile.png', fullPage: false });
  });
});
```

## Phase 3: Visual Regression

### Capture Script (3 breakpoints × 2 themes)

```js
// visual_regression.spec.ts
import { test, expect } from '@playwright/test';
import pixelmatch from 'pixelmatch';
import fs from 'fs';
import path from 'path';

const BREAKPOINTS = [
  { name: 'desktop', size: { width: 1440, height: 900 } },
  { name: 'tablet',  size: { width: 768, height: 1024 } },
  { name: 'mobile',  size: { width: 390, height: 844 } },
];

const THEMES = ['light', 'dark'];

const SCREENSHOT_PATHS = [
  { id: 'overview',      selector: '[data-testid="kpi-header"]' },
  { id: 'chart-area',    selector: '[data-testid="chart-container"]' },
  { id: 'table-section', selector: '[data-testid="table-container"]' },
];

const BASELINE_DIR = 'benchmarks/screenshots';
const THRESHOLD = 0.001; // 0.1%

function compareAgainstBaseline(actual, expectedId) {
  const currentFile = `${expectedId}_${BREAKPOINTS[0].name}.png`;
  const baseFile = path.join(BASELINE_DIR, 'baseline', currentFile);

  if (!fs.existsSync(baseFile)) {
    // Write fresh baseline; do NOT fail
    console.warn(`[visual-regression] No baseline for ${currentFile}, writing fresh baseline.`);
    fs.writeFileSync(baseFile, actual);
    return { passed: true, inconclusive: true, reason: 'no_baseline' };
  }

  const currentBuf = Buffer.from(actual);
  const baseBuf = fs.readFileSync(baseFile);

  if (currentBuf.equals(baseBuf)) return { passed: true };

  // pixelmatch comparison
  const currImg = png.parseSync(currentBuf);
  const baseImg = png.parseSync(baseBuf);
  const diff = new Uint8ClampedArray(currImg.data.length);
  const diffPixels = pixelmatch(currImg.data, baseImg.data, diff, currImg.width, currImg.height, { threshold: 0.1 });
  const pct = diffPixels / (currImg.width * currImg.height);

  if (pct > THRESHOLD) {
    fs.writeFileSync(`${BASELINE_DIR}/diff_${currentFile}`, png.sync({ data: diff, width: currImg.width, height: currImg.height }));
    return { passed: false, diffPct: pct };
  }
  return { passed: true, note: 'within_threshold' };
}

test.use({ viewport: BREAKPOINTS[0].size }); // desktop default

for (const theme of THEMES) {
  test.describe(`${theme} theme`, () => {
    // Apply dark-mode CSS for theme detection
    if (theme === 'dark') {
      test.beforeEach(async ({ page }) => {
        await page.emulateMedia({ colorScheme: 'dark' });
        // Also toggle if JS-driven:
        const btn = page.locator('[data-testid="theme-toggle"]');
        if (await btn.isVisible()) await btn.click();
      });
    }

    // Mask time-sensitive widgets BEFORE screenshotting
    test.beforeEach(async ({ page }) => {
      await page.addStyleTag({ content: `
        [data-widget="live-ticker"],
        .metric-card__delta,
        .chart-tooltip__time,
        [data-testid="timestamp-display"] {
          display: none !important;
        }
      `});
    });

    for (const bp of BREAKPOINTS) {
      test(`Screenshot ${bp.name} (${bp.size.width}w)`, async ({ page }) => {
        await page.setViewportSize(bp.size);
        await page.goto('/dashboard', { waitUntil: 'networkidle' });

        for (const s of SCREENSHOT_PATHS) {
          await expect(page.locator(s.selector)).toBeVisible({ timeout: 10_000 });
          const buf = await page.locator(s.selector).screenshot();

          const result = compareAgainstBaseline(buf, s.id);

          if (result.inconclusive) {
            console.log(`[${theme}/${bp.name}/${s.id}] INCONCLUSIVE — no baseline, wrote fresh one.`);
          } else if (!result.passed) {
            console.error(`[${theme}/${bp.name}/${s.id}] FAIL — ${result.diffPct * 100}% diff > ${THRESHOLD * 100}%`);
          }
        }
      });
    }
  });
}
```

## Sign-Off Exit Criteria (All Phases Must Clear)

| Gate | Condition | Verdict Impact if Failed |
|------|-----------|-------------------------|
| Phase 1 smoke | 0 critical errors, all 200/304, CWV thresholds met | `DO NOT SHIP` |
| Phase 2 interactions | Every nav link alive, forms valid+invalid states confirmed, auth cycle works | `SHIP WITH FIXES` (if ≤ 3 medium issues) or `DO NOT SHIP` (≥ 4 or any auth issue) |
| Phase 3 visual regression | No diffs > 0.1%; any missing baseline → `INCONCLUSIVE` (can still ship if other phases clear) | `INCONCLUSIVE` blocks merge unless visual change is intentional and reviewed |
| Phase 4 a11y | Zero WCAG 2.2 AA violations, or all accepted with documented risk | `DO NOT SHIP` if any violation is rated `critical` impact |

**Final verdict taxonomy**:
```
SHIP                          — all phases green, zero blockers
SHIP WITH FIXES               — non-blocking issues filed, tracked in ticket system, SLA < 1 sprint
DO NOT SHIP                   — any critical blocker (auth failure, crash, a11y critical, CWV regression > 50%)
INCONCLUSIVE                  — missing baselines or environment unavailable; cannot determine visual regression outcome
```
