### Test 2 — Async Worker Poll

**What's wrong:** One-shot `await asyncio.sleep(2)` assumes the worker finishes within exactly 2 seconds of scheduling. Under CPU pressure the event loop is starved; the scheduled delay extends, and `task.done()` is still `False` at check time. Reruns go green because luck evens out.

**Fix:** Replace the opaque sleep with a **bounded spin-wait**. It checks periodically, caps total wait, and raises a clear `TimeoutError` instead of silently returning a false-negative.

```python
async def _wait_for_done(task: asyncio.Task, *, timeout: float = 10.0) -> None:
    """Spin until the task completes or timeout expires."""
    deadline = time.monotonic() + timeout
    while not task.done():
        remaining = deadline - time.monotonic()
        if remaining <= 0:
            raise TimeoutError(f"Task did not finish within {timeout:.1f}s")
        await asyncio.sleep(min(0.25, remaining))       # poll ≤250 ms

# Usage:
task = asyncio.create_task(worker())
await _wait_for_done(task, timeout=10.0)
assert task.result() == expected
```

Why spin ≥100 ms apart? Aggressive polling burns CPU and creates more load, ironically worsening the problem. 250 ms is a proven sweet spot for asyncio tests.

```python
    deadline = time.monotonic() + 30  # generous ceiling
    while len(worker.results) != 50 and time.monotonic() < deadline:
        await asyncio.sleep(0.2)       # poll interval, no busy-wait
    
    # If we exited the loop because of the deadline, give a clear error:
    assert len(worker.results) == 50, (
        f"Worker stalled: only {len(worker.results)}/50 items processed "
        f"(took {time.monotonic()-deadline:.1f}s)"
    )

# ──────────────────────────────────────────────
# CONDITION-BASED WAITING (generalized helper)
# ──────────────────────────────────────────────
async def wait_for(condition, poll_interval=0.1, timeout=30):
    """Replace ALL arbitrary sleeps in tests with this pattern."""
    deadline = time.monotonic() + timeout
    while not condition() and time.monotonic() < deadline:
        await asyncio.sleep(poll_interval)
    return condition()
```

**Fix summary:**
1. Replace `time.sleep(N)` with `asyncio.wait(task)` or condition polling (`await asyncio.sleep(interval)` in a loop checking a predicate).
2. Always include a timeout/deadline to fail fast with a clear message rather than hanging indefinitely.
3. Use `time.monotonic()` (not `time.time()`) — immune to system clock adjustments.

## Fix 2 — Async Worker Polling (Root Cause: Fixed `sleep(2)` vs Variable Latency)

### Diagnosis

Test spins up an async worker (e.g., starts a background task, waits for readiness), then polls with:

```python
sleep(2)                         # ← THE BUG: magic number < max startup latency
assert worker.is_ready
```

Under low CPU (CI VM), the worker starts in ~0.5s — `sleep(2)` covers it. Under high CPU (loaded dev laptop), startup takes 3–5s — `sleep(2)` expires too early → `AssertionError`. Reruns go green because sometimes the worker happens to start fast enough.

**This is a textbook use case for condition-based waiting** — replace arbitrary timeouts with polling until a predicate holds or a maximum deadline is reached.

### Deterministic Fix

```python
"""
tests/test_async_worker.py  — FIXED VERSION

Changes:
  1. Replace `sleep(2) + assert` with a reusable `await_condition` helper.
  2. Set explicit maximum wait (e.g. 10 s) and poll interval (e.g. 100 ms).
  3. Add diagnostic error message showing elapsed time when it times out.
"""

import asyncio
import pytest

from app.worker import AsyncWorker


async def await_condition(predicate, *, max_wait: float = 10.0, poll_interval: float = 0.1):
    """Poll an async callable until True or max_wait seconds elapse.

    Returns the predicate result once True. Raises TimeoutError if deadline passes.
    """
    deadline = asyncio.get_event_loop().time() + max_wait
    while True:
        result = predicate()
        if result:
            return result
        remaining = deadline - asyncio.get_event_loop().time()
        if remaining <= 0:
            raise TimeoutError(
                f"Condition not met after {max_wait}s (elapsed={asyncio.get_event_loop().time() - deadline + max_wait:.1f}s)"
            )
        await asyncio.sleep(min(poll_interval, remaining))


class TestAsyncWorkerReadiness:
    """Worker-startup test using condition-based waiting instead of fixed sleep."""

    @pytest.fixture
    async def running_worker(self):
        worker = AsyncWorker()
        worker.start()
        yield worker
        await worker.stop()

    @pytest.mark.asyncio
    async def test_worker_becomes_ready_within_deadline(self, running_worker):
        """
        OLD CODE (flaky):
            sleep(2)
            assert running_worker.is_ready

        NEW CODE (deterministic):
            Polled `is_ready` every 100ms for up to 10s.
        """
        ready = await await_condition(
            lambda: running_worker.is_ready,
            max_wait=10.0,
            poll_interval=0.1,
        )
        assert ready is True

    @pytest.mark.asyncio
    async def test_worker_reports_correct_status(self, running_worker):
        """Verify status transitions are deterministic."""
        status = await await_condition(
            lambda: running_worker.status,
            max_wait=10.0,
            poll_interval=0.1,
        )
        assert status == "running"
```
