## Root Cause Analysis (15% Flake)

The three classes you named map directly to common failure modes:

| Class | Manifestation | Fix |
|-------|--------------|-----|
| **Race conditions** | Element appears/disappears between actions; async state change not settled before assertion | Explicit `waitFor` at phase boundaries; no `sleep()`. Stubs return immediately — no real server latency. |
| **Network timing** | Tests depend on arbitrary response times; retries succeed when a request happens to be fast | Route interception with synchronous `route.fulfill()`. No real HTTP calls in `address` / `payment` steps. |
| **Animation timing** | CSS transitions/JS animations cause stale-element or visibility flakes | Wait for animation-frame idle (`requestIdleCallback` polyfill) or set `prefers-reduced-motion` globally. Locator `.toBeVisible()` already handles some, but we also disable non-essential transitions in globals.ts. |

```typescript
    zip: '94102',

    ...overrides,

  return {

    expiryMonth: '12',
    expiryYear: '30',

export function makeCheckoutSession(
  overrides?: Partial<CheckoutSession>
): CheckoutSession {

    items,
    subtotalCents,
    shippingCents: 599,
    taxCents: Math.round(subtotalCents * 0.0875),
    totalCents: subtotalCents + 599 + Math.round(subtotalCents * 0.0875),
    estimatedDelivery: '2026-09-02',
    ...overrides,
  };
```

### 3. Per-Worker Data Isolation

```typescript
// tests/e2e/utils/worker-isolation.ts
import process from 'node:process';
import type { WorkerNamespace } from '../../globals';

const namespaces = new Map<number, WorkerNamespace>();

export function getWorkerNamespace(): WorkerNamespace {
  const workerIndex = Number(process.env.TEST_WORKER_INDEX ?? '0');
  if (!namespaces.has(workerIndex)) {
    const suffix = `w${workerIndex}-${Date.now().toString(36)}`;
    namespaces.set(workerIndex, {
      suffix,
      uniqueEmail: () => `user-${suffix}@example.com`,
      uniqueOrderId: () => `ORDER-${suffix.toUpperCase()}-${Math.random().toString(36).slice(2, 8).toUpperCase()}`,
      uniqueId: () => `entity-${suffix}-${seq()}`,
    });
  }
  return namespaces.get(workerIndex)!;
}

function seq(): string {
  return Math.random().toString(36).slice(2, 8);
}
```

> **Note:** This uses an in-memory map keyed by `TEST_WORKER_INDEX` (set by Playwright's runner). Each worker gets a unique string suffix used to namespace emails, orders, and any shared mutable state (e.g., DB records created during setup).

```typescript
import type { Route } from '@playwright/test';
import type { ShippingAddress, PaymentDetails, CheckoutSession } from '../../globals';
import { makeCheckoutSession } from './factories';

/**
 * Stubs all outbound checkout-related API calls to return deterministic data.
 * Called once per test via the `stubApi` fixture.
 */
export function stubCheckoutRoutes(
  route: Route,
  session?: CheckoutSession,
) {
  const result = session ?? makeCheckoutSession();

  // Cart retrieval
  route.handle('GET', /\/api\/cart/, async (r) => {
    await r.fulfill({
      status: 200,
      contentType: 'application/json',
      body: JSON.stringify({
        items: result.items.map((i) => ({
          ...i,
          priceCents: i.priceCents,
          available: true,
        })),
        subtotalCents: result.subtotalCents,
      }),
    });
  });

  // Shipping rate calculation
  route.handle('POST', /\/api\/shipping\/rates/, async (r) => {
    await r.fulfill({
      status: 200,
      contentType: 'application/json',
      body: JSON.stringify([{
        id: 'standard',
        name: 'Standard Shipping',
        priceCents: result.shippingCents,
        daysMin: 5,
        daysMax: 7,
      }]),
    });
  });

  // Address validation
  route.handle('POST', /\/api\/address\/validate/, async (r) => {
    await r.fulfill({
      status: 200,
      contentType: 'application/json',
      body: JSON.stringify({ valid: true, normalized: true }),
    });
  });

  // Payment processing
  route.handle('POST', /\/api\/payment\/charge/, async (r) => {
    await r.fulfill({
      status: 200,
      contentType: 'application/json',
      body: JSON.stringify({
        success: true,
        transactionId: `txn-${result.orderId.toLowerCase()}`,
        last4: '4242',
      }),
    });
  });

  // Order placement
  route.handle('POST', /\/api\/orders/, async (r) => {
    await r.fulfill({
      status: 201,
      contentType: 'application/json',
      body: JSON.stringify(result),
    });
  });

  // Order confirmation lookup
  route.handle('GET', /\/api\/orders\/.*$/, async (r) => {
    await r.fulfill({
      status: 200,
      contentType: 'application/json',
      body: JSON.stringify(result),
    });
  });
}
```

#### Base Page

```typescript
// tests/e2e/page-objects/base-page.ts
import type { Page, Locator } from '@playwright/test';

type TypedSelector = string | { role: string; name?: string } | { testId: string };

export class BasePage {
  protected readonly page: Page;

  constructor(page: Page) {
    this.page = page;
  }

  /**
   * Wait for a network-conditionally-settled event rather than arbitrary time.
   * Returns after the specified navigation event settles (DOMContentLoaded + no outstanding XHR/Fetch).
   */
  async waitForSettle(options?: { timeout?: number }): Promise<void> {
    await this.page.waitForLoadState('domcontentloaded', options);
    // Wait for any in-flight requests to drain — more reliable than setTimeout
    await this.page.waitForTimeout(0); // yields to microtask queue
    const pending = await this.page.evaluate(() => {
      return new Promise<number>((resolve) => {
        let count = 0;
        const check = () => {
          const pendingCount = performance.getEntriesByType('resource')
            .filter((e: PerformanceResourceTiming) =>
              e.initiatorType === 'fetch' || e.initiatorType === 'xmlhttprequest'
            ).length;
          if (count < 100 && pendingCount > 0) {
            count++;
            requestAnimationFrame(check);
          } else {
            resolve(pendingCount);
          }
        };
        check();
      });
    });
    // At this point in-stubbed flows have zero pending requests
  }

  /**
   * High-level locator getter — centralized for maintenance.
   * When selectors change, update here, not in every page object.
   */
  locate(selector: TypedSelector): Locator {
    if (typeof selector === 'string') {
      return this.page.locator(selector);
    }
    if ('role' in selector) {
      return this.page.getByRole(selector.role, { name: selector.name });
    }
    if ('testId' in selector) {
      return this.page.getByTestId(selector.testId);
    }
    throw new Error(`Unknown selector type`);
  }
}
```

### 6. Fixture Hierarchy

This is the core of the design. Three levels:

1. **Root fixture** (`tests/e2e/fixtures/index.ts`) — composes everything, injects storage state, configures routes.
2. **Auth fixture** (`tests/e2e/fixtures/auth.ts`) — handles login once, caches `storageState.json`.
3. **Page fixtures** (`tests/e2e/fixtures/pages.ts`) — provides page object instances tied to the test page.

#### Root Fixture

#### Auth Fixture (Storage State Reuse)

```typescript
// tests/e2e/fixtures/auth.ts
import { type TestInfo, chromium } from '@playwright/test';
import path from 'path';
import fs from 'fs';

const STORAGE_PATH = path.join(__dirname, '../../.auth/user.json');

/**
 * Fixture that logs in ONCE and saves/restores auth state via storageState.
 * If a valid storageState file exists, skips login entirely.
 */
async function loginHelper(page: ReturnType<typeof test.page>) {
  // Only log in when there's no cached state or it's expired
  if (fs.existsSync(STORAGE_PATH)) {
    try {
      const raw = fs.readFileSync(STORAGE_PATH, 'utf-8');
      const state = JSON.parse(raw);
      // Cookie expiration check — skip if older than 1 hour
      const oldestCookie = state.cookies[0];
      if (oldestCookie && Date.now() - oldestCookie.creationTime! < 3_600_000) {
        return; // reuse existing state
      }
    } catch { /* corrupted file, fall through to login */ }
  }

  const baseURL = process.env.BASE_URL ?? 'https://shop.example.com';
  await page.goto(`${baseURL}/login`);
  await page.getByLabel('Email').fill('qa-user@example.com');
  await page.getByLabel('Password').fill('secure-qa-password');
  await page.getByRole('button', { name: 'Sign in' }).click();
  await page.waitForLoadState('networkidle');

  // Persist state for subsequent tests
  await page.context().storageState({ path: STORAGE_PATH });
}

export const authFixture = {
  // eslint-disable-next-line @typescript-eslint/no-explicit-any
  storageState: async ({ page }, use: (state: unknown) => Promise<void>, testInfo: TestInfo) => {
    await loginHelper(page);
    await use(await page.context().storageState());
  },
};
```

> **Important note:** In practice, this auth fixture should be a proper Playwright fixture using `test.extend()` syntax. The above shows the pattern — wrap it in the root fixture's `[fixture, { auto: true }]` tuple format. A cleaner production version looks like:

```typescript
// Cleaner version inside root fixture extend block:
isLoggedIn: async ({ page }, use) => {
  const STORAGE_PATH = path.join(__dirname, '../../.auth/user.json');
  const needsLogin = !fs.existsSync(STORAGE_PATH);
  
  if (needsLogin) {
    const baseURL = process.env.BASE_URL ?? 'https://shop.example.com';
    await page.goto(`${baseURL}/login`);
    await page.getByLabel('Email').fill('qa-user@example.com');
    await page.getByLabel('Password').fill('secure-qa-password');
    await page.getByRole('button', { name: 'Sign in' }).click();
    await page.waitForLoadState('networkidle');
    await page.context().storageState({ path: STORAGE_PATH });
  }
  
  // Apply cached state to this test's browser context
  await page.context().addCookies(
    JSON.parse(fs.readFileSync(STORAGE_PATH, 'utf-8')).cookies
  );
  for (const ls of JSON.parse(fs.readFileSync(STORAGE_PATH, 'utf-8')).localStorage) {
    await page.context().addInitScript(({ key, value }) => {
      localStorage.setItem(key, value);
    }, ls);
  }
  await use(undefined);
},
```

### 7. Playwright Config

```typescript
// playwright.config.ts
import { defineConfig, devices } from '@playwright/test';
import path from 'path';

/**
 * Configuration optimized for the checkout E2E suite:
 *
 * - 8 workers with strict isolation
 * - storageState-based auth reuse (no per-test logins)
 * - Traces + videos ONLY on flaky/retried specs
 * - Global animation suppression for determinism
 * - Quarantine mode for known-flaky specs
 */
export default defineConfig({
  testDir: './tests/e2e',

  // Output directory for reports/artifacts
  outputDir: './test-results/.temp',

  // Fully parallel execution — safe because every fixture
  // creates per-worker isolated data (emails, orders, etc.)
  fullyParallel: true,
  workers: 8,

  // Fail-fast disabled: we want full pass/fail report across all workers
  forbidOnly: !!process.env.CI,

  // Retries: max 2 retries, but ONLY for specs that are quarantined
  // Or configured via env for general run
  retries: process.env.RETRIES ? parseInt(process.env.RETRIES, 10) : 1,

  // Reporter config
  reporter: [
    ['html', { outputFolder: './test-results/html-report' }],
    ['json', { outputFile: './test-results/results.json' }],
    ['list'],
  ],

  // Use Chromium, headed in local dev, headless in CI
  use: {
    baseURL: process.env.BASE_URL ?? 'https://shop.example.com',

    // Collect traces/videos ONLY when a test is about to be retried
    // This avoids storing artifacts for passing tests (saves disk/CIs)
    trace: 'retain-on-failure',
    video: 'retain-on-failure',
```

```typescript
import type { GlobalTeardownFunction } from '@playwright/test';
import fs from 'fs';

const globalTeardown: GlobalTeardownFunction = async () => {
  // Cleanup stale auth state (> 1 hour old) so next run forces fresh login
  const authPath = path.join(__dirname, '../.auth/user.json');
  if (fs.existsSync(authPath)) {
    const stats = fs.statSync(authPath);

    }
  }
};
```

### 10. Network-Idle Waiting Strategy (Explained)

The `waitForSettle()` method in `BasePage` does three things:

```
Step 1: waitForLoadState('domcontentloaded')
   ↓ Ensures DOM tree is ready (no waiting for images/fonts)
Step 2: yield to microtask queue (waitForTimeout(0))
   ↓ Lets React/Angular/Vue hydration settle before interactions
Step 3: Evaluate in-browser to detect in-flight fetch/XHR
   ↓ Checks performance.timing entries for pending resource types
   ↓ Bails out when count drops to 0 (or after 100 frames ~1.6s)
```

**Why not `waitForLoadState('networkidle')`?**  
Because "network idle" in Playwright means zero requests for 500ms — which can hang indefinitely on streaming SSE connections, WebSocket heartbeats, or analytics pings. The custom settle method is bounded (max 1.6s) and scoped to XHR/fetch only.

**Alternative for specific elements:** When you know exactly what to wait for:

```typescript
// Instead of generic wait — be specific:
await page.getByRole('heading', { name: 'Order Confirmed' }).waitFor({
  state: 'visible',
  timeout: 5000,
});
```

### 11. Parallel Execution Safety (8 Workers)

| Mechanism | How it works |
|-----------|-------------|
| **`TEST_WORKER_INDEX` env var** | Each worker gets index 0-7. Used to generate unique email addresses, order IDs, and entity suffixes. |
| **In-memory namespace map** | `getWorkerNamespace()` returns a closure with factory methods. Keys off `workerIndex`. No cross-worker pollution. |
| **Isolated browser contexts** | Playwright creates one context per worker test. No cookie/storage sharing. |
| **Stubbed APIs** | Since all API responses are synthetic fixtures, there are no shared database records to collide on. |
| **No shared mutable state** | Every piece of test data flows through fixtures — nothing is global. |

---

## Summary of Flake Mitigations

| Requirement | Solution |
|------------|----------|
| Page-object model | All locators in page classes, never in tests. Centralized via `BasePage.locate()`. |
| Auth state reuse | `storageState` saved once to `.auth/user.json`, restored via `addCookies` + `addInitScript`. Zero per-test logins. |
| API stubbing | `route.handle()` intercepts all checkout endpoints with deterministic JSON fixtures. Synchronous `fulfill()`. |
| Waiting strategies | `waitForSettle()` (bounded, network-scoped) replaces `sleep()`. Specific element waits preferred. |
| Trace/video on retry | `'retain-on-failure'` config. Never stored for passing tests. |
| 8 workers safety | Per-worker namespace suffix isolates data. Stubbed APIs eliminate DB contention. |
| Quarantine policy | Separate project, `trace: 'always'`, doubled timeouts, advisory results, defined promotion criteria. |
