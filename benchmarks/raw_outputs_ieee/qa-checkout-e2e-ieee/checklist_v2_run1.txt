## Checkout Flow E2E Test Suite — Complete Design & Implementation

### Architecture Overview

The suite addresses the 15% flake rate by replacing arbitrary waits with deterministic API intercepts, reusing auth state via `storageState`, capturing traces/videos selectively on retries only, and isolating per-worker fixtures. Below is the full implementation.

Key decisions:
- **`trace: 'off'` / `video: 'off'`** at config level — never recorded by default. Individual fixtures enable them *only* on worker retries (see §3).
- **Workers**: unbounded locally, capped at 8 in CI. `fullyParallel: true` enables safe concurrent execution.
- **`forbidOnly: CI`** fails fast on `.only` in CI pipelines.

**Production version** using API call (fastest, most reliable):

```typescript
// tests/e2e/fixtures/auth.ts  — production version
import { test as base, expect } from '@playwright/test'
import type { StorageState } from '@playwright/test/api'
import path from 'path'

const STORAGE_PATH = path.resolve(__dirname, '../fixtures/storage-state.json')

interface AuthCreds { email: string; password: string }
const CREDS: AuthCreds = {
  email: process.env.E2E_ADMIN_EMAIL ?? 'admin@example.com',
  password: process.env.E2E_ADMIN_PASSWORD ?? 'changeme123',
}

export const test = base.extend<{
  storageState: StorageState
}>({
  storageState: async ({}, use) => {
    let state: StorageState | null = null

    try {
      const fs = await import('fs')
      const raw = fs.readFileSync(STORAGE_PATH, 'utf-8')
      state = JSON.parse(raw)
      // Validate expiry — cookie names match your app
      const cookies = state.cookies ?? []
      const expired = cookies.some(
        (c: { name: string; value: string; domain?: string; path?: string; expires?: number; httpOnly?: boolean; secure?: boolean; sameSite?: 'Strict' | 'Lax' | 'None' }) =>
          c.expires !== undefined && c.expires < Date.now() / 1000
      )
      if (expired) state = null
    } catch { /* file missing — will re-login */ }

    if (!state) {
      state = await relogin()
      const fs = await import('fs')
      const dir = path.dirname(STORAGE_PATH)
      if (!(await import('fs').then(fs => fs.existsSync(dir)))) {
        await import('fs').then(fs => fs.mkdirSync(dir, { recursive: true }))
      }
      fs.writeFileSync(STORAGE_PATH, JSON.stringify(state, null, 2))
    }

    await use(state)
  },
})

async function relogin(): Promise<StorageState> {
  const { request } = await import('@playwright/test')
  const res = await request.post('/api/auth/login', {
    data: CREDS,
  })
  await expect(res).toBeOK()  // custom matcher — see extensions
  const body = await res.json() as { token: string; refreshToken: string }

  return {
    cookies: [],
    origins: [{
      origin: new URL('/api/auth/me', CREDS.email).origin, // adjust baseURL
      localStorage: [
        { name: 'accessToken', value: body.token },
        { name: 'refreshToken', value: body.refreshToken },
      ],
    }],
  }
}
```

This avoids UI login entirely. Tests that need auth get the same serialized state reused across all workers — no per-test overhead.

```typescript
import { type Page, type Locator, type BrowserContext } from '@playwright/test'

export class BasePage {
  readonly page: Page
  readonly context: BrowserContext

  constructor(page: Page, context?: BrowserContext) {
    this.page = page
    this.context = context ?? page.context()
  }

  get(id: string): Locator { return this.page.getByTestId(id) }
  heading(text: RegExp | string): Locator { return this.page.getByRole('heading', { name: text }) }
  button(text: RegExp | string): Locator { return this.page.getByRole('button', { name: text }) }
  input(label: RegExp | string): Locator { return this.page.getByLabel(label) }
  link(text: RegExp | string): Locator { return this.page.getByRole('link', { name: text }) }

  async goto(pathname: string): Promise<void> {
    await this.page.goto(pathname, { waitUntil: 'networkidle' })
  }

  /** Wait until all in-flight requests settle — no animation/timeout hacks. */
  async waitForStability(): Promise<void> {
    await this.page.waitForLoadState('networkidle')
    // Additional guard: wait for any active timeouts/timers to clear
    await this.page.evaluate(() => new Promise(r => setTimeout(r, 0)))
  }
}
```

### 5. Quarantine Policy

Flaky specs are managed through three mechanisms:

| Tier | Mechanism | When Used | Effect |
|------|-----------|-----------|--------|
| **P0: `test.fixme`** | Inline quarantine | Known bug filed (Issue #XYZ), high confidence reproducible failure | Always runs but marked in report; CI ignores result |
| **P1: `test.skip` conditional** | Conditional skip | Environment-specific failure (e.g., staging-only, CI-specific) | Skipped entirely; does not affect pass/fail counts |
| **P2: Retry-based auto-capture** | Artifact capture on retry | Intermittent race conditions where the root cause is unclear | Trace/video only recorded on retry iterations |

#### P0 Example (`test.fixme`):
```typescript
test('flaky: rapid purchase race', async ({ page }) => {
  test.fixme(true, 'Issue #1234: consecutive checkouts lose order state')
  // Test body remains intact for easy re-enablement
})
```

#### P1 Example (`test.skip` conditional):
```typescript
test('works with specific third-party provider', async ({ page }) => {
  test.skip(process.env.PAYMENT_PROVIDER !== 'stripe-test', 'Requires Stripe test mode')
  // …
})
```

#### P2 Example (auto artifact capture):
Handled by the `startArtifactCapture` fixture — automatically turns on tracing and video when `testInfo.retry > 0`. No per-test boilerplate.

### 6. Flakiness Identification & Remediation Workflow

```bash
# Run a suspect spec 10× to measure flake rate
npx playwright test tests/e2e/features/search.spec.ts --repeat-each=10 --retries=3

# Run entire suite with increased retries to surface intermittent failures
npx playwright test --repeat-each=5 --retries=2

# Generate HTML report with traces
npx playwright show-report ./playwright-report
```

#### Common Patterns Fixed in This Suite

| Symptom | Fix Applied |
|---------|-------------|
| **"locator.click: target closed"** | All pages use `page.waitForLoadState('networkidle')` after navigation; locators auto-wait internally |
| **"API returned stale data"** | Every API route is intercepted with `route.fulfill()` — responses are deterministic JSON fixtures |
| **"Element not attached"** | No `waitForTimeout()`. Uses `waitForResponse()`, `waitForLoadState('networkidle')`, and locator auto-wait |
| **"Animation caused missed click"** | `page.waitForLoadState('networkidle')` naturally waits for render completion |
| **"Cross-worker state leakage"** | Each worker gets a fresh `newContext()` seeded with `storageState`; cleaned up post-test |
| **"Too many CI artifacts"** | Traces/videos only captured on retry (`testInfo.retry > 0`) |

        with:
