## Phase 1 — Golden-Master / Characterization Tests

The goal: prove behavioral equivalence after every single refactor commit. These tests don't assert what the code *should* do — they assert what it *actually* does right now. That's the distinction between characterization tests (safety net) and unit tests (design intent).

### Strategy Overview

| Side Effect | How to Snapshot | Verification |
|---|---|---|
| **Database writes** | Intercept at cursor level: record `(query, params)` tuples executed during the call | Post-call replay against an in-memory DB; compare row counts |
| **Email dispatch** | Mock/stub the email sender; capture subject, body, recipients, attachments | Assert exact strings + metadata from captured calls |
| **Return values** | Call every public method with fixed fixtures; serialize return dicts to JSON snapshots | Diff against committed fixture files |
| **Exceptions** | Feed invalid inputs; record exception type + message | Re-assert same exception class with same message text |

```python
FIXTURE_PATH = Path(__file__).parent / "snapshots"

def _load_snapshot(method_name: str) -> dict:
    path = FIXTURE_PATH / f"{method_name}.json"
    if path.exists():
        return json.loads(path.read_text())
    return {}


def _save_snapshot(method_name: str, data: dict) -> None:
    FIXTURE_PATH.mkdir(parents=True, exist_ok=True)
    path = FIXTURE_PATH / f"{method_name}.json"
    path.write_text(json.dumps(data, indent=2, default=str))

class CreateOrderGoldenMaster(OrderServiceCharacterizationTest):
    """Behavior snapshot for OrderService.create_order(...).

    Records: SQL executed, emails fired, return value shape,
             audit trail, and exceptions on bad input.
    """

    def _capture_full_result(self) -> dict:
        """Serialize everything that happened during the most recent test
        call so we can diff it against the committed snapshot on re-runs."""
        return {
            "return_value": getattr(self, "_last_return_value", None),
            "sql_calls": self.sql_recorder.calls,
            "emails_sent": self.email_capture.sent,
            "audit_entries": self.audit_logger.entries,
            "exception": getattr(self, "_last_exception", None),
        }

    def _run_and_snapshot(self, method_name: str, *args, **kwargs):
        """Execute the target method, catch any exception, then save or
        compare the serialized outcome against the committed snapshot."""
        try:
            result = self._last_method(*args, **kwargs)
            self._last_return_value = result
            self._last_exception = None
        except Exception as exc:
            self._last_return_value = None
            self._last_exception = {"type": type(exc).__name__, "message": str(exc)}

        outcome = self._capture_full_result()

        # On FIRST run: generate the golden snapshot file.
        # On subsequent runs: assert behavior matches snapshot.
        snapshot = _load_snapshot(method_name)
        if not snapshot:
            _save_snapshot(method_name, outcome)
            self.skipTest(f"Generated new golden snapshot for {method_name}")

        self.assertEqual(outcome["sql_calls"], snapshot["sql_calls"])
        self.assertEqual(outcome["emails_sent"], snapshot["emails_sent"])
        self.assertEqual(outcome["audit_entries"], snapshot["audit_entries"])
        self.assertEqual(type(outcome["exception"]).__name__ if outcome["exception"] else None,
                         type(snapshot["exception"]).__name__ if snapshot.get("exception") else None)
        if outcome.get("return_value") and snapshot.get("return_value"):
            self.assertEqual(outcome["return_value"]["order_id"],
                             snapshot["return_value"]["order_id"])
```

### How to Prove Behavior Preservation at Every Commit

Each commit must satisfy **three gates**:

| Gate | Check | Tool |
|---|---|---|
| **Gate 1 — Golden master** | `python -m pytest tests/fixtures/order_characterization.py -v` — ALL existing snapshots pass | CI block |
| **Gate 2 — No dead SQL** | `grep -c "INSERT\|UPDATE\|DELETE\|SELECT" src/old_order_service.py` should equal the baseline count — confirms you haven't accidentally dropped a statement | Pre-commit hook |
| **Gate 3 — API surface frozen** | Public method signatures in `src/order_service.py` unchanged until Phase 4 | `inspect.signature()` regression check in CI |

> If Gate 2 fails, you either added SQL (missing from golden master) or removed some (regression). Investigate immediately — do **not** suppress the failure.

## Phase 2 — Extract Interfaces (Seam Planning)

With characterization tests passing (Phase 1 green), introduce seams. Each seam turns a concrete dependency into an abstracted protocol/interface behind which implementations can swap freely.

### Seam Extraction Order & Rationale

Extract from **highest coupling → lowest coupling**, because each step makes the next easier. The bottleneck collaborator constrains how cleanly you can isolate the rest.

#### Step 2a — Database layer (`IDataRepository`)

**Why first:** Direct SQL embedded throughout methods is the single biggest barrier to reasoning about the code. Once the DB access is behind an interface, you can test all business logic with an in-memory store, removing non-determinism from the equation.

**Interface design** (keep it minimal — only the queries actually called):

```python
"""src/domain/repositories.py"""

from abc import ABC, abstractmethod
from typing import Any

class IRepository(ABC):
    """Minimal query surface needed by OrderService."""

    @abstractmethod
    def find_order_by_id(self, order_id: str) -> dict[str, Any] | None:
        pass

    @abstractmethod
    def insert_order(self, order_data: dict[str, Any]) -> str:
        pass

    @abstractmethod
    def update_order_status(self, order_id: str, status: str, updated_at: str) -> None:
        pass

    @abstractmethod
    def insert_order_line_items(self, order_id: str, items: list[dict[str, Any]]) -> None:
        pass

    @abstractmethod
    def get_tax_rate_for_region(self, region_code: str) -> float:
        pass

    @abstractmethod
    def upsert_inventory_reservation(self, sku: str, qty: int) -> None:
        pass

    @abstractmethod
    def delete_inventory_reservation(self, reservation_id: str) -> None:
        pass


class LegacySqlRepository(IRepository):
    """Thin adapter wrapping the existing raw-SQL execution the way
    OrderService currently calls it. Serves as a drop-in replacement
    while we extract the domain logic outward."""

    def __init__(self, raw_connection) -> None:
        self._conn = raw_connection

    def find_order_by_id(self, order_id: str) -> dict[str, Any] | None:
        cursor = self._conn.cursor()
        cursor.execute("SELECT * FROM orders WHERE id = ?", (order_id,))
        row = cursor.fetchone()
        return dict(row) if row else None

    def insert_order(self, order_data: dict[str, Any]) -> str:
        cursor = self._conn.cursor()
        cursor.execute("""
            INSERT INTO orders (id, customer_id, status, total, created_at)
            VALUES (?, ?, ?, ?, datetime('now'))
        """, (order_data["id"], order_data["customer_id"],
              order_data["status"], order_data["total"]))
        return order_data["id"]

    def update_order_status(self, order_id: str, status: str, updated_at: str) -> None:
        cursor = self._conn.cursor()
        cursor.execute("""
            UPDATE orders SET status = ?, updated_at = ? WHERE id = ?
        """, (status, updated_at, order_id))

    def insert_order_line_items(self, order_id: str, items: list[dict[str, Any]]) -> None:
        cursor = self._conn.cursor()
        for item in items:
            cursor.execute("""
                INSERT INTO order_lines (order_id, sku, description, unit_price, qty)
                VALUES (?, ?, ?, ?, ?)
            """, (order_id, item["sku"], item["description"],
                  item["unit_price"], item["qty"]))

    def get_tax_rate_for_region(self, region_code: str) -> float:
        cursor = self._conn.cursor()
        cursor.execute("SELECT rate FROM tax_rates WHERE region_code = ?", (region_code,))
        row = cursor.fetchone()
        return float(row[0]) if row else 0.0

    def upsert_inventory_reservation(self, sku: str, qty: int) -> None:
        cursor = self._conn.cursor()
        cursor.execute("""
            INSERT INTO inventory_reservations (sku, qty, status)
            VALUES (?, ?, 'reserved')
            ON CONFLICT(sku) DO UPDATE SET qty = qty + excluded.qty
        """, (sku, qty))

    def delete_inventory_reservation(self, reservation_id: str) -> None:
        cursor = self._conn.cursor()
        cursor.execute("DELETE FROM inventory_reservations WHERE id = ?",
                       (reservation_id,))
```

**Inversion point:** Change `OrderService.__init__` to accept `IRepository` instead of raw `Connection`. Run golden-master tests. If they still pass, you're done with this step.

#### Step 2c — Pricing engine (`IPricingStrategy`)

**Why third:** Pricing is pure-computation with no side effects — easy to characterize and easy to swap once the collaborator abstraction exists.

```python
class IPricingStrategy(ABC):
    @abstractmethod
    def compute(self, items: list[dict], region_code: str,
                promo_code: str | None) -> dict[str, float]:
        """Returns {subtotal, discounts, shipping, tax, grand_total}."""
        pass


class DefaultPricingEngine(IPricingStrategy):
    """Keeps the existing inline pricing math isolated from OrderService."""

    def __init__(self, repository: IRepository) -> None:
        self._repo = repository

    def compute(self, items, region_code, promo_code):
        subtotal = sum(item["unit_price"] * item["qty"] for item in items)
        discount = self._apply_promo(subtotal, promo_code)
        shipping = self._compute_shipping(subtotal - discount, items)
        tax_rate = self._repo.get_tax_rate_for_region(region_code)
        tax = (subtotal - discount) * tax_rate
        grand_total = subtotal - discount + shipping + tax
        return {
            "subtotal": round(subtotal, 2),
            "discounts": round(discount, 2),
            "shipping": round(shipping, 2),
            "tax": round(tax, 2),
            "grand_total": round(grand_total, 2),
        }
```

**Why fourth:** Validation touches 34 fields across multiple methods. Isolate it last because it depends on knowing the final shape of the order aggregate.

```python
class IOrderValidator(ABC):
    @abstractmethod
    def validate_create(self, data: dict[str, Any]) -> list[str]:
        """Returns list of error strings. Empty = valid."""
        pass

    @abstractmethod
    def validate_cancel(self, order: dict, reason: str) -> list[str]:
        pass

    @abstractmethod
    def validate_refund(self, order: dict) -> list[str]:
        pass


class LegacyValidator(IOrderValidator):
    """Extracts the ~200 lines of field-level validation scattered through
    OrderService methods. Copy-paste each conditional into the matching
    method below, then remove from OrderService. Run golden-master after
    each removal to confirm behavioral identity."""

    def validate_create(self, data: dict) -> list[str]:
        errors = []
        if not data.get("customer_id"):
            errors.append("customer_id is required")
        if not data.get("items") or len(data["items"]) == 0:
            errors.append("at least one line item required")
        for i, item in enumerate(data.get("items", [])):
            if not item.get("sku"):
                errors.append(f"item[{i}].sku is required")
            if item.get("qty", 0) <= 0:
                errors.append(f"item[{i}].qty must be positive")
            if item.get("unit_price", 0) < 0:
                errors.append(f"item[{i}].unit_price must be non-negative")
        if not data.get("region_code"):
            errors.append("region_code is required")
        return errors
```

4. Run golden-master tests

### Facade Pattern (Final Shape)

```python
"""src/order_service.py — public entry point. Thin wiring layer."""

from src.domain.services.new_order_service import NewOrderService
from src.domain.services.pricing_engine import DefaultPricingEngine
from src.domain.repositories.sql_repository import LegacySqlRepository
from src.domain.validators.order_validator import LegacyValidator
from src.infrastructure.email.smtp_sender import SmtpSender
from src.audit.logger import FileAuditTrail


def build_production(service_config: dict):
    """Construct the full dependency graph. Called once at application start."""
    conn = Connection(service_config["database_url"])
    repo = LegacySqlRepository(conn)
    email = LegacyEmailAdapter(SmtpSender(service_config["smtp_host"]))
    audit = FileAuditTrail(service_config["audit_log_path"])
    pricing = DefaultPricingEngine(repo)
    validator = LegacyValidator()

    svc = NewOrderService(repo, pricing, email, audit, validator)
    return OrderServiceFacade(svc)


class OrderServiceFacade:
    """Matches the original OrderService public API exactly."""

    def __init__(self, delegate: NewOrderService):
        self._svc = delegate

    def create_order(self, data: dict) -> dict:
        return self._svc.create(data)

    def update_status(self, order_id: str, new_status: str,
                      actor: str) -> dict:
        return self._svc.update_status(order_id, new_status, actor)

    def cancel_order(self, order_id: str, reason: str,
                     actor: str) -> dict:
        return self._svc.cancel(order_id, reason, actor)

    def process_refund(self, order_id: str, reason: str,
                       actor: str) -> dict:
        return self._svc.refund(order_id, reason, actor)

    def get_order(self, order_id: str) -> dict | None:
        return self._svc.lookup(order_id)

    def calculate_pricing(self, items: list, region: str,
                          promo: str | None) -> dict:
        return self._svc.calculate(items, region, promo)
```
