#### 0a. Execution-Level Snapshot: Interceptor + Replay Engine

Build a thin proxy that sits *in front* of every real collaborator inside OrderService, captures the full side-effect transcript for every `public` method call, and writes deterministic JSON to disk. After the run, compare outputs byte-for-byte.

```python
# characterization/transcript_runner.py — the heart of golden-master
import json, time, hashlib, functools
from pathlib import Path
from typing import Any

OUTPUT_DIR = Path("tests/golden_snapshots")
OUTPUT_DIR.mkdir(parents=True, existists=False)

class TranscriptCollector:
    """Intercepts all DB calls, email sends, and audit log writes.
    
    Each invocation records:
      1. The exact SQL text + parameter values used
      2. The email recipient, subject, body hash, attachments metadata
      3. Audit log record keys + severity
    
    The transcript is a list of ordered "effects" that get hashed
    deterministically per-order so the same inputs always produce
    the same output file.
    """
    def __init__(self):
        self.effects: list[dict] = []
    
    def record_sql(self, operation: str, table: str, sql: str, params: dict | None):
        # Canonicalize: remove whitespace differences, sort param keys
        cleaned = ' '.join(sql.split())
        sanitized_params = dict(sorted((k, str(v)) for k, v in (params or {}).items()))
        self.effects.append({
            "type": "sql",
            "operation": operation,           # INSERT|UPDATE|DELETE|SELECT
            "table": table,
            "sql_hash": hashlib.sha256(cleaned.encode()).hexdigest()[:12],
            "cleaned_sql": cleaned,
            "param_count": len(sanitized_params),
            "params_fingerprint": hashlib.sha256(
                json.dumps(sanitized_params).encode()
            ).hexdigest()[:8],
        })
    
    def record_email(self, to: str, subject: str, body_plain: str, 
                     body_html: str | None, attachments: list[dict]):
        self.effects.append({
            "type": "email",
            "to": to,
            "subject_hash": hashlib.sha256(subject.encode()).hexdigest()[:12],
            "body_md5": hashlib.md5(body_plain.encode()).hexdigest(),
            "has_html": body_html is not None,
            "attachment_count": len(attachments),
        })
    
    def record_audit(self, action: str, entity_type: str, entity_id: str, 
                     severity: str, detail: str):
        self.effects.append({
            "type": "audit",
            "action": action,
            "entity_type": entity_type,
            "entity_id": entity_id,
            "severity": severity,
            "detail_hash": hashlib.sha256(detail.encode()).hexdigest()[:12],
        })
    
    def snapshot_key(self) -> str:
        return hashlib.sha256(
            json.dumps(self.effects, sort_keys=True).encode()
        ).hexdigest()[:16]


def freeze_order_result(order_result: Any) -> dict:
    """Convert any rich result object to pure-JSON-serializable form."""
    # If results carry datetime, Decimal, UUID — normalize here
    return {
        "order_id": str(order_result.order_id),
        "status": order_result.status,
        "total_cents": int(order_result.total_cents),
        "line_items": [
            {"sku": li.sku, "qty": li.qty, "unit_price_cents": int(li.unit_price_cents)}
            for li in order_result.line_items
        ],
        "created_at": str(order_result.created_at),
    }


def record_execution(order_service, method_name: str, args, kwargs) -> dict:
    """Execute one OrderService public method + collect full transcript.
    
    This replaces every real collaborator temporarily via monkey-patch
    or dependency injection swap (see §0b below). Returns the
    golden-master JSON payload.
    """
    collector = TranscriptCollector()
    
    # --- Patch collaborators ---
    _patch_db(order_service, collector)
    _patch_emailer(order_service, collector)
    _patch_logger(order_service, collector)
    
    # Execute
    start = time.monotonic()
    result = getattr(order_service, method_name)(*args, **kwargs)
    elapsed_ms = round((time.monotonic() - start) * 1000, 1)
    
    # Revert patches (or rely on scoped DI swap)
    _unpatch_all(order_service)
    
    frozen_result = freeze_order_result(result)
    snapshot = {
        "method": method_name,
        "input_hash": hashlib.sha256(
            json.dumps({"args": args, "kwargs": kwargs}, default=str).encode()
        ).hexdigest(),
        "result": frozen_result,
        "effects": collector.effects,
        "elapsed_ms": elapsed_ms,
        "snapshot_key": collector.snapshot_key(),
    }
    return snapshot


def _patch_db(service, collector):
    raw_conn = service._db_connection          # or however it owns its connection
    original_execute = raw_conn.execute
        
    @functools.wraps(original_execute)
    def traced_execute(sql, params=None):
        parsed = _parse_statement(sql)         # heuristic parser
        collector.record_sql(parsed["op"], parsed["tbl"], sql, params)
        return original_execute(sql, params)
    
    raw_conn.execute = traced_execute


def _patch_emailer(service, collector):
    orig_send = service._mailer.send
    @functools.wraps(orig_send)
    def traced_send(to, subject, body_plain, body_html=None, attachments=None):
        collector.record_email(to, subject, body_plain, body_html, attachments or [])
        return orig_send(to, subject, body_plain, body_html=body_html, attachments=attachments)
    service._mailer.send = traced_send


def _patch_logger(service, collector):
    orig_write = service._auditor.write
    @functools.wraps(orig_write)
    def traced_write(action, entity_type, entity_id, severity, detail):
        collector.record_audit(action, entity_type, entity_id, severity, detail)
        return orig_write(action, entity_type, entity_id, severity, detail)
    service._auditor.write = traced_write


def _parse_statement(sql: str) -> dict:
    """Naive but sufficient statement classifier."""
    upper = sql.strip().upper()
    op = upper[:6]                              # SELECT|INSERT|UPDATE|DELETE
    table_map = {
        "INSERT INTO orders": "orders",
        "UPDATE orders SET": "orders",
        "INSERT INTO order_lines": "order_lines",
        "INSERT INTO order_payments": "payments",
        "SELECT FROM payments": "payments",
    }
    tbl = "unknown"
    for key, val in table_map.items():
        if key.upper() in sql.upper():
            tbl = val
            break
    return {"op": op, "tbl": tbl}
```

def _assert_golden(method: str, snapshot: dict):
    """Read expected file; if missing, CREATE it (first-run mode).
       On subsequent runs, COMPARE byte-for-byte.
       
       -- GATHER_MODE=1 env var tells this to *write* rather than assert.
    """
    import os
    golden_path = _golden_path(method, snapshot["input_hash"])
    
    if os.environ.get("GATHER_MODE") == "1":
        golden_path.parent.mkdir(parents=True, exist_ok=True)
        golden_path.write_text(json.dumps(snapshot, indent=2, sort_keys=True))
        print(f"[GATHER] Wrote {golden_path}")
        return
    
    if not golden_path.exists():
        pytest.fail(
            f"NO GOLDEN SNAPSHOT FOR '{method}' (input_hash={snapshot['input_hash']}).\n"
            f"Run with GATHER_MODE=1 to create baseline."
        )
    
    expected = json.loads(golden_path.read_text())
    assert snapshot["result"] == expected["result"], \
        f"RESULT MISMATCH for {method}: expected {expected['result']} != got {snapshot['result']}"
    assert snapshot["effects"] == expected["effects"], \
        f"EFFECTS MISMATCH for {method}:\n" \
        f"  expected {len(expected['effects'])} effects, got {len(snapshot['effects'])}\n" \
        f"  diff keys: {set(e['snapshot_key'] for e in expected['effects']) ^ set(e['snapshot_key'] for e in snapshot['effects'])}"

        yield name, snap

### Phase 1 — Identify Collaborators & Extract Interfaces

Before writing a single line of replacement code, identify the four external dependencies baked into OrderService's 1,400 lines:

| Internal reference | Role | Why it's tangled |
|---|---|---|
| `_db_connection` / raw SQL strings | Persistence | CRUD + queries scattered across 6+ methods |
| `_mailer` (sendgrid/Mandrill/etc.) | Notifications | Sent in `create_order`, `cancel_order`, `update_status` |
| `_auditor` (write_log / insert_audit_row) | Audit trail | Called after every state mutation |
| `_tax_engine` / `_pricing_calculator` inline methods (often nested functions) | Tax + Pricing | Business rules computed in-place, ~400 combined LOC |

**Extract order:** Interface the Database/SQL layer *first*. Here's why:

1. **Highest coupling**: Raw SQL strings litter the most methods. Getting this right creates a clear seam.
2. **Easiest to test independently**: SQLite in-memory works fine for unit tests; email/tax need more setup.
3. **Enables immediate isolation**: Once you can pass a fake `OrderRepository` to a stub OrderService, you can start exercising *all* methods against an in-memory DB without touching network resources.
4. **No behavioral ambiguity**: SQL reads/writes are deterministic given fixed seed data. Email content and tax rates depend on external state that may drift.

#### Step 2: Extract Repository Layer

**Goal**: Replace all raw `cursor.execute()` calls with `OrderRepository` methods. Keep the existing SQL-based repository implementation (`SqliteOrderRepository` or `PostgresOrderRepository`) so behavior is identical.

Strategy:
1. Create the `OrderRepository` ABC (already defined above).
2. Implement `SqlQueryOrderRepository` that wraps the existing connection and executes the same SQL the OrderService was already using. Map query results back to `Order` value objects.
3. Go method-by-method in OrderService: find each `execute()`, replace with the corresponding repository call.
4. Golden master passes after each method replaced (check SQL fingerprint count stays constant).

```python
# src/persistence/sql_query_repository.py — drops-in as a straight wrapper

class SqlQueryOrderRepository(OrderRepository):
    def __init__(self, connection):
        self._conn = connection
    
    def save_order(self, order: Order) -> str:
        txn = self._conn.begin()
        try:
            oid = uuid4().hex[:12].upper()
            self._conn.execute(
                "INSERT INTO orders (order_id, customer_email, status, ...) VALUES (?, ?, ?, ...)",
                (oid, order.customer_email, order.status.value, ...),
            )
            for item in order.line_items:
                self._conn.execute(
                    "INSERT INTO order_lines (order_id, sku, qty, unit_price_cents) VALUES (?, ?, ?, ?)",
                    (oid, item.sku, item.qty, item.unit_price_cents),
                )
            txn.commit()
            return oid
        except Exception:
            txn.rollback()
            raise
        # ... similar for get_order, update_order_status, upsert_payment, get_order_by_customer
```

### Phase 4 — Proving Behavior Preservation at Every Commit

This is the non-negotiable discipline. At **every single commit** that modifies OrderService or its collaborators:

#### 4a. Golden Master Suite Must Pass

```bash
# Run ALL golden snapshots — not just affected ones
pytest tests/golden_master/ -v --tb=short

# Failures mean behavior regressed. Roll back the commit.
```

Why **all**, not just affected? Because subtle cross-cutting bugs exist — a change to `_apply_discount` affects both `create_order` and `cancel_order` refund amounts. Only full-suite regression catches this.

#### 4b. Side-Effect Comparison Checklist

For each commit, verify three dimensions:

| Dimension | What it proves | How checked |
|---|---|---|
| **Result fidelity** | Computation is correct | `snapshot["result"] == expected["result"]` asserts in golden tests |
| **SQL fingerprint stability** | Same queries, same params, same count | Effects array equality check |
| **Email/content parity** | Same recipients, subjects, body structure | Hash comparison on effects |
| **Audit trail integrity** | Same actions logged, same entities touched | Audit entry count + action/hash matching |

#### 4c. Integration Checkpoints

Run these gates **before merging** any strangler step:

```bash
# 1. Unit tests (once they exist alongside characterization tests)
pytest tests/unit/ -v

# 2. Golden master (behavior preservation — always required)
pytest tests/golden_master/ -v

# 3. Diff sanity checks
git diff --stat | grep -q "\.py$"  # ensure only expected files changed
grep -rn "_db_connection\.execute" src/order/order_service.py  # should be empty after Step 2
```

#### 4d. Database Schema Guarantee

Never alter the schema during refactoring. The SQL in `SqlQueryOrderRepository` is a 1:1 mirror of what OrderService already executes. Schema changes belong in a separate migration ticket, verified by integration tests that spin up the real database.

> **Rule**: Golden master protects *business behavior*, not schema. If the schema changes, that's a feature ticket — not part of a purity refactor.

#### 4e. Coverage Floor

After the characterization suite gathers all paths, measure:

```bash
coverage run -m pytest tests/golden_master/
coverage report --show-missing
```

Every method exercised by the golden master is confirmed covered. If the suite hits 95%+ of OrderService's branches before refactoring starts, post-refactor coverage should not drop below that floor.
