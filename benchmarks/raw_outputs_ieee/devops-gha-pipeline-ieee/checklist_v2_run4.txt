## Architecture Overview

The solution uses **two workflow files**:

- **`.github/workflows/ci.yml`** — Main pipeline: detection → lint → test matrix → build → publish
- **`.github/workflows/release.yml`** — Release gating: environment approval → deploy → SBOM → attestation

A **single reusable workflow** pattern is used to avoid duplication between CI and release jobs where applicable.

---

## Cache-Key Design Philosophy

Three distinct cache namespaces, each with layered key strategies:

### 1. Dependency cache (`pnpm-store`)

```
key: pnpm-linux-node-${{ runner.os }}-node@${{ matrix.node-version }}-${{ hashFiles('pnpm-lock.yaml') }}
restore-keys: |
  pnpm-linux-node-${{ runner.os }}-node@${{ matrix.node-version }}-
  pnpm-linux-node-${{ runner.os }}-
```

- Full match on OS + Node major + lockfile hash — zero stale deps
- Progressive restore keys fall back gracefully when lockfile changes (keeps partial hits)
- Single store shared across all matrix combinations via `${HOME}/.local/share/pnpm/store`

### 2. Build artifact cache

```
key: build-${{ runner.os }}-node@${{ matrix.node-version }}-${{ github.ref_name }}-${{ github.sha }}
restore-keys: |
  build-${{ runner.os }}-node@${{ matrix.node-version }}-${{ github.ref_name }}-
  build-${{ runner.os }}-node@${{ matrix.node-version }}-
```

- Unique per commit for exact reproducibility (`github.sha`)
- Prefix-based restore from same branch for incremental speed
- Stores `.turbo` cache dir and workspace `.dts` outputs

### 3. Turbo/monorepo cache (remote fallback)

When configured with a remote cache (GitHub Artifacts), turbo falls back to HTTP after local cache misses. The `--remote-cache-expiration 90` flag ensures stale entries don't linger.

**Why three layers:** Dependencies change infrequently (lockfile-driven), builds change per-commit (sha-driven), and turbo cache bridges branches. Each namespace avoids collision.

## Workflow 1: `.github/workflows/ci.yml`

```yaml
# .github/workflows/ci.yml
name: CI

on:
  push:
    branches: [main, develop]
  pull_request:
    branches: [main, develop]
  merge_group:
    types: [checks_requested]

permissions:
  contents: read
  # statuses needed for merge queue enforcement
  statuses: write

env:
  PNPM_CACHE_FOLDER: ${{ github.workspace }}/.pnpm-store
  TURBO_TOKEN: ${{ secrets.TURBO_TOKEN }}
  TURBO_TEAM: ${{ vars.TURBO_TEAM }}
  NODE_VERSION: "20"

# Cancel redundant runs on the same PR
concurrency:
  group: ci-${{ github.workflow }}-${{ github.head_ref || github.run_id }}
  cancel-in-progress: true

jobs:
  # ──────────────────────────────────────────────
  # 1. Detect changed packages / paths
  # ──────────────────────────────────────────────
  changes:
    name: Detect changes
    runs-on: ubuntu-latest
    permissions:
      contents: read
    outputs:
      apps: ${{ steps.filter.outputs.apps }}
      libs: ${{ steps.filter.outputs.libs }}
      shared: ${{ steps.filter.outputs.shared }}
      any: ${{ steps.filter.outputs.any_changed }}
    steps:
      - uses: actions/checkout@v4
        with:
          fetch-depth: 0

      - name: Filter changed paths
        id: filter
        uses: dorny/paths-filter@v3
        with:
          filters: |
            apps:
              - 'apps/web/**'
              - 'apps/api/**'
              - 'apps/mobile/**'
            libs:
              - 'packages/*/src/**'
              - 'packages/*/package.json'
              - 'shared/**'
            shared:
              - 'pnpm-workspace.yaml'
              - 'pnpm-lock.yaml'
              - '.github/workflows/ci.yml'
              - 'turbo.json'
              - 'tsconfig.base.json'

  # ──────────────────────────────────────────────
  # 2. Lint (always runs on every change)
  # ──────────────────────────────────────────────
  lint:
    name: Lint
    runs-on: ubuntu-latest
    needs: [changes]
    if: ${{ needs.changes.outputs.any == 'true' }}
    steps:
      - uses: actions/checkout@v4

      - name: Setup pnpm
        uses: pnpm/action-setup@v4
        with:
          version: 9

      - name: Setup Node.js
        uses: actions/setup-node@v4
        with:
          node-version: ${{ env.NODE_VERSION }}
          cache: "pnpm"

      - name: Install dependencies
        run: pnpm install --frozen-lockfile

      - name: Run lint
        run: pnpm run lint

      - name: Check formatting
        run: pnpm run format:check

  # ──────────────────────────────────────────────
  # 3. Build (affected workspaces only)
  # ──────────────────────────────────────────────
  build:
    name: Build (${{ matrix.workspace }})
    runs-on: ubuntu-latest
    needs: [changes, lint]
    if: ${{ needs.changes.outputs.any == 'true' }}
    strategy:
      fail-fast: false
      matrix:
        workspace:
          ${{ fromJSON(needs.changes.outputs.libs) }}
          ${{ fromJSON(needs.changes.outputs.apps) }}
    steps:
      - uses: actions/checkout@v4

      - name: Setup pnpm
        uses: pnpm/action-setup@v4
        with:
          version: 9

      - name: Setup Node.js
        uses: actions/setup-node@v4
        with:
          node-version: ${{ env.NODE_VERSION }}
          cache: "pnpm"

      # ── Dependency cache ──
      - name: Restore pnpm store
        uses: actions/cache@v4
        with:
          path: ${{ env.PNPM_CACHE_FOLDER }}
          key: pnpm-${{ runner.os }}-node@${{ env.NODE_VERSION }}-${{ hashFiles('pnpm-lock.yaml') }}
          restore-keys: |
            pnpm-${{ runner.os }}-node@${{ env.NODE_VERSION }}-
            pnpm-${{ runner.os }}-

      - name: Install dependencies
        run: pnpm install --frozen-lockfile

      # ── Build artifact cache ──
      - name: Restore build cache
        uses: actions/cache@v4
        with:
          path: .turbo
          key: build-${{ runner.os }}-node@${{ env.NODE_VERSION }}-${{ github.ref_name }}-${{ matrix.workspace }}-${{ hashFiles('pnpm-lock.yaml') }}
          restore-keys: |
            build-${{ runner.os }}-node@${{ env.NODE_VERSION }}-${{ github.ref_name }}-${{ matrix.workspace }}-
            build-${{ runner.os }}-node@${{ env.NODE_VERSION }}-

      - name: Build ${{ matrix.workspace }}
        run: pnpm --filter "${{ matrix.workspace }}" run build

      - name: Upload build artifacts
        uses: actions/upload-artifact@v4
        with:
          name: dist-${{ matrix.workspace }}
          path: |
            ${{ startsWith(matrix.workspace, 'apps/') && format('{0}/**', matrix.workspace) || format('packages/{0}/dist', matrix.workspace) }}
          retention-days: 7

  # ──────────────────────────────────────────────
  # 4. Test Matrix (Node 20 + 22 × shards 4)
  # ──────────────────────────────────────────────
  test:
    name: Test (${{ matrix.node-version }}/shard-${{ matrix.shard }}/ws:${{ matrix.workspace }})
    runs-on: ubuntu-latest
    needs: [changes, lint]
    if: ${{ needs.changes.outputs.any == 'true' }}
    timeout-minutes: 30
    strategy:
      fail-fast: false
      matrix:
        node-version: [20, 22]
        shard: [1/4, 2/4, 3/4, 4/4]
        workspace:
          ${{ fromJSON(format('[{0}]", join(fromJSON(needs.changes.outputs.apps), fromJSON(needs.changes.outputs.libs)), '"')) }}
          # Fallback: if no diffs detected, still test all
          - "apps/web"
          - "apps/api"
          - "apps/mobile"
          - "packages/*"
        exclude:
          # Don't shard tests for small lib-only changes on non-app workspaces
          # This saves matrix combinatorial blowup
          - workspace: ${{ fromJSON(needs.changes.outputs.libs)[0] }}
            shard: "2/4"
    steps:
      - uses: actions/checkout@v4

      - name: Setup pnpm
        uses: pnpm/action-setup@v4
        with:
          version: 9

      - name: Setup Node.js ${{ matrix.node-version }}
        uses: actions/setup-node@v4
        with:
          node-version: ${{ matrix.node-version }}
          cache: "pnpm"

      - name: Restore pnpm store
        uses: actions/cache@v4
        with:
          path: ${{ env.PNPM_CACHE_FOLDER }}
          key: pnpm-${{ runner.os }}-node@${{ matrix.node-version }}-${{ hashFiles('pnpm-lock.yaml') }}
          restore-keys: |
            pnpm-${{ runner.os }}-node@${{ matrix.node-version }}-
            pnpm-${{ runner.os }}-

      - name: Install dependencies
        run: pnpm install --frozen-lockfile

      - name: Run tests (shard ${{ matrix.shard }})
        run: pnpm --filter "${{ matrix.workspace }}" run test -- --ci --shard=${{ matrix.shard }}
        continue-on-error: true

  # ──────────────────────────────────────────────
  # 5. Integration Tests (runs once, after all sharded tests)
  # ──────────────────────────────────────────────
  integration-test:
    name: Integration Tests
    runs-on: ubuntu-latest
    needs: [test]
    if: always() && needs.test.result == 'success' && needs.changes.outputs.any == 'true'
    steps:
      - uses: actions/checkout@v4

      - name: Setup pnpm
        uses: pnpm/action-setup@v4
        with:
          version: 9

      - name: Setup Node.js
        uses: actions/setup-node@v4
        with:
          node-version: ${{ env.NODE_VERSION }}
          cache: "pnpm"

      - name: Install dependencies
        run: pnpm install --frozen-lockfile

      - name: Start services
        run: |
          docker compose up -d postgres redis
          sleep 10

      - name: Run integration tests
        run: pnpm run test:integration
        env:
          DATABASE_URL: postgresql://postgres:test@localhost:5432/test
          REDIS_URL: redis://localhost:6379

      - name: Cleanup
        if: always()
        run: docker compose down

  # ──────────────────────────────────────────────
  # 6. Type Check (across full repo)
  # ──────────────────────────────────────────────
  type-check:
    name: Type Check
    runs-on: ubuntu-latest
    needs: [changes, lint]
    if: ${{ needs.changes.outputs.any == 'true' }}
    steps:
      - uses: actions/checkout@v4

      - name: Setup pnpm
        uses: pnpm/action-setup@v4
        with:
          version: 9

      - name: Setup Node.js
        uses: actions/setup-node@v4
        with:
          node-version: ${{ env.NODE_VERSION }}
          cache: "pnpm"

      - name: Install dependencies
        run: pnpm install --frozen-lockfile

      - name: Type check full workspace
        run: pnpm run typecheck

  # ──────────────────────────────────────────────
  # 7. Summary gate (ensures matrix tests passed)
  # ──────────────────────────────────────────────
  summary:
    name: CI Summary
    runs-on: ubuntu-latest
    needs: [build, test, integration-test, type-check]
    if: always()
    steps:
      - name: Check results
        run: |
          echo "::notice::CI summary complete"
          if [[ "${{ needs.build.result }}" != "success" && \
                "${{ needs.build.result }}" != "skipped" ]]; then
            echo "Build failed"
            exit 1
          fi
          if [[ "${{ needs.test.result }}" != "success" ]]; then
            echo "Tests failed"
            exit 1
          fi
          if [[ "${{ needs.type-check.result }}" != "success" && \
                "${{ needs.type-check.result }}" != "skipped" ]]; then
            echo "Type check failed"
            exit 1
          fi

  # ──────────────────────────────────────────────
  # 8. Preview Environments (PR-only, one per PR)
  # ──────────────────────────────────────────────
  preview:
    name: Preview Environment
    runs-on: ubuntu-latest
    needs: [summary, changes]
    if: >-
      github.event_name == 'pull_request' &&
      needs.changes.outputs.apps != '[]' &&
      needs.summary.result == 'success'
    environment:
      name: preview
      url: ${{ steps.preview.outputs.url }}
    timeout-minutes: 20
    steps:
      - uses: actions/checkout@v4

      - name: Setup pnpm
        uses: pnpm/action-setup@v4
        with:
          version: 9

      - name: Setup Node.js
        uses: actions/setup-node@v4
        with:
          node-version: ${{ env.NODE_VERSION }}
          cache: "pnpm"

      - name: Restore pnpm store
        uses: actions/cache@v4
        with:
          path: ${{ env.PNPM_CACHE_FOLDER }}
          key: pnpm-${{ runner.os }}-node@${{ env.NODE_VERSION }}-${{ hashFiles('pnpm-lock.yaml') }}
          restore-keys: |
            pnpm-${{ runner.os }}-node@${{ env.NODE_VERSION }}-

      - name: Install dependencies
        run: pnpm install --frozen-lockfile

      - name: Build all apps
        run: pnpm --filter "apps/..." run build

      - name: Deploy previews
        id: preview
        run: |
          # Assumes each app has a deploy:preview script that deploys to a unique subdomain
          # e.g., pr-<number>.<app>.yourcompany.com
          for app in apps/web apps/api apps/mobile; do
            if pnpm --filter "$app" run --silent list-files | grep -q "deploy"; then
              DEPLOY_URL=$(pnpm --filter "$app" run deploy:preview \
                --env PREVIEW_DOMAIN="pr-${{ github.event.pull_request.number }}.${app#apps/}.preview.yourcompany.com")
              echo "url=$DEPLOY_URL" >> $GITHUB_OUTPUT
              echo "::notice::$app deployed to $DEPLOY_URL"
            fi
          done

      - name: Smoke test previews
        run: |
          for url in ${{ steps.preview.outputs.url }}*; do
            if command -v curl &> /dev/null; then
              curl -sf --retry 3 --retry-delay 5 "$url/health" || {
                echo "::warning::Smoke test failed for $url"
              }
            fi
          done

      - name: Comment PR with URLs
        if: steps.preview.outputs.url != ''
        uses: actions/github-script@v7
        with:
          github-token: ${{ secrets.GITHUB_TOKEN }}
          script: |
            const urls = `${{ steps.preview.outputs.url }}`.trim().split('\n');
            const body = `🎨 Preview environment(s) deployed:\n\n${urls.map(u => `- ${u}`).join('\n')}\n\nThey will be destroyed when the PR is closed.`;
            await github.rest.issues.createComment({
              issue_number: context.issue.number,
              owner: context.repo.owner,
              repo: context.repo.repo,
              body
            });
```

## Workflow 2: `.github/workflows/release.yml`

```yaml
# .github/workflows/release.yml
name: Release & Deploy

on:
  release:
    types: [published]
  workflow_dispatch:
    inputs:
      environment:
        description: "Target environment"
        required: true
        default: staging
        type: choice
        options:
          - staging
          - production
      version:
        description: "Semantic version (e.g., v1.2.3)"
        required: true
        type: string

permissions:
  contents: read
  id-token: write       # Required for OIDC federated auth (no long-lived keys)
  packages: write       # For publishing artifacts/blobs
  attestations: write   # For provenance attestation
  security-events: write # For supply-chain metadata

env:
  PNPM_CACHE_FOLDER: ${{ github.workspace }}/.pnpm-store
  REGISTRY: ghcr.io
  IMAGE_NAME: ${{ github.repository }}

# Prevent concurrent releases
concurrency:
  group: release-${{ github.ref }}
  cancel-in-progress: false

jobs:
  # ──────────────────────────────────────────────
  # Pre-release: build everything
  # ──────────────────────────────────────────────
  build-release:
    name: Build Release Artifacts
    runs-on: ubuntu-latest
    outputs:
      version: ${{ steps.version.outputs.VERSION }}
      tag: ${{ steps.version.outputs.TAG }}
      sbom-hash: ${{ steps.sbom.outputs.hash }}
    steps:
      - uses: actions/checkout@v4
        with:
          fetch-depth: 0

      - name: Derive version
        id: version
        run: |
          VERSION="${{ github.event.release.tag_name || inputs.version }}"
          TAG="$(echo "$VERSION" | tr '+' '_')"
          echo "VERSION=$VERSION" >> $GITHUB_OUTPUT
          echo "TAG=$TAG" >> $GITHUB_OUTPUT

      - name: Setup pnpm
        uses: pnpm/action-setup@v4
        with:
          version: 9

      - name: Setup Node.js
        uses: actions/setup-node@v4
        with:
          node-version: ${{ env.NODE_VERSION }}
          cache: "pnpm"

      - name: Restore pnpm store
        uses: actions/cache@v4
        with:
          path: ${{ env.PNPM_CACHE_FOLDER }}
          key: pnpm-${{ runner.os }}-node@${{ env.NODE_VERSION }}-${{ hashFiles('pnpm-lock.yaml') }}
          restore-keys: |
            pnpm-${{ runner.os }}-node@${{ env.NODE_VERSION }}-

      - name: Install dependencies
        run: pnpm install --frozen-lockfile

      - name: Build all packages
        run: pnpm --filter "...[origin/main]" run build

      - name: Generate SBOM (spdx)
        id: sbom
        run: |
          npx --yes @cyclonedx/cyclonedx-npm@latest --output-file sbom.spdx.json --format spdx-json
          HASH=$(sha256sum sbom.spdx.json | awk '{print $1}')
          echo "hash=$HASH" >> $GITHUB_OUTPUT

      - name: Upload SBOM
        uses: actions/upload-artifact@v4
        with:
          name: sbom-spdx
          path: sbom.spdx.json
          retention-days: 90

      - name: Compress build artifacts
        run: |
          mkdir -p dist/releases/${{ steps.version.outputs.TAG }}
          cp -r apps/web/dist dist/releases/${{ steps.version.TAG }}/web
          cp -r apps/api/dist dist/releases/${{ steps.version.TAG }}/api
          cp -r apps/mobile/dist dist/releases/${{ steps.version.TAG }}/mobile
          for pkg in packages/*/dist; do
            name="${pkg#packages/}"
            name="${name%/dist}"
            cp -r "$pkg" "dist/releases/${{ steps.version.outputs.TAG }}/$name"
          done

      - name: Upload release artifacts
        uses: actions/upload-artifact@v4
        with:
          name: release-assets
          path: dist/releases/${{ steps.version.outputs.TAG }}
          retention-days: 90

  # ──────────────────────────────────────────────
  # Deploy to Staging (auto on release)
  # ──────────────────────────────────────────────
  deploy-staging:
    name: Deploy to Staging
    runs-on: ubuntu-latest
    needs: [build-release]
    if: >-
      github.event_name == 'release' ||
      (github.event_name == 'workflow_dispatch' && inputs.environment == 'staging')
    environment:
      name: staging
      url: https://staging.yourcompany.com
    steps:
      - uses: actions/checkout@v4

      - name: Download artifacts
        uses: actions/download-artifact@v4
        with:
          name: release-assets
          path: dist

      - name: Deploy to staging
        run: |
          # Example: deploy to Kubernetes staging cluster
          # Uses OIDC-federated kubectl (configured below)
          ./scripts/deploy.sh \
            --environment staging \
            --version "${{ needs.build-release.outputs.version }}" \
            --artifacts dist

  # ──────────────────────────────────────────────
  # Deploy to Production (manual approval gate)
  # ──────────────────────────────────────────────
  deploy-production:
    name: Deploy to Production
    runs-on: ubuntu-latest
    needs: [build-release, deploy-staging]
    if: >-
      github.event_name == 'release' ||
      (github.event_name == 'workflow_dispatch' && inputs.environment == 'production')
    # ⚠️  Manual approval via GitHub Environments
    environment:
      name: production
      url: https://www.yourcompany.com
    steps:
      - uses: actions/checkout@v4

      - name: Download artifacts
        uses: actions/download-artifact@v4
        with:
          name: release-assets
          path: dist

      - name: Verify SBOM integrity
        run: |
          EXPECTED_HASH="${{ needs.build-release.outputs.sbom-hash }}"
          ACTUAL_HASH=$(sha256sum sbom.spdx.json | awk '{print $1}')
          if [[ "$EXPECTED_HASH" != "$ACTUAL_HASH" ]]; then
            echo "::error::SBOM integrity check failed!"
            echo "  Expected: $EXPECTED_HASH"
            echo "  Actual:   $ACTUAL_HASH"
            exit 1
          fi

      - name: Deploy to production
        run: |
          # Rolling update with health checks
          ./scripts/deploy.sh \
            --environment production \
            --version "${{ needs.build-release.outputs.version }}" \
            --artifacts dist \
            --strategy rolling \
            --health-check-interval 30 \
            --timeout 600

      - name: Post-deployment smoke tests
        run: |
          curl -sf --retry 5 --retry-delay 10 https://www.yourcompany.com/health || exit 1
          curl -sf --retry 3 --retry-delay 10 https://www.yourcompany.com/api/health || exit 1

  # ──────────────────────────────────────────────
  # Artifact Attestation (supply-chain provenance)
  # ──────────────────────────────────────────────
  attest:
    name: Generate Provenance Attestation
    runs-on: ubuntu-latest
    needs: [deploy-production, build-release]
    # Only on success
    if: success()
    permissions:
      id-token: write
      contents: write
      attestations: write
    steps:
      - uses: actions/checkout@v4

      - name: Download release artifacts
        uses: actions/download-artifact@v4
        with:
          name: release-assets
          path: dist

      - name: Attest build provenance
        uses: actions/attest-build-provenance@v1
        with:
          subject-path: |
            dist/web
            dist/api
            dist/mobile
          subject-name: "<app-name>"
          # Uncomment to customize SLSA levels:
          # builder-id: https://github.com/yourorg/repo/.github/workflows/release.yml@refs/heads/main
          # subject-digest-sha256: <hash-of-subject>

      - name: Attest SBOM
        uses: sigstore/cosign-installer@v3
        with:
          cosign-release: "v2.2.2"

      - name: Sign SBOM with cosign (OIDC)
        if: ${{ vars.SIGSTORE_FULCIO_URL != '' }}
        env:
          COSIGN_EXPERIMENTAL: "1"
        run: |
          cosign sign-blob \
            --certificate-oidc-issuer "${{ vars.COSIGN_OIDC_ISSUER }}" \
            --signature "$SIGNATURE_FILE" \
            sbom.spdx.json > sbom.spdx.json.sig
        working-directory: ${{ github.workspace }}
```

## OIDC Trust Configuration

### Cloud Provider: AWS (example — adapt for GCP/Azure)

```bash
# 1. Create an IAM OpenID Connect provider in AWS
aws iam create-open-id-connect-provider \
  --url https://token.actions.githubusercontent.com \
  --client-id-list sts.amazonaws.com \
  --thumbprint-list 6938fd4d98bab03faadb97b34396831e3780aea1

# 2. Create an IAM role with trust policy
cat > oidc-trust-policy.json <<'EOF'
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Principal": {
        "Federated": "arn:aws:iam::<ACCOUNT_ID>::oidc-provider/token.actions.githubusercontent.com"
      },
      "Action": "sts:AssumeRoleWithWebIdentity",
      "Condition": {
        "StringEquals": {
          "token.actions.githubusercontent.com:aud": "sts.amazonaws.com"
        },
        "StringLike": {
          "token.actions.githubusercontent.com:sub": [
            "repo:<OWNER>/<REPO>:environment:staging",
            "repo:<OWNER>/<REPO>:environment:production"
          ]
        }
      }
    }
  ]
}
EOF

aws iam create-role \
  --role-name github-actions-deploy \
  --assume-role-policy-document file://oidc-trust-policy.json

# 3. Attach least-privilege deployment permissions
cat > deploy-permissions.json <<'EOF'
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": [
        "ecs:*",
        "ecr:*",
        "elasticloadbalancing:*"
      ],
      "Resource": "*"
    }
  ]
}
EOF

aws iam put-role-policy \
  --role-name github-actions-deploy \
  --policy-name deploy-permissions \
  --policy-document file://deploy-permissions.json

# 4. Store the role ARN as a GitHub repository secret
gh secret set AWS_DEPLOY_ROLE_ARN --body "arn:aws:iam::<ACCOUNT_ID>::role/github-actions-deploy"
```

### In the workflow (`.github/workflows/release.yml` snippet):

```yaml
steps:
  - name: Configure AWS credentials (OIDC, no long-lived keys)
    uses: aws-actions/configure-aws-credentials@v4
    with:
      role-to-assume: ${{ secrets.AWS_DEPLOY_ROLE_ARN }}
      aws-region: us-east-1
      # Role session naming for audit trail
      role-session-name: github-actions-${{ github.workflow }}-${{ github.run_id }}
```

**Key properties of this setup:**

| Property | Detail |
|---|---|
| Long-lived credentials | None — no AWS access keys stored anywhere |
| Trust boundary | Scoped to specific GitHub Environments (`staging`, `production`) |
| Auditing | `role-session-name` includes `run_id` for per-run traceability |
| Condition scoping | `StringLike` on `sub` allows different permissions per environment via environment-level secrets |
| Token lifecycle | GitHub token auto-expires; no manual rotation needed |

## Required Status Checks for Merge Queue

In **Repository Settings → Branches → Merge Queue**, configure:

```
Required status checks to pass before merging:
  ✓ Lint
  ✓ Type Check
  ✓ Build (all filtered workspaces)
  ✓ CI Summary
  ✓ Integration Tests
```

The merge queue triggers `checks_requested` events. To prevent the matrix combinatorial explosion during merge-queue checks, add this override to `ci.yml`:

```yaml
merge_group:
  types: [checks_requested]

# Then in the test matrix:
matrix:
  node-version:
    ${{ github.event_name == 'merge_group' && fromJson('[20]') || fromJson('[20, 22]') }}
  shard:
    ${{ github.event_name == 'merge_group' && fromJson('["1/4"]') || fromJson('["1/4", "2/4", "3/4", "4/4"]') }}
```

This runs only Node 20 with shard 1/4 during merge-queue evaluation (fast feedback), while full matrix runs on PRs and pushes.

## Path-Filtering Explanation

The `dorny/paths-filter@v3` action compares the PR base against modified paths. Outputs are JSON arrays like `["apps/web","packages/utils"]`. These feed directly into `matrix.workspace` via `fromJSON()`, so:

- **Changed only `apps/web` + its deps** → lint + web build + web tests run
- **Changed a shared lib used by all apps** → shared filter matches `shared` → all apps rebuild
- **Changed only docs** → nothing runs (filters return empty arrays, `if` conditions short-circuit)

The `any_changed` output gates all downstream jobs, ensuring zero wasted CI minutes on truly unchanged branches.

## Turborepo Caching Notes

All jobs reference `$TURBO_TOKEN` and `$TURBO_TEAM` environment variables. Configure these as GitHub repository secrets/variables:

```bash
gh variable set TURBO_TEAM --body "<team-id-from-turborepo>"
gh secret set TURBO_TOKEN --body "<token-from-turborepo-dashboard>"
```

Turborepo's remote cache stores `.turbo` tarballs in cloud storage (AWS S3/GCP Bucket/etc). Local `actions/cache` for `.turbo` acts as a warm-up layer — the first CI run populates the remote, subsequent runs hit local first.
