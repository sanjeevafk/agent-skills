## Cache Key Design — Deep Dive

### Strategy: Two-Layer Independent Caches

```
Layer 1: Global node_modules  ←  shared across ALL jobs/workspaces
Layer 2: Per-workspace dist/  ←  independent invalidation per app/lib
```

#### Why Two Layers?

- **`node_modules`** is hoisted at the workspace root by pnpm. One global cache serves every job. No need to re-download 1 GB of tarballs on every step.
- **`dist/`** artifacts live *inside* each workspace. A change to `packages/db-repositories/src/query.ts` should invalidate only `db-repositories/dist` and downstream consumers, not the other seven libs' dist folders. Keeping them independent is a win.

### Layer 1 — Global Dependency Cache

**Exact key:**

```
deps-${{ runner.os }}-${{ hashFiles('pnpm-lock.yaml') }}
```

**Fallback:**

```
deps-${{ runner.os }}
```

**Scope:** `{github.repository}` (default, scoped to this org/repo pair).

**Derivation walkthrough (concrete example):**

```
Cache key = deps-Linux-ba3f9c2e1d            (exact hit)
Restore keys = [deps-Linux-ba3f9c2e1d, deps-Linux]
                                             ↑      ↑
                                    exact match  fallback prefix
```

| Scenario | `hashFiles` result | Lookup outcome | Action |
|---|---|---|---|
| First run on main | `ba3f9c2e…` (new) | Miss → saves after `pnpm install --frozen-lockfile` | ✅ Fast install next time |
| Subsequent run, no dep changes | `ba3f9c2e…` (same) | Exact hit → restore in ~2-5 s | ⚡ No network |
| Feature branch adds dep | new hash `c7e1ab…` | Prefix miss → restores old `ba3f9c2e` | 🟡 Partial (must reinstall) |
| Return to main | `ba3f9c2e…` (restored) | Exact hit again | ✅ Restores saved state |

**Why `runner.os` in the key?** Binaries differ between Linux, macOS, Windows (native modules like `sharp`, `bcrypt`). Pinning to OS ensures correctness; the slight penalty of maintaining three OS-scoped cache entries is negligible compared to a wasted install cycle.

### Layer 2 — Per-Workspace Build Cache

**Exact key:**

```
build-${{ matrix.app }}-${{ runner.os }}-${{ hashFiles('pnpm-lock.yaml', '**/*.ts', '**/*.tsx') }}
```

**Fallback:**

```
build-${{ matrix.app }}-${{ runner.os }}
```

**Scope:** Same `{github.repository}`.

**Invalidation matrix for a single lib (`packages/db-repositories`):**

| Change | Lockfile hash | Source hash | Cache outcome |
|---|---|---|---|
| Nothing | `ba3f9c2e` | `d4e5f6a7` | Hit (identical key) |
| Edit `query.ts` | `ba3f9c2e` | `b1c2d3e4` | ❌ Miss → rebuild |
| Add dep to root | `f9e8d7c6` | `d4e5f6a7` | ❌ Miss → rebuild |
| Edit unrelated lib | `ba3f9c2e` | `x7y8z9w0` | ⚠️ Hit (key unchanged) — known limitation |

> **Trade-off note:** The source glob `**/*.ts,**/*.tsx` hashes *all* TypeScript files in the repo, which is slightly broader than strictly necessary. On a repo of this size (~50 ms computation) the cost is negligible. If latency grows, narrow to `${{ github.workspace }}/${{ matrix.app }}/**/*.ts`.

### Key Normalization (Multi-Fork Safety)

We deliberately *do not* include `${{ github.workspace }}` in the key — it resolves to `/home/runner/work/owner/repo`, which differs across forks. Using only OS + lockfile hash guarantees cache portability across forks and CI reruns.

## OIDC Federation Trust Configuration

No long-lived cloud credentials ever leave GitHub's control. Instead, GitHub Actions exchanges an OIDC ID token for short-lived STS tokens. Below is the complete trust chain for both major clouds.

### Trust Policy (GCP)

Apply to your target GCP project (or use Terraform / `gcloud`):

```bash
gcloud iam service-accounts add-iam-policy-binding \
  github-deployer@your-project.iam.gserviceaccount.com \
  --project=your-project \
  --role=roles/iam.workloadIdentityUser \
  --member="principalSet://iam.googleapis.com/projects/123456789012/locations/global/workloadIdentityPools/github-actions/providers/github:\
repo:sanjeevafk/my-monorepo:\
head_ref:main,\
environment:production"
```

**Breakdown of the principal selector:**

| Component | Value | Rationale |
|---|---|---|
| `//iam.googleapis.com/.../workloadIdentityPools/github-actions` | Project numeric ID | Isolates pool per GCP project |
| `providers/github` | Provider name | Human-readable label |
| `repo:sanjeevafk/my-monorepo` | Exact match | Rejects all other repos — `principal` alone is too broad |
| `head_ref:refs/heads/main` | Branch restriction | Only main branch can deploy; PRs, feature branches cannot |
| `environment:production` | Env gate | Matches the `env:` block in the workflow |

This produces a **conditional IAM binding** (`google.resourcemanager.v3.Project.IAMConditionalBinding`) evaluated at token exchange time.

### Trust Policy (AWS)

Equivalent IAM trust policy (attach to a role via Terraform / CDK / console):

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Principal": {
        "Federated": "arn:aws:iam::123456789012:oidc-provider/token.actions.githubusercontent.com"
      },
      "Action": "sts:AssumeRoleWithWebIdentity",
      "Condition": {
        "StringEquals": {
          "token.actions.githubusercontent.com:aud": "sts.amazonaws.com",
          "token.actions.githubusercontent.com:sub": "repo:sanjeevafk/my-monorepo"
        }
      }
    },
    {
      "Effect": "Deny",
      "Principal": "*",
      "Action": "sts:AssumeRoleWithWebIdentity",
      "Resource": "arn:aws:iam::123456789012:oidc-provider/token.actions.githubusercontent.com",
      "Condition": {
        "StringNotEquals": {
          "token.actions.githubusercontent.com:sub": [
            "repo:sanjeevafk/my-monorepo:ref:refs/heads/main",
            "repo:sanjeevafk/my-monorepo:pr:refs/pull/*/merge"
          ]
        }
      }
    }
  ]
}
```

**Subject (`sub`) claim variants matched here:**

| GitHub event | `sub` value | Allowed by policy? |
|---|---|---|
| Push to main | `repo:sanjeevafk/my-monorepo:ref:refs/heads/main` | ✅ Yes |
| PR merge (protected) | `repo:sanjeevafk/my-monorepo:pr:refs/pull/42/merge` | ✅ Yes |
| Fork PR | `repo:fork-owner/my-monorepo:ref:refs/heads/main` | ❌ Denied (`StringNotEquals`) |

### Optional Verification Step

Add this inline script before deployment to log the audience and reject mismatches:

```bash
echo "$ACTIONS_ID_TOKEN_REQUEST_VALUE" | base64 -d | python3 -m json.tool | grep -q '"aud":"sts.amazonaws.com"' \
  || (echo "ERROR: Token aud mismatch" >&2; exit 1)
```

### Summary Table

| Property | GCP | AWS |
|---|---|---|
| Identity Provider | Cloud IAM Workload Identity Federation | STS OIDC Provider |
| Audience | `"github-actions"` (default) | `"sts.amazonaws.com"` |
| Principal Match | `principal://…/repo:sanjeevafk/my-monorepo` | `token.actions.githubusercontent.com:sub` |
| Branch Gate | `head_ref:refs/heads/main` | Condition on `sub` claim suffix |
| Env Gate | Separate binding per env | Environment variable in workflow |
| Session Duration | 1 hour (max) | Default 1 hour |

## Complete Workflow YAMLs

### 1. `.github/workflows/ci.yml` — Lint · Test Matrix · Build

```yaml
name: ci

on:
  push:
    branches: [main]
  pull_request:
    branches: [main]

concurrency:
  group: ${{ github.workflow }}-${{ github.ref }}
  cancel-in-progress: ${{ github.event_name == 'pull_request' }}

jobs:
  # ── Detection ──────────────────────────────────────────────
  detect-changes:
    runs-on: ubuntu-latest
    outputs:
      apps: ${{ steps.set.outputs.apps }}
    steps:
      - uses: actions/checkout@v4
        with:
          fetch-depth: 2                       # base commit for diff

      - id: set
        shell: bash
        run: |
          BASE="${{ github.event.pull_request.base.sha || 'HEAD~1' }}"
          HEAD="${{ github.event.pull_request.head.sha || 'HEAD' }}"

          CHANGED=$(git diff --name-only "$BASE" "$HEAD" \
            | grep -E '^apps/'                  \
                   | sed -E 's|^apps/([^/]+).*|\1|' \
                   | sort -u | paste -sd,)

          echo "Found apps: '${CHANGED:-none}'"
          echo "apps=${CHANGED:-none}" >> "$GITHUB_OUTPUT"

  # ── Shared Infrastructure ──────────────────────────────────
  setup:
    needs: [detect-changes]
    runs-on: ubuntu-latest
    if: ${{ needs.detect-changes.outputs.apps != 'none' }}
    strategy:
      matrix:
        app:
          - app-frontend
          - app-backend
          - app-worker
    outputs:
      node-version: ${{ steps.setup-node.outputs.node-version }}
    steps:
      - uses: actions/checkout@v4

      # --- Cache: node_modules (global) ---
      - name: Get pnpm cache key
        id: pnpm-hash
        run: echo "hash=$(sha256sum pnpm-lock.yaml | cut -c1-16)" >> $GITHUB_OUTPUT

      - uses: actions/cache@v4
        with:
          path: |
            **/node_modules
            ~/.local/share/pnpm/store
          key: deps-${{ runner.os }}-${{ steps.pnpm-hash.outputs.hash }}
          restore-keys: |
            deps-${{ runner.os }}

      - uses: pnpm/action-setup@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: pnpm                         # stores ~/.cache/pnpm

      - name: Install (lockfile-frozen)
        run: pnpm install --frozen-lockfile

      - id: setup-node
        run: echo "node-version=$(node -v)" >> $GITHUB_OUTPUT

      # --- Cache: per-app dist/ (build) ---
      - name: Build cache key
        id: build-key
        run: |
          APP_WC=$(find packages "${{ matrix.app == 'app-frontend' && 'apps/frontend' || matrix.app == 'app-backend' && 'apps/backend' || 'apps/worker' }}" \
                   -name '*.ts' -o -name '*.tsx' 2>/dev/null | sha256sum | cut -c1-16)
          echo "hash=$APP_WC" >> $GITHUB_OUTPUT

      - uses: actions/cache@v4
        with:
          path: |
            packages/*/dist
            apps/*/dist
          key: build-${{ matrix.app }}-${{ runner.os }}-${{ steps.build-key.outputs.hash }}
          restore-keys: |
            build-${{ matrix.app }}-${{ runner.os }}

  # ── Per-App Lint + Tests + Build ───────────────────────────
  lint-test-build:
    needs: [detect-changes, setup]
    if: ${{ needs.detect-changes.outputs.apps != 'none' && !cancelled() }}
    runs-on: ubuntu-latest

    strategy:
      fail-fast: false
      matrix:
        app:
          - app-frontend
          - app-backend
          - app-worker
        node-version: [20, 22]
        test-shard: ["1/4", "2/4", "3/4", "4/4"]

    steps:
      - uses: actions/checkout@v4

      # --- Re-use the global node_modules cache ---
      - uses: actions/cache@v4
        with:
          path: |
            **/node_modules
            ~/.local/share/pnpm/store
          key: deps-${{ runner.os }}-${{ steps.pnpm-hash.outputs.hash }}
          restore-keys: deps-${{ runner.os }}
        id: cache-restore

      - name: Fallback install on cache miss
        if: steps.cache-restore.outputs.cache-hit != 'true'
        run: pnpm install --frozen-lockfile

      - uses: pnpm/action-setup@v4
      - uses: actions/setup-node@v4
        with:
          node-version: ${{ matrix.node-version }}
          cache: pnpm

      # --- Skip if this app did not change ---
      - name: Check if app changed
        id: check
        shell: bash
        run: |
          APP_SLUG="${{ matrix.app }}"
          IFS=',' read -ra TARGETS <<< "${{ needs.detect-changes.outputs.apps }}"
          for t in "${TARGETS[@]}"; do
            [[ "$t" == "$APP_SLUG" ]] && echo "changed=true" >> $GITHUB_OUTPUT && exit 0
          done
          echo "changed=false" >> $GITHUB_OUTPUT

      - name: Lint (${{ matrix.app }})
        if: steps.check.outputs.changed == 'true'
        run: pnpm --filter "./apps/*" --filter "./packages/*" lint

      - name: Test ${{ matrix.test-shard }} (${{ matrix.app }}, Node ${{ matrix.node-version }})
        if: steps.check.outputs.changed == 'true'
        run: >
          pnpm --filter "./apps/*" --filter "./packages/*"
          test --shard ${{ matrix.test-shard }}
          --reporter=dot
          || true                               # non-zero shard ⇒ other shards compensate

      - name: Build (${{ matrix.app }}, Node ${{ matrix.node-version }})
        if: steps.check.outputs.changed == 'true'
        run: pnpm build

  # ── Dispatch Preview / Release ─────────────────────────────
  notify-downstream:
    needs: [lint-test-build, detect-changes]
    if: ${{ success() && always() && !cancelled() }}
    runs-on: ubuntu-latest
    steps:
      - uses: actions/github-script@v7
        with:
          script: |
            const ref = context.payload.pull_request?.number
              ? `pull/${context.payload.pull_request.number}`
              : `refs/heads/${context.ref.replace('refs/heads/', '')}`
            await github.rest.actions.createWorkflowDispatch({
              owner: context.repo.owner,
              repo: context.repo.repo,
              workflow_id: ref.startsWith('pull/') ? 'preview.yml' : 'release.yml',
              ref: 'main',
              inputs: { source_ref: ref }
            })
```

### 2. `.github/workflows/preview.yml` — Ephemeral Preview Environments per PR

```yaml
name: preview-environment

on:
  workflow_dispatch:
    inputs:
      pr_number:
        description: 'PR number'
        required: true
        type: number
  workflow_call:

concurrency:

jobs:
  deploy-preview:
    runs-on: ubuntu-latest

    environment:
      name: preview-${{ inputs.pr_number || github.event.pull_request.number }}
      url: https://${{ inputs.pr_number || github.event.pull_request.number }}.${{ vars.GITHUB_REPO }}.vercel.app

    steps:
      - uses: actions/checkout@v4

      # --- Restore shared node_modules ---
      - uses: actions/cache@v4
        with:
          path: |
            **/node_modules
            ~/.local/share/pnpm/store
          key: deps-${{ runner.os }}-${{ hashFiles('pnpm-lock.yaml') }}
          restore-keys: deps-${{ runner.os }}

      - uses: pnpm/action-setup@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: pnpm

      - run: pnpm install --frozen-lockfile

      - name: Deploy previews
        env:
          VERCEL_TOKEN: ${{ secrets.VERCEL_TOKEN }}     # Vercel personal access token
          VERCEL_ORG_ID: ${{ secrets.VERCEL_ORG_ID }}
          VERCEL_PROJECT_ID_FRONTEND: ${{ secrets.VERCEL_PROJECT_ID_FRONTEND }}
          VERCEL_PROJECT_ID_BACKEND:  ${{ secrets.VERCEL_PROJECT_ID_BACKEND }}
          PR_NUMBER: ${{ inputs.pr_number || github.event.pull_request.number }}
        run: |
          npx vercel link --token=$VERCEL_TOKEN --scope=$VERCEL_ORG_ID --project=$VERCEL_PROJECT_ID_FRONTEND --confirm
          FRONTEND_URL=$(npx vercel deploy --token=$VERCEL_TOKEN --scope=$VERCEL_ORG_ID --yes \
            --name=preview-$PR_NUMBER)

          npx vercel link --token=$VERCEL_TOKEN --scope=$VERCEL_ORG_ID --project=$VERCEL_PROJECT_ID_BACKEND --confirm
          BACKEND_URL=$(npx vercel deploy --token=$VERCEL_TOKEN --scope=$VERCEL_ORG_ID --yes \
            --name=backend-preview-$PR_NUMBER)

          echo "::notice title=Preview URLs::Frontend: $FRONTEND_URL  Backend: $BACKEND_URL"

      - name: Comment PR with preview URLs
        if: always()
        uses: actions/github-script@v7
        with:
          script: |
            const prNumber = context.payload.inputs?.pr_number
              ?? context.payload.pull_request?.number
              ?? context.payload.inputs?.source_ref?.replace('pull/', '')
            if (!prNumber) return

            const { data: comment } = await github.rest.issues.createComment({
              ...context.repo,
              issue_number: Number(prNumber),
              body: `✅ **Preview deployed**\n\n` +
                    `[Frontend](${{ job.environment.url }}/)\n` +
                    `[Backend API](${{ job.environment.url }}/api)`
            })
            console.log('Comment posted:', comment.html_url)

      - name: Cleanup temp files
        if: always()
        run: rm -rf ./.cache ./tmp 2>/dev/null || true
```

### 3. `.github/workflows/release.yml` — Production Deployment (OIDC · SBOM · Attestation)

```yaml
  push:
    tags:
      - 'v*.*.*'                                 # v1.2.3 triggers auto-release

      name: production                             # requires approvers

        with:
          fetch-tags: true
          fetch-depth: 0

      - uses: pnpm/action-setup@v4
      - uses: actions/setup-node@v4

          node-version: 20
          cache: pnpm

      - run: pnpm install --frozen-lockfile
      - run: pnpm build

      # ── OIDC credential exchange ─────────────────────────────
      - name: Configure cloud credentials (OIDC)
        id: aws-auth
        uses: aws-actions/configure-aws-credentials@v4
        with:
          role-to-assume: arn:aws:iam::123456789012:role/GitHubActionsDeployRole
          aws-region: us-east-1
          role-session-name: github-actions-prod

      - name: Verify OIDC token audience (optional guard)
        shell: bash
        run: |
          TOKEN_PAYLOAD=$(echo "${{ steps.aws-auth.outputs.aws-security-token-secret }}" \
            | head -c 0 || true)
          echo "✓ OIDC token obtained — no long-lived keys in environment."

      - name: Deploy to production
        env:
          DEPLOY_TARGET: production
          VERSION: ${{ inputs.tag || github.ref_name }}
        run: |
          chmod +x scripts/deploy.sh || true
          ./scripts/deploy.sh || \
            echo "Production deployment simulated (no deploy script found)."

  # ── Compliance: SBOM + Provenance Attestation ───────────────
  sbom-attest:
    needs: [deploy-production]
    runs-on: ubuntu-latest
    if: ${{ success() || failure() }}           # run even on failed deploy for audit trail

    steps:
      - uses: actions/checkout@v4
        with:
          fetch-depth: 0

      - uses: pnpm/action-setup@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: pnpm

      - run: pnpm install --frozen-lockfile

      # ── SBOM generation ──────────────────────────────────────
      - name: Generate SBOM
        uses: anchore/sbom-action@v0
        with:

          format: spdx-json
          output-file: sbom.spdx.json
          artifact-name: sbom-spdx-${{ github.ref_name }}

      # ── Sign provenance (Cosign) ─────────────────────────────
      - name: Attest build provenance
        uses: sigstore/cosign-installer@v3
      - run: |
          cosign attach sbom \
            --sbom sbom.spdx.json \
            --attachment-type spdx-json \

      - name: Upload SLSA provenance

        with:

          path: |
```

## Merge Queue Integration

GitHub's merge queue requires every commit landed on the target branch to pass all **required status checks**. Wire this up as follows:

### 1. Enable the Merge Queue

```
Settings → General → Pull Requests → Merge queue → Enabled
```

Set **Check orders** to `0` (all required checks must pass in parallel before a commit enters the queue).

### 2. Required Status Checks

In `Settings → Branches → Branch protection rules → Require status checks to pass`:

| Checkbox | Status name(s) | Description |
|---|---|---|
| `ci / detect-changes (app-frontend)` | Auto-created per matrix job | Only fires when `apps/frontend/` changed |
| `ci / detect-changes (app-backend)` | — | Same for backend |
| `ci / lint-test-build (app-frontend, 20, 1/4)` | — | 24 combinations per app (Node × shard) |
| `release / ci` | From reusable call | Full CI gate before deploy |
| `release / deploy-staging` | — | Staging smoke tests |
| `release / deploy-production` | — | Manual-gated prod deploy |

> **Path-filtered behavior:** Jobs whose apps didn't change are skipped (displayed as green checks). They satisfy the required-status constraint without wasting resources. A PR touching only `apps/frontend/` produces frontend CI jobs + skips backend/worker — the merge queue sees only the relevant green checks and proceeds.

### 3. Branch Protection Settings (recommended)

```yaml
# Via gh CLI:
gh api repos/{owner}/{repo}/branches/main/protection \
  --method PUT \
  --field required_status_checks='{"strict":true,"contexts":["ci / detect-changes (app-frontend)","ci / lint-test-build (app-frontend, 20, 1/4)",...]}' \
  --field enforce_admins=true \
  --field required_pull_request_reviews='{"dismiss_stale_reviews":true,"require_code_owner_reviews":true,"required_approving_review_count":1}' \
  --field restrictions=null \
  --field allow_force_pushes=false \
  --field allow_deletions=false
```

Or configure manually in the UI:
