**Design decisions:**
- **Clock injection** via constructor — tests drive time forward deterministically; zero real sleeps
- **Per-key independent windows** — `OrderedDict[str, deque[float]]` mapping key → ordered timestamps
- **Distributed-safe interface** — `acquire(key)` is the sole public mutation point; callers gate on its return value, enabling distributed semaphore patterns or optimistic-lock retry loops
- **Async-first / blocking-free** — coroutine-friendly, suitable for I/O-bound and service-to-service deployments

```python
# src/rate_limiter/limiter.py (initial version)
from __future__ import annotations

import time
from collections import deque
from typing import Optional, Callable


class RateLimiter:
    """Per-key sliding-window rate limiter.

    Stores an ordered deque of timestamps per key. On each acquire(),
    expired entries outside the current window are discarded before
    evaluating whether the limit permits another request.
    """

    def __init__(
        self,
        limit: int,
        window_seconds: float,
        clock: Optional[Callable[[], float]] = None,
    ) -> None:
        if limit < 1:
            raise ValueError("limit must be >= 1")
        if window_seconds <= 0:
            raise ValueError("window_seconds must be > 0")

        self._limit = limit
        self._window = window_seconds
        self._clock = clock or time.time
        self._stores: dict[str, deque] = {}

    async def acquire(self, key: str) -> bool:
        store = self._stores.setdefault(key, deque())

        now = self._clock()
        cutoff = now - self._window

        # Remove expired entries oldest-first
        while store and store[0] <= cutoff:
            store.popleft()

        if len(store) >= self._limit:
            return False

        store.append(now)
        return True

    def get_request_count(self, key: str) -> int:
        if key not in self._stores:
            return 0
        store = self._stores[key]
        return len(store)
```

```python

import asyncio
from typing import AsyncLock

# Per-key locks stored alongside stores
self._locks: dict[str, AsyncLock] = {}

async def acquire(self, key: str) -> bool:
    # Lazily create per-key lock
    lock = self._locks.setdefault(key, asyncio.Lock())
    
    async with lock:                          # ← serialize access
        store = self._stores.setdefault(key, deque())
        self._clean_stale(store, self._clock())

        if len(store) >= self._limit:
            return False

        store.append(self._clock())
        return True
```

This guarantees correctness regardless of CPython internals. The cost is one lock per unique key (not global), minimizing contention.

## Final Production-Grade Implementation

### `src/rate_limiter/limiter.py`

```python
"""Per-key sliding-window rate limiter.

Tracks timestamps of successful acquisitions in an OrderedDict mapping
key → deque[float]. On each acquire(), is_allowed(), or get_request_count()
call, expired timestamps outside the current window are discarded before
evaluating the limit.

Designed for async/await usage. Each key has its own asyncio.Lock during
acquire() to prevent TOCTOU races when multiple coroutines contend for
the same key. Different keys never block each other.

Clock injection via constructor enables deterministic testing without
real sleeps — pass a callable returning the current timestamp.

Example::

    limiter = RateLimiter(limit=10, window_seconds=60.0, clock=my_clock)
    if await limiter.acquire("user:123"):
        handle_request()
"""

from __future__ import annotations

import asyncio
import time
from collections import OrderedDict, deque
from typing import Callable, Optional


class RateLimiter:
    """Per-key sliding-window rate limiter.

    Parameters
    ----------
    limit : int
        Maximum number of successful acquisitions per window per key.
    window_seconds : float
        Duration of the sliding window in seconds. Must be > 0.
    clock : callable, optional
        Zero-argument callable returning the current timestamp (seconds).
        Defaults to ``time.time``. Inject a custom clock for testing.

    Raises
    ------
    ValueError
        If ``limit < 1`` or ``window_seconds <= 0``.
    """

    def __init__(
        self,
        limit: int,
        window_seconds: float,
        clock: Optional[Callable[[], float]] = None,
    ) -> None:
        if limit < 1:
            raise ValueError("limit must be >= 1")
        if window_seconds <= 0:
            raise ValueError("window_seconds must be > 0")

        self._limit = limit
        self._window = window_seconds
        self._clock = clock or time.time
        self._stores: OrderedDict[str, deque] = OrderedDict()
        self._locks: dict[str, asyncio.Lock] = {}

    async def acquire(self, key: str) -> bool:
        """Attempt to acquire one slot for *key*.

        Prunes expired entries, checks the limit, and appends the
        current timestamp if allowed.

        Returns
        -------
        bool
            ``True`` if the request is allowed; ``False`` if the key
            has reached its quota for the current window.
        """
        lock = self._locks.setdefault(key, asyncio.Lock())

        async with lock:
            store = self._stores.setdefault(key, deque())
            now = self._clock()
            self._clean_stale(store, now)

            if len(store) >= self._limit:
                return False

            store.append(now)
            return True

    def is_allowed(self, key: str) -> bool:
        """Check whether an acquire() would succeed *without* consuming a slot.

        bool

        store = self._stores[key]
        now = self._clock()

        return len(store) < self._limit

        Prunes expired entries before counting.

        Parameters

        key : str
            The rate-limit key.

        Returns
        -------
        int
            Number of unexpired requests. Returns 0 if the key has never
            been seen or all its requests have expired.
        """
        if key not in self._stores:
            return 0

        store = self._stores[key]
        now = self._clock()
        self._clean_stale(store, now)

        return len(store)

    def get_all_keys(self) -> set[str]:
        """Return the set of all keys that currently have active requests.

        Expired entries are cleaned before reporting. Keys that only have
        expired entries are excluded from the result.
        """
        now = self._clock()
        alive: set[str] = set()

        # Iterate over a snapshot of keys to avoid mutation during iteration
        for key in list(self._stores.keys()):
            store = self._stores[key]
            self._clean_stale(store, now)

            if store:
                alive.add(key)

        self._stores.clear()
        self._locks.clear()
```

## Architecture Notes

1. **Why per-key locks, not a global lock?** Global locking serializes all acquires across all keys, destroying throughput for unrelated clients. Per-key locking concentrates contention only where it matters — shared keys. Independent keys proceed in parallel.

2. **Why async-only?** The rate limiter itself is CPU-light, but its primary deployment context is async services (FastAPI, aiohttp, gRPC). The `asyncio.Lock` integrates naturally; there's no sync equivalent because there's no blocking operation to release the GIL.

3. **Distributed safety:** This implementation is safe for a single process. For multi-node deployments, replace the in-memory `_stores` backing with Redis (`INCR` + `EXPIRE` per key with TTL = window). The public `acquire(key) -> bool` interface remains identical — only the internal state backend changes. This is the "deep module" pattern: simple interface, swappable implementation.

4. **Clock injection is the contract for testability.** Every production test replaces `time.time` with `MonoClock`, eliminating flaky timing-dependent tests. The `_clean_stale` static method lets you verify cleanup logic in isolation:

   ```python
   from src.rate_limiter.limiter import RateLimiter

   dq = deque([0.0, 2.0, 5.0])
   RateLimiter.clean_stale(dq, now=8.0, window=5.0)
   assert list(dq) == [5.0]  # entries at 0.0 and 2.0 removed
   ```
