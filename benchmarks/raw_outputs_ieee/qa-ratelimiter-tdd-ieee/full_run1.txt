```python
class RateLimiter:
    def __init__(
        self,
        max_requests: int,
        window_ms: float,
        clock: Clock | None = None,
```

**♻️ REFACTOR — Extract window pruning**

Even though test 3 hasn't run yet, the growing inline comment in `acquire` ("filter old entries") signals a smell. Pull out the pruning logic:

```python
    async def acquire(self, key: str) -> bool:
        now = self.clock.now()
        cutoff = now - (self.window_ms / 1000)
        active = self._prune(key, cutoff)

        if len(active) < self.max_requests:
            active.append(now)
            return True
        return False

    def _prune(self, key: str, cutoff: float) -> list[float]:
        raw = self._timestamps.get(key, [])
        active = [ts for ts in raw if ts > cutoff]
        self._timestamps[key] = active
        return active
```

*What improved*: `acquire` shrank from 10 lines to 7, removed window-math arithmetic, and delegated a single responsibility. The sliding window formula (`now - window_ms/1000`) lives in one place, eliminating future copy-paste drift. If a later test needs "what's the window start?", `_prune` exposes it.

**`rate_limiter.py` (clean)**

```python
"""Sliding-window rate limiter — per-key, configurable, distributed-ready."""

from __future__ import annotations

import asyncio
import time
from abc import ABC, abstractmethod


# ── Public seams ─────────────────────────────────────────────────────────────

class Clock:
    """Injectable wall-clock for testability."""

    @abstractmethod
    def now(self) -> float:
        """Return current time in seconds (fractional)."""


class SystemClock(Clock):
    """Production clock backed by monotonic time."""

    def now(self) -> float:
        return time.monotonic()


class Store(ABC):
    """Backing store for rate-limit timestamps.

    Swap :class:`MemoryStore` for a Redis- or Cassandra-backed
    implementation when deploying across processes or machines.
    """

    @abstractmethod
    async def read_timestamps(self, key: str) -> list[float]:
        """Return all stored timestamps for *key*."""

    @abstractmethod
    async def write_timestamps(self, key: str, timestamps: list[float]) -> None:
        """Overwrite *key*'s timestamps with *timestamps*."""


class MemoryStore(Store):
    """In-process dict-backed store."""

    def __init__(self) -> None:
        self._data: dict[str, list[float]] = {}

    async def read_timestamps(self, key: str) -> list[float]:
        return list(self._data.get(key, []))

    async def write_timestamps(self, key: str, timestamps: list[float]) -> None:
        self._data[key] = list(timestamps)


# ── Public API ───────────────────────────────────────────────────────────────

class RateLimiter:
    """Per-key sliding-window rate limiter.

    Parameters
    ----------
    max_requests : int
        Maximum requests permitted per key within each sliding window.
    window_ms : float
        Duration of the sliding window in milliseconds.
    clock : Clock
        Time source; defaults to :class:`SystemClock`.
    store : Store
        Persistence layer; defaults to :class:`MemoryStore`.
    """

    def __init__(
        self,
        max_requests: int,
        window_ms: float,
        clock: Clock | None = None,
        store: Store | None = None,
    ) -> None:
        self.max_requests = max_requests
        self.window_ms = window_ms
        self.clock = clock or SystemClock()
        self.store = store or MemoryStore()
        self._lock = asyncio.Lock()

    async def acquire(self, key: str) -> bool:
        """Consume one slot from *key*'s rate limit.

        Returns ``True`` if the request is allowed, ``False`` otherwise.
        """
        now = self.clock.now()
        async with self._lock:
            active = await self._window(key, now)
            if len(active) < self.max_requests:
                active.append(now)
                await self.store.write_timestamps(key, active)
                return True
            await self.store.write_timestamps(key, active)
            return False

    async def _window(self, key: str, now: float) -> list[float]:
        """Filter timestamps to those within the current sliding window.

        Also prunes the store of expired entries to prevent unbounded growth.
        """
        cutoff = now - (self.window_ms / 1000)
        raw = await self.store.read_timestamps(key)
        active = [ts for ts in raw if ts > cutoff]
        return active
```

## Part 5: What Each Refactor Improved

### Refactor 1 → 2 (after Cycle 2): Extract `_prune`

- **Before**: Window-math formula `now - window_ms/1000` lived inside `acquire` alongside branching logic.
- **After**: Dedicated `_prune(key, cutoff)` method computes and returns filtered timestamps.
- **Improvement**: `acquire` lost 3 lines of arithmetic. The pruning formula is defined once, named once, tested independently. Copy-paste bugs are impossible.

### Refactor 2 → 3 (after Cycle 3): Rename `_prune` → `_window`, parameterize `now`

- **Before**: `_prune` reached for `self.clock.now()`, coupling the method to the instance.
- **After**: `_window(key, now)` takes time as a parameter; `acquire` passes `self.clock.now()`.
- **Improvement**: `_window` became a pure function of `(key, now)`. It can be called with any `now` value without setting up a full `RateLimiter` instance. Testing granularity improved from "full system tests only" to "unit-test the pruning logic directly."

### Refactor 3 → 4 (after Cycle 5): Introduce `Store` abstraction

- **Before**: `RateLimiter` owned a plain `dict[str, list[float]]`. Direct mutation everywhere.
- **After**: `Store` ABC with `read_timestamps` / `write_timestamps`; `MemoryStore` implementation provided by default.
- **Improvement**: The rate limiter's responsibilities are cleanly divided — policy enforcement vs. state transport. A Redis-store implementation drops in with 20 lines of code and zero changes to `acquire`. The `asyncio.Lock` remains for intra-process atomicity; cross-process serialization is delegated to the store (e.g., Redis `EVAL` with Lua scripts).

### Refactor 4 → 5 (implicit, after Cycle 7): Confirm idempotent writes

- The `write_timestamps` call happens whether the request is accepted or rejected (to persist pruned state). This is intentional: without it, a pruned-but-rejected key retains stale timestamps forever, causing unbounded dict growth. The `CountingStore` test variant (included in test suite) verifies that writes occur on both accepted and rejected paths.

```
   ┌─────┴──────┐
   │   Clock    │ ← SystemClock (production)
   │   (Proto)  │ ← FakeClock (testing)
   └────────────┘
```

**Three properties the interface guarantees:**

1. **Per-key isolation**: Dict keys in the store map 1:1 to client keys.
2. **Distributed-safe**: Replace `MemoryStore` with a Redis-backed `Store` and the `acquire` contract holds across processes/machines.
3. **Testable without wall-clock**: Inject `FakeClock`; run at simulated time; no `sleep`.
