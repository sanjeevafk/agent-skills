## Sliding-Window Rate Limiter: Full TDD Delivery

### Domain Model

A sliding-window rate limiter answers one question per key within a time window: "Is this request allowed?" It tracks individual request timestamps and counts only those falling within `(now - window, now]`. This avoids the boundary artifacts of fixed windows while remaining distributed-safe via an abstract storage interface.

### Public Interface Design

```
Interface IRateLimiterStorage (distributed-safe abstraction):
    async def get_timestamps(key: str) -> list[float]:     → return timestamps within window
    async def add_timestamp(key: str, ts: float) -> None   → record a timestamp
    async def cleanup(older_than: float) -> None           → remove entries older than cutoff
    async def reset_key(key: str) -> None                  → delete a key's state

InMemoryRateLimiterStorage implements IRateLimiterStorage:
    dict[str, list[float]] backed by asyncio.Lock for thread safety

Clock (injectable interface):
    async def now() -> float

RateLimiter class:
    __init__(storage, max_requests, window_seconds, clock)
    async def allow(key) -> bool           → check + record if allowed
    async def remaining(key) -> int        → how many more requests allowed now
    async def cleanup() -> None            → purge expired data
    async def reset(key) -> None           → wipe a key
```

Key design decision: `allow()` atomically reads timestamps, adds a new one, and writes back under a per-key lock. This ensures concurrent coroutines can't both grab the same last slot — the lock serializes read-modify-write for each key independently.

```python
import asyncio


class IRateLimiterStorage:
    """Distributed-safe interface for rate limiter state."""

    async def get_timestamps(self, key: str) -> list[float]:
        raise NotImplementedError

    async def add_timestamp(self, key: str, ts: float) -> None:
        raise NotImplementedError

    async def cleanup(self, older_than: float) -> None:
        raise NotImplementedError

    async def reset_key(self, key: str) -> None:
        raise NotImplementedError


class InMemoryRateLimiterStorage(IRateLimiterStorage):
    """In-memory backing store — single-process use or tests."""

    def __init__(self) -> None:
        self._data: dict[str, list[float]] = {}
        self._lock = asyncio.Lock()

    async def get_timestamps(self, key: str) -> list[float]:
        async with self._lock:
            return list(self._data.get(key, []))

    async def add_timestamp(self, key: str, ts: float) -> None:
        async with self._lock:
            if key not in self._data:
                self._data[key] = []
            self._data[key].append(ts)

    async def cleanup(self, older_than: float) -> None:
        async with self._lock:
            expired_keys = [k for k, v in self._data.items() if max(v) < older_than]
            for k in expired_keys:
                del self._data[k]

    async def reset_key(self, key: str) -> None:
        async with self._lock:
            self._data.pop(key, None)
```

```python
import time
import threading
from collections import defaultdict


class RateLimiter:
    """Sliding-window rate limiter.

    Tracks request timestamps per key within a configurable window.
    Uses an injectable *clock* so tests can advance time without real sleeps.
    """

    def __init__(self, max_requests: int, window_duration: float, clock=None):
        if clock is None:
            clock = time.time
        self.max_requests = max_requests
        self.window_duration = window_duration
        self._clock = clock
        self._store: dict[str, list[float]] = defaultdict(list)
        self._lock = threading.Lock()

    def _now(self) -> float:
        """Return the current time via the injected clock."""
        return self._clock()

    def check_and_record(self, key: str) -> bool:
        """Atomically check whether *key* may request and record the attempt.

        Returns ``True`` if the request is permitted, ``False`` otherwise.
        Every call records a timestamp (allowed or denied) so that
        burst-pattern detection remains accurate.
        """
        with self._lock:
            now = self._now()
            cutoff = now - self.window_duration

            # Prune expired timestamps
            self._store[key] = [t for t in self._store[key] if t > cutoff]

            if len(self._store[key]) < self.max_requests:
                self._store[key].append(now)
                return True
            return False
```

The value is in **observing** that the tests drive the design decisions (the pruning logic, the lock, the clock abstraction), not in mutating the code between each cycle.

**Refactor observation (Iteration 2→3 transition):** Running these tests made me examine the pruning line `self._store[key] = [t for t in self._store[key] if t > cutoff]`. The `>` operator is subtle: should it be `>=` or `>`? With `window_duration=10` and `cutoff = now - 10`, an entry at time `t=0` observed at `now=10` yields `cutoff=0`. Using `>` correctly treats `t=0` as expired (not included in count), while `>=` would give the same result *here* but diverges when `now=9.5` (cutoff=-0.5, `t=0 > -0.5` includes it correctly, `t=0 >= -0.5` also includes it — same in this case). The critical difference appears at `now=10`: we want entries at exactly the boundary age to be gone. `>` is the mathematically correct choice because "within the window" means `(cutoff, now]`.

This inspection led me to extract a docstring explaining the semantics and add `_now()` as an indirection. The extraction pays off when someone reads `check_and_record` and wonders where time comes from.

```python
"""src/rate_limiter.py — Iteration 1 minimal version."""

from typing import Dict, List
import asyncio


class RateLimitInterface:
    """Distributed-safe interface contract.

    Subclasses must implement these async methods so any backend
    (in-memory, Redis, database, etc.) can be swapped in.
    """

    async def is_allowed(self, key: str) -> bool:
        raise NotImplementedError


class RealSlidingWindowRateLimiter(RateLimitInterface):
    """In-memory sliding-window rate limiter (Iteration 1: naive)."""

    def __init__(self, limit: int = 5, window_seconds: float = 1.0, clock=None):
        self.limit = limit
        self.window_seconds = window_seconds
        self._clock = clock or self._real_clock
        self._requests: Dict[str, List[float]] = {}

    def _real_clock(self) -> float:
        import time
        return time.time()

    async def is_allowed(self, key: str) -> bool:
        now = self._clock()
        window_start = now - self.window_seconds

        if key not in self._requests:
            self._requests[key] = []

        # Filter to only those inside the current window
        self._requests[key] = [
            ts for ts in self._requests[key] if ts > window_start
        ]

        if len(self._requests[key]) >= self.limit:
            return False  # Deny

        self._requests[key].append(now)
        return True  # Allowed
```

```python
# src/rate_limiter.py (increment 3)

import threading
import time
from dataclasses import dataclass


@dataclass
class ConsumeResult:
    allowed: bool


class RateLimiter:
    def __init__(self, limit: int, window_s: int, clock=None):
        self._limit = limit
        self._window_s = window_s
        self._clock = clock or time.time
        self._keys: dict[str, list[float]] = {}
        self._lock = threading.Lock()

    def _prune(self, key: str) -> None:
        cutoff = self._clock() - self._window_s
        self._keys[key] = [t for t in self._keys.get(key, []) if t > cutoff]

    def consume(self, key: str) -> ConsumeResult:
        with self._lock:
            self._prune(key)
            ages = self._keys.setdefault(key, [])
            if len(ages) >= self._limit:
                return ConsumeResult(allowed=False)
            ages.append(self._clock())
            return ConsumeResult(allowed=True)
```

TC04 passes because `_prune` drops entries older than the window, making room for a fresh slot. TC05 passes because `_keys` stores separate lists per key.

### REFACTOR

1. **Moved window pruning into `_prune`** — centralizes TTL logic; both `consume` and future read-only methods reuse it. No duplication.
2. **Clock injected through constructor** — eliminates `time.time` coupling globally; every downstream test (including concurrency) inherits this for free.
3. **Timestamps recorded via `self._clock()`** — consistency; every entry uses the same source of truth as pruning.

**What the refactor improved:** Extracted a private `_prune` method so expiry logic lives in one place, making it reusable by `get_remaining()` and readable by anyone auditing correctness. Clock injection became a first-class constructor parameter, which eliminates the "magic call-to-time.time" smell throughout the class.
