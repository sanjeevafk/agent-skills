**The current design fails under multi-process deployments and leaves the server vulnerable to unauthenticated DoS, timing leaks, and double-processing race conditions.**

**1 → In-memory replay ledger causes double-processing in production.** A Python `dict` is local to a single worker process and wipes on restart, allowing duplicate concurrent webhooks across multiple Uvicorn workers or server instances to execute the payment logic twice.

**2 → Parsing JSON before HMAC verification allows unauthenticated resource exhaustion.** Parsing the request body prior to authentication lets attackers flood the endpoint with malformed or nested JSON payloads that consume memory and CPU without a valid signature.

**3 → Single-secret verification and non-constant-time comparisons break key rotation and leak timing data.** Verifying with standard equality (`==`) leaks key timing signatures, while supporting only one key causes dropped webhooks during provider secret rotation grace periods.

**4 → Unsanitized error bubbling leaks internal architecture and stack traces.** Propagating internal processing or database exceptions directly to the webhook caller exposes backend details and third-party credentials.

import hmac
import json
import logging
from typing import List
from fastapi import FastAPI, Header, HTTPException, Request, Response, status
from redis import asyncio as aioredis

logger = logging.getLogger("webhook")
app = FastAPI()

# Configure Redis connection for distributed locking and replay tracking
redis_client = aioredis.Redis(host="localhost", port=6379, db=0, decode_responses=True)

# Support multiple secrets during rotation (primary, grace period keys)
ACTIVE_WEBHOOK_SECRETS: List[str] = ["secret_v2_current", "secret_v1_retiring"]
SIGNATURE_HEADER = "X-Signature-SHA256"
EVENT_LOCK_TTL_SECONDS = 86400  # 24 hours retention for event IDs


def verify_hmac_signature(raw_body: bytes, signature_header: str | None, secrets: List[str]) -> bool:
    if not signature_header or not secrets:
        return False
    
    # Strip prefix if provider prefixes hash (e.g. 'sha256=...')
    provided_signature = signature_header.removeprefix("sha256=").strip()

    for secret in secrets:
        computed_hmac = hmac.new(
            secret.encode("utf-8"),
            raw_body,
            hashlib.sha256
        ).hexdigest()
        
        # Constant-time comparison prevents timing attacks
        if hmac.compare_digest(computed_hmac, provided_signature):
            return True
            
    return False
