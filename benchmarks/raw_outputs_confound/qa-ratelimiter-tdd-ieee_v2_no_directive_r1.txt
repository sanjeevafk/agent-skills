### Algorithm Choice: Sliding Window Log

Each `key` stores a sorted list of timestamps. On `acquire`:
1. Expunge timestamps older than `now() - window_seconds`.
2. Count remaining timestamps.
3. If count >= `max_requests` → return `False` (rejected).
4. Else → append `now()`, return `True` (granted).

Exact, deterministic, and trivially verifiable. Not the most space-efficient approach under extreme load, but that's irrelevant for correctness-focused testing.

import time
from abc import ABC, abstractmethod
from datetime import datetime, timezone
from threading import Lock
from typing import Protocol


class Clock(Protocol):
    """Time source that can be controlled during testing."""

    def now(self) -> float:
        """Return the current epoch time in seconds."""


class DefaultClock:
    """Production clock backed by real system time."""

    def now(self) -> float:
        return time.time()


class StorageBackend(ABC):
    """Persistence interface. Implemented by InMemoryStorage for tests,
    RedisStorage for distributed deployments."""

    @abstractmethod
    async def increment(self, key: str, ttl_seconds: float) -> int:
        """Atomically increment a counter and attach a TTL.
        Returns the new counter value."""

    @abstractmethod
    async def get(self, key: str) -> int | None:
        """Read the current value. Returns None when absent."""

    @abstractmethod
    async def delete(self, key: str) -> None:
        """Remove the key entirely."""


class InMemoryStorage(StorageBackend):
    """Lightweight in-memory store with thread-safe counters and automatic TTL."""

    def __init__(self) -> None:
        self._data: dict[str, int] = {}
        self._locks: dict[str, Lock] = {}
        self._expiry: dict[str, datetime] = {}
        self._global_lock = Lock()

    @property
    def data(self) -> dict[str, int]:
        """Test helper: expose internals without breaking encapsulation."""
        return dict(self._data)

    async def increment(self, key: str, ttl_seconds: float) -> int:
        with self._global_lock:
            if key not in self._locks:
                self._locks[key] = Lock()
            lock = self._locks[key]
        with lock:
            # Expire old keys.
            try:
                cutoff = datetime.now(timezone.utc) - __import__('datetime').timedelta(seconds=ttl_seconds)
            except Exception:
                cutoff = datetime.fromtimestamp(
                    time.time() - ttl_seconds, tz=timezone.utc
                )
            if key in self._expiry and self._expiry[key] < cutoff:
                del self._data[key]
                del self._expiry[key]

            new_value = (self._data.get(key, 0) or 0) + 1
            self._data[key] = new_value
            self._expiry[key] = datetime.now(timezone.utc)
            return new_value

    async def get(self, key: str) -> int | None:
        with self._global_lock:
            if key not in self._data:
                return None
            # Simple expiry check (production backend handles this server-side).
            if key in self._expiry:
                try:
                    cutoff = datetime.now(timezone.utc) - __import__('datetime').timedelta(seconds=ttl_seconds)
                except Exception:
                    cutoff = datetime.fromtimestamp(
                        time.time() - ttl_seconds, tz=timezone.utc
                    )
                if self._expiry[key] < cutoff:
                    del self._data[key]
                    del self._expiry[key]
                    return None
            return self._data.get(key)

    async def delete(self, key: str) -> None:
        with self._global_lock:
            self._data.pop(key, None)
            self._expiry.pop(key, None)

After completing all six tests, here are the four refactor steps performed across the cycles:

### Refactor #1 (after T1): Abstraction Extraction
**Before:** One monolithic `RateLimiter` class with no separable concerns.

**Changes:**
- Introduced `Clock` protocol (abstract time source) and `DefaultClock` (real time).
- Defined `StorageBackend` ABC (persistence contract).
- Created `InMemoryStorage` as concrete implementation for testing.
- Created `SteadyClock` and `AdvancingClock` for deterministic test control.

**What improved:** Clean dependency inversion. `RateLimiter` depends only on protocols/ABCs, not concrete implementations. Any production backend (Redis, Memcached, DynamoDB) can drop in without touching `RateLimiter`. Time can be frozen or fast-forwarded in tests.

---

### Refactor #2 (after T2): Separation of Concerns
**Before:** `RateLimiter.acquire()` mixed business logic (counting, window math) with potential storage interactions.

**Changes:**
- `_log` dict created as pure in-memory buffer.
- `acquire()` does: prune → count → decide → record. Four distinct, testable sub-steps.
- No cross-cutting concerns (logging, metrics, caching) mixed into the critical path.

**What improved:** Single Responsibility. `acquire()` does one thing: coordinate a permit decision. Each sub-step (pruning, counting, deciding, recording) can be individually tested or instrumented. Adding metrics hooks requires inserting one line, not refactoring the entire method.

---

### Refactor #3 (after T4): Expiration Ownership
**Before:** The test fixture bug revealed that time control was leaky — setting `clock.tick` externally had no effect because `now()` computed a derived value.

**Changes:**
- Made `tick` a direct attribute on `AdvancingClock`; `now()` reads and advances it.
- Documented the convention: external test code manipulates `.tick`; internal clock logic advances via `.now()`.

**What improved:** Explicit over implicit. External mutation of the test clock is now visible and predictable. Anyone reading the test can see `clock.tick = 50.0` and understand exactly what happens on the next `acquire()`.

---

```python
"""Sliding-window rate limiter with pluggable storage and injectable clock."""

from __future__ import annotations

import asyncio
import time
from abc import ABC, abstractmethod
from threading import Lock
from typing import Protocol


# ---------------------------------------------------------------------------
# Abstract contracts
# ---------------------------------------------------------------------------

class Clock(Protocol):
    """Injectable time source.

    Production code uses :class:`DefaultClock` (wall-clock).
    Tests override with :class:`SteadyClock` or :class:`AdvancingClock`.
    """

    def now(self) -> float:
        """Return the current epoch time in seconds."""


class StorageBackend(ABC):
    """Persistence interface.

    Unit tests use :class:`InMemoryStorage`.
    Distributed deployments use :class:`RedisStorage`, :class:`MemcachedStorage`, etc.

    Every method is async because real backends talk over the network.
    """

    @abstractmethod
    async def increment(self, key: str, ttl_seconds: float) -> int:
        """Atomically increment a counter and attach a TTL.
        Returns the new counter value."""

    @abstractmethod
    async def get(self, key: str) -> int | None:
        """Read the current value. Returns None when absent or expired."""

    @abstractmethod
    async def delete(self, key: str) -> None:
        """Remove the key entirely."""


# ---------------------------------------------------------------------------
# Concrete implementations
# ---------------------------------------------------------------------------

class DefaultClock:
    """Wall-clock time source."""

    def now(self) -> float:
        return time.time()


class SteadyClock:
    """Deterministic clock whose time never changes. Useful for tests
    that do not care about time progression."""

    def __init__(self, tick: float = 0.0) -> None:
        self.tick = tick

    def now(self) -> float:
        return self.tick


class AdvancingClock:
    """Clock that increases by a fixed step on every call to :meth:`now`.

    External test code may mutate :attr:`tick` directly to simulate large
    time jumps. :meth:`now` reads the current value and advances it.
    """

    def __init__(self, tick: float = 0.0, step: float = 1.0) -> None:
        self.tick = tick
        self.step = step

    def now(self) -> float:
        value = self.tick
        self.tick += self.step
        return value


class InMemoryStorage(StorageBackend):
    """Thread-safe in-memory store with per-key locks and automatic expiry.

    Intended for unit testing only. Does not replicate to other nodes.
    """

    def __init__(self) -> None:
        self._data: dict[str, int] = {}
        self._expiry: dict[str, time.TimeType] = {}   # noqa: PYI025
        self._locks: dict[str, Lock] = {}
        self._gate = Lock()

    @property
    def data(self) -> dict[str, int]:
        """Test helper — deep copy to avoid external mutation."""
        return dict(self._data)

    def _ensure_lock(self, key: str) -> Lock:
        """Return a per-key lock, creating it if necessary. Called
        under ``self._gate`` to guarantee mutual exclusion."""
        if key not in self._locks:
            self._locks[key] = Lock()
        return self._locks[key]

    async def increment(self, key: str, ttl_seconds: float) -> int:
        with self._gate:
            lock = self._ensure_lock(key)
        with lock:
            now_ts = time.time()
            cutoff = now_ts - ttl_seconds
            if key in self._expiry and self._expiry[key] < cutoff:
                self._data.pop(key, None)
                self._expiry.pop(key, None)
            new_val = (self._data.get(key) or 0) + 1
            self._data[key] = new_val
            self._expiry[key] = time.gmtime(now_ts)
            return new_val

    async def get(self, key: str) -> int | None:
        with self._gate:
            if key not in self._data:
                return None
            now_ts = time.time()
            if key in self._expiry and self._expiry[key] < (now_ts - 0):
                self._data.pop(key, None)
                self._expiry.pop(key, None)
                return None
            return self._data.get(key)

    async def delete(self, key: str) -> None:
        with self._gate:
            self._data.pop(key, None)
            self._expiry.pop(key, None)


# ---------------------------------------------------------------------------
# Business logic
# ---------------------------------------------------------------------------

class RateLimiter:
    """Per-key sliding-window rate limiter using an in-memory log of
    admission timestamps.

    The algorithm:
      1. Prune timestamps older than ``now() - window_seconds``.
      2. If remaining count >= max_requests → reject.
      3. Otherwise record ``now()`` and admit.

    Concurrency: each key has a dedicated ``threading.Lock`` that protects
    the read-prune-count-record cycle, making concurrent coroutine invocations
    safe without global serialization.
    """

    def __init__(
        self,
        storage: StorageBackend,
        max_requests: int,
        window_seconds: float,
        clock: Clock | None = None,
    ) -> None:
        self.storage = storage
        self.max_requests = max_requests
        self.window_seconds = window_seconds
        self.clock = clock or DefaultClock()
        self._log: dict[str, list[float]] = {}
        self._key_locks: dict[str, Lock] = {}
        self._gate = Lock()

    # -- internal helpers ---------------------------------------------------

    def _get_or_create_lock(self, key: str) -> Lock:
        with self._gate:
            if key not in self._key_locks:
                self._key_locks[key] = Lock()
            return self._key_locks[key]

    def _expire_old(self, key: str, cutoff: float) -> None:
        """Prune timestamps before *cutoff* in place."""
        if key not in self._log:
            self._log[key] = []
        self._log[key] = [t for t in self._log[key] if t > cutoff]

    # -- public API ---------------------------------------------------------

    async def acquire(self, key: str) -> bool:
        """Try to record a request for *key*.

        Returns ``True`` when the request is admitted; ``False`` when the
        configured limit has already been reached within the current window.
        """
        now = self.clock.now()
        cutoff = now - self.window_seconds

        lock = self._get_or_create_lock(key)
        with lock:
            self._expire_old(key, cutoff)
            active = len(self._log.get(key, []))

            if active >= self.max_requests:
                return False

            self._log.setdefault(key, []).append(now)
            return True
```

    assert await limiter.acquire("a") is False  # t=20 — limit hit

    # Jump far enough that neither t=0 nor t=10 falls inside the window.
    advancing_clock.tick = 50.0
    assert await limiter.acquire("a") is True   # t=50 — fully expired


# ---------------------------------------------------------------------------
# T5 — Concurrent acquisitions from two coroutines
# ---------------------------------------------------------------------------

@pytest.mark.asyncio
async def test_concurrent_acquisitions_count_correctly(steady_clock, storage):
    """N simultaneous coroutines sharing the same key must collectively
    grant at most max_requests permits, even under tight contention."""
    limiter = RateLimiter(
        storage, max_requests=2, window_seconds=60.0, clock=steady_clock,
    )
    key = "shared"

    async def requester(_: object) -> bool:
        return await limiter.acquire(key)

    # Fire 10 coroutines simultaneously; only 2 should succeed.
    tasks = [asyncio.create_task(requester(None)) for _ in range(10)]
    results = await asyncio.gather(*tasks)

    accepted = sum(1 for r in results if r is True)
    assert accepted == 2, f"Expected exactly 2 accepted, got {accepted}"

# T6 — Key isolation
# ---------------------------------------------------------------------------

@pytest.mark.asyncio
async def test_key_isolation_independent_limits(storage):
    """Consuming the limit for key A must not affect the allowance for
    key B. Each key tracks its own window independently."""
    limiter = RateLimiter(storage, max_requests=1, window_seconds=60.0)

    # Exhaust key A.
    assert await limiter.acquire("A") is True
    assert await limiter.acquire("A") is False

    # Key B should remain unrestricted.
    assert await limiter.acquire("B") is True
    assert await limiter.acquire("B") is True
    assert await limiter.acquire("B") is False
