### Quality Assessment Against Standards

**Vertical slice approach**: The tests are organized as tracer bullets — each one validates a single behavioral unit. This is exactly right. However, note that all 13 bullets' tests already exist rather than being built incrementally one-at-a-time with implementation between each cycle. That said, the structure itself follows vertical-slice discipline.

**Behavior over implementation**: Tests verify through public interfaces (`state`, `history`, `transition()`, `current_state`) — not internal data structures. Renaming `_TRANSITION_RULES` or switching from dict to some other mapping wouldn't break any test. Good.

**Integration-style testing**: Tests use real state machine code paths, not mocks (except for callback handlers in TB-9). Concurrent tests exercise actual threading. The test reads like a spec: "user can transition draft→pending", "concurrent races resolved without deadlock."

**Coverage gaps worth noting**:
- No explicit test for `ACTIVE → PAST_DUE → PENDING → ACTIVE` reactivation loop (the `resume → pending → activate` round-trip). You have the individual steps but not the chained reactivation.
- No negative thread-safety case where more than 2 threads race simultaneously.
- No test verifying that `_notify_handlers` logs exceptions at ERROR level (TB-9 isolates them, but doesn't assert on the log output).

### Implementation Review

The FSM implementation is clean and production-grade:

- **`SubscriptionState`** — enum-backed str for clear domain language
- **`TransitionEvent`** — frozen dataclass, immutable domain event with arrow notation repr (`draft→pending`)
- **`_TRANSITION_RULES` / `_ACTION_TARGETS`** — flat config-driven transition table, easy to extend
- **`SubscriptionStateMachine`** — RLock-protected, handler-observable, history-tracked, timeout-aware
- **`trigger_transition("auto_cancel")`** — separates timeout logic from regular transitions, supports injected `now` for deterministic testing
- **Naive datetime handling** — coerced to UTC rather than crashing

Everything looks solid.
