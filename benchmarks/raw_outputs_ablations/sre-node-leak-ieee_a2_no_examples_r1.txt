## Node.js RSS Memory Leak Diagnosis Plan — Step by Step

### Phase 1: Capture Heap Snapshots in Production Safely

#### 1.1 Use `--heapsnapshot` signal instead of CLI tools in prod

```bash
# Send SIGUSR2 to trigger a heap snapshot — no extra deps needed
kill -SIGUSR2 <pid>
```

This writes `<name>-<timestamp>.heapsnapshot` to `/tmp` or wherever Node was invoked. In Kubernetes:

```yaml
# pod level: ensure /tmp is large enough or set HEAPSNAPDIR
env:
  - name: NODE_OPTIONS
    value: "--max-old-space-size=1800"  # leave headroom before OOM limit
```

To write to a persistent volume you can monitor from a sidecar:

```js
// Add this early in bootstrap (one-time only, throttle to avoid disk fill)
process.on('SIGUSR2', () => {
  const snapshotDir = process.env.HEAPSNAP_DIR || '/var/log/heap';
  const filename = `heap-${Date.now()}.heapsnapshot`;
  fs.mkdirSync(snapshotDir, { recursive: true });
  // Write throttled: max 2 per hour via an in-process flag
  if (!this._recording && Date.now() - this._lastSnapshot > 3600000) {
    this._recording = true;
    this._lastSnapshot = Date.now();
    const writer = fs.createWriteStream(path.join(snapshotDir, filename));
    const agent = new v8.getHeapSnapshotAgent(writer);
    writer.on('finish', () => { this._recording = false; });
  }
});
```

**Why not `--heapsnapshot-signal=SIGUSR2` in Docker?** It works fine. The concern is disk space. Rate-limit to 2-3 snapshots over the observation window (6h apart as stated).

#### 1.2 Capture strategy

| Snapshot | Timing | Purpose |
|----------|--------|---------|
| S1 | Baseline (restart) | Cold state reference |
| S2 | ~24h after restart | First growth point |
| S3 | ~48h or before OOM | Pre-mortem final state |
| S4 | Immediately after OOM kill (if coredump enabled) | Last known good |

#### 1.3 Diffing snapshots locally

Transfer `.heapsnapshot` files out of the cluster (they're plain JSON):

```bash
kubectl cp ns/pod:/tmp/heap-S2.heapsnapshot .
kubectl cp ns/pod:/tmp/heap-S3.heapsnapshot .
```

Open each in Chrome DevTools → Memory tab → select "Comparison" mode or use the built-in diff view:

```
DevTools: Select both snapshots → click "Difference" view
Key metric: Look at "Detached DOM trees" equivalent for JS — 
objects retained but unreachable from global scope roots.
```

Alternatively, use `node --inspect` to load into a local devtools instance without Chrome:

```bash
node --inspect-devtools profile-reporter.mjs heap-S2.heapsnapshot
```

Or programmatically:

```js
// diff_snapshots.js
const { readFileSync } = require('fs');
const snapA = JSON.parse(readFileSync('heap-S2.heapsnapshot'));
const snapB = JSON.parse(readFileSync('heap-S3.heapsnapshot'));

const byTypeA = {};
for (const obj of snapA.nodes.objects) byTypeA[obj.name] = obj.size;

const byTypeB = {};
for (const obj of snapB.nodes.objects) byTypeB[obj.name] = obj.size;

console.log('Growing types (bytes):');
for (const [type, sizeB] of Object.entries(byTypeB)) {
  const sizeA = byTypeA[type] ?? 0;
  const delta = sizeB - sizeA;
  if (delta > 0) console.log(`${type}: +${(delta/1e6).toFixed(1)}MB (${sizeA}→${sizeB})`);
}
```

For detailed object-level diffs, use [`heapdump`](https://www.npmjs.com/package/heapdump) with [`memwatch-next`](https://www.npmjs.com/package/memwatch-next) or the built-in `v8.getHeapSpaceStatistics()` for monitoring.

### Phase 2: Identify Retainer Chains

#### 2.1 For Closure Retentions (event-emitter registry)

In Chrome DevTools Memory panel:

1. Load the snapshot → switch to **Summary** view
2. Type filter: enter `closure` or `script` to isolate closure objects
3. Click a representative closure → switch to **Retainers** pane
4. Walk up the tree. You're looking for:
   - A `ListenerArray` or similar structure
   - Underlying source: an `EventEmitter` instance whose `_events` map has grown entries

The canonical Node.js `EventEmitter` internal structure (`internal/event_target.js`):

```
EventEmitter instance
  └─ _events: Map<string, Function[] | Function>      ← HERE — leaked listeners
     └─ "data": [fn1, fn2, fn3, ... fn_n]             ← accumulated over time
        └─ each fn captures `this` or lexical scope    ← closure retention chain
```

**Specifically look for**: Any `on()` call where the callback references:
- A class instance (`this`)
- Large objects from closures (request/response bodies, DB results)
- Loop variables captured by `setTimeout`/Promises

#### 2.2 For Buffer Retentions

1. Filter objects by type: `Uint8Array` or `DataView` (Buffer is a typed array backing)
2. Check retainers for patterns like:
   - Arrays being pushed to repeatedly
   - Objects referenced by middleware closures
   - `res.end(Buffer.from(data))` where `data` is cached somewhere

3. Use the **Comparison** view: filter to show only objects present in S3 but not S2 → these are newly allocated and never freed

**Quick runtime check** (drop-in addition to the service):

```js
// buffer_leak_detector.js — require/import near startup
setInterval(() => {
  const stats = process.memoryUsage();
  console.log(`[leak-detector] rss=${(stats.rss/1e6).toFixed(0)}MB heapUsed=${(stats.heapUsed/1e6).toFixed(0)}MB heapTotal=${(stats.heapTotal/1e6).toFixed(0)}MB external=${(stats.external/1e6).toFixed(0)}MB`);
}, 30_000);

// Detect unbounded arrays (common accumulator bug)
const ProxyMonitor = (() => {
  const tracked = new WeakSet();
  return function watch(obj, label) {
    if (tracked.has(obj)) return obj;
    tracked.add(obj);
    return new Proxy(obj, {
      set(target, prop, value) {
        if (Array.isArray(target) && typeof prop === 'number' && !isNaN(Number(prop))) {
          if (target.length > 10000) {
            console.warn(`[array-leak] ${label} grew to ${target.length} elements at`, new Error().stack?.split('\n').slice(1,4).join('\n'));
          }
        }
        target[prop] = value;
        return true;
      }
    });
  };
})();
```

#### 2.3 Programmatic retainer query

```js
// query_retainers.js
function run() {
  // Force GC first
  global.gc?.();
  
  const snapshot = v8.getHeapSnapshot();
  let chunks = '';
  snapshot.readChunk(32 * 1024, 0, (c, sz) => { if (c) chunks += c; });
  
  const reader = new v8.SnapshotReader(chunks);
  const iter = reader.iterateObjectsOverRange(0, reader.nodesCount);
  
  const closures = [];
  const buffers = [];
  
  while (iter.next()) {
    const obj = iter.current();
    if (obj.type === 'Closure' && obj.shallowSize > 100) {
      closures.push({ constructor: obj.constructorName, size: obj.shallowSize, selfSize: obj.selfSize });
    }
    if (obj.type === 'JSBuffer' || obj.constructorName === 'ArrayBuffer') {
      buffers.push({ size: obj.shallowSize });
    }
  }
  
  console.log(`Found ${closures.length} closures > 100 bytes, total: ${(closures.reduce((a,c)=>a+c.shallowSize,0)/1e6).toFixed(2)}MB`);
  console.log(`Found ${buffers.length} buffers, total: ${(buffers.reduce((a,b)=>a+b.size,0)/1e6).toFixed(2)}MB`);
}
```

### Phase 3: Confirm Emitter Registry Leaks

#### 3.1 Monkey-patch EventEmitter to detect leaks

```js
// emit_leak_detector.js — require at module boot
const { EventEmitter } = require('events');
const originalOn = EventEmitter.prototype.on;
const originalAddListener = EventEmitter.prototype.addListener;
const listenerLog = new Map();

EventEmitter.prototype.on = function(event, listener) {
  const key = `${this.constructor.name}:${event}:${this.uuid ?? this}`;
  const count = listenerLog.get(key) ?? 0;
  listenerLog.set(key, count + 1);
  
  if (count > 50) {
    const stack = new Error().stack?.split('\n').slice(2, 8).join('\n');
    console.error(`[emit-leak] ${key} now at ${count+1} listeners:\n${stack}`);
  }
  return originalOn.call(this, event, listener);
};

EventEmitter.prototype.addListener = function(event, listener) {
  // Same logic as .on()
  return originalAddListener.call(this, event, listener);
};

// Periodic report
setInterval(() => {
  const leakers = [...listenerLog.entries()]
    .filter(([, n]) => n > 10)
    .sort((a, b) => b[1] - a[1])
    .slice(0, 20);
  if (leakers.length > 0) {
    console.error('[emit-leak report] Top accumulating emitters/events:');
    leakers.forEach(([key, n]) => console.error(`  ${key}: ${n} registrations`));
  }
}, 60_000);

// Cleanup hook
process.on('beforeExit', () => {
  console.error(`\n[emit-leak final] Total unique event registrations logged: ${listenerLog.size}`);
});
```

#### 3.2 Check the specific event-emitter registry mentioned

If there's a custom listener store (not raw `EventEmitter`), search for patterns:

```bash
grep -rn "\.on\(" src/ --include="*.ts" --include="*.js" | grep -v node_modules | head -50
```

Look specifically for:
```js
// Anti-patterns to find:
emitter.on('message', async (msg) => { ... });  // anonymous async → never removed
bus.subscribe(event, createHandler(ctx));         // handler factory called every registration
stream.on('data', chunk => buffer.push(chunk));   // buffer grows indefinitely
```

Check for `removeAllListeners()`, `off()`, or cleanup hooks in the lifecycle:

```bash
grep -rn "removeAllListeners\|\.off(\|destroy()" src/ --include="*.ts" --include="*.js"
```

If none exist alongside the `on()` calls, that's the leak.

### Phase 4: Diagnose Response-Logging Middleware Buffer Leak

#### 4.1 Typical patterns and root causes

**Pattern A — Accumulator array in middleware:**
```js
// REQUEST LOG MIDDLEWARE (buggy)
const responseBodyLog = [];  // ← never cleared

app.use(async (req, res, next) => {
  const originalEnd = res.end.bind(res);
  res.end = function(chunk, encoding) {
    if (chunk) {
      const body = Buffer.isBuffer(chunk) ? chunk : Buffer.from(String(chunk));
      responseBodyLog.push(body);  // ← pushes Buffer forever
    }
    originalEnd(chunk, encoding);
  };
  next();
});
```

**Pattern B — Closure capturing request/response:**
```js
eventEmitter.on('response', (req, resBody) => {
  const logEntry = {
    timestamp: Date.now(),
    url: req.url,           // req object holds everything
    body: resBody,          // potentially large payload
    headers: req.headers,   // duplicate data
  };
  logs.push(logEntry);  // ← unbounded array of logged responses
});
```

**Pattern C — Writable stream not drained:**
```js
const logStream = fs.createWriteStream('/dev/null');  // intentional sink?

app.use((req, res, next) => {
  const origWrite = res.write.bind(res);
  res.write = (chunk) => {
    logStream.write(JSON.stringify({ url: req.url, size: chunk.length }) + '\n');
    // But also pipes chunk somewhere else that retains it?
    return origWrite(chunk);
  };
  next();
});
```

### Phase 5: Root Causes and Fixes

#### Fix 1 — Listener accumulation

```js
// BEFORE (leaking):
connection.on('data', handleMessage(connection));  // creates new handler per connection

// AFTER (fixed):
const handlers = new Map();  // keyed by connection ID
connection.on('data', handlers.get(id) || handlers.set(id, createHandler()).get(id));
connection.once('end', () => handlers.delete(id));
```

Use `.once()` where appropriate. Implement explicit cleanup:

```js
class ManagedEmitter extends EventEmitter {
  destroy() {
    this.removeAllListeners();
    super.destroy?.();
  }
}
```

Or use a cleanup framework like [`emittery`](https://github.com/sindresorhus/emittery) which supports auto-remove on dispose.

#### Fix 2 — Response body buffering

```js
// BEFORE (leaking):
const responseBodyAccumulator = [];
app.use(responseLoggerMiddleware(responseBodyAccumulator));

// AFTER (fixed — bounded, ring-buffer):
const MAX_LOGGED_RESPONSES = 1000;
const responseBodyRing = new FixedLengthQueue(MAX_LOGGED_RESPONSES);

app.use((req, res, next) => {
  const originalEnd = res.end.bind(res);
  const chunks = [];
  
  res.end = function(chunk, encoding) {
    if (chunk) chunks.push(Buffer.from(chunk));
    originalEnd(chunk, encoding);
    
    // Only log after response completes, then discard
    if (chunks.length > 0) {
      const body = Buffer.concat(chunks);
      responseBodyRing.push({
        url: req.url,
        method: req.method,
        statusCode: res.statusCode,
        size: body.length,
        // Don't store full body unless error
        ...(res.statusCode >= 500 ? { body: body.toString('utf8').slice(0, 4096) } : {}),
      });
    }
  };
  next();
});
```

Where `FixedLengthQueue` is:

```js
class FixedLengthQueue {
  constructor(maxSize) {
    this.queue = [];
    this.maxSize = maxSize;
  }
  push(item) {
    if (this.queue.length >= this.maxSize) {
      this.queue.shift();  // O(n) but acceptable for <= 10K items
    }
    this.queue.push(item);
  }
}
```

#### Fix 3 — Preventative architecture changes

```js
// Global guardrail — add once at app boot:
const LEAK_THRESHOLD = 0.8; // 80% of max-old-space-size

function startMemoryGuard() {
  setInterval(() => {
    const used = process.memoryUsage().heapUsed;
    const limit = parseInt(process.execArgv.find(a => a.includes('--max-old')) ?? '', 10) || 1700;
    const ratio = used / (limit * 1024 * 1024);
    
    if (ratio > LEAK_THRESHOLD) {
      console.error(`[memory-guard] Heap usage at ${(ratio*100).toFixed(1)}% — triggering graceful drain`);
      // Emit warning, optionally begin draining connections
      metrics.increment('memory.guard.threshold_exceeded');
    }
    
    if (ratio > 0.95) {
      console.error('[memory-guard] CRITICAL — initiating forced cleanup');
      global.gc?.();  // if --expose-gc
      metrics.increment('memory.guard.critical');
    }
  }, 10_000);
}
```

#### Fix 4 — Connection pooling and emitter lifecycle management

```js
// Ensure all emitters have finite lifecycles:
class RequestContext {
  constructor() {
    this.emitter = new EventEmitter();
    this.cleanedUp = false;
  }
  
  on(event, handler) {
    const wrapped = (...args) => {
      if (this.cleanedException) return;
      return handler(...args);
    };
    // Track so we can remove later
    this['_' + event] = this['_' + event] || [];
    this['_' + event].push([wrapped, handler]);
    
    this.emitter.on(event, wrapped);
    return this;
  }
  
  async cleanup() {
    if (this.cleanedException) return;
    this.cleanedException = true;
    
    for (const [wrapped, original] of this['_close'] || []) {
      this.emitter.removeListener('close', wrapped);
    }
    this.emitter.removeAllListeners();
  }
}
```
