Done! Created `tp53_lookup.py` — a single-file Python script (stdlib + requests only) that:

- **UniProt lookup**: Fetches full TP53 entry (`P04637`) via `/uniprot/{accession}`, extracts sequence, organism, gene names, protein length, checksum, function descriptions, catalytic activities, and cross-references
- **Ensembl mapping**: Extracts Ensembl Gene IDs from UniProt's embedded xrefs (database=`"Ensembl"`, id starts with `"ENSG"`), with a fallback note if unavailable
- **PubChem lookup**: Gets aspirin CID via PUG REST `/compound/name/aspirin/cids/JSON`
- **Pagination demo**: `paginate_uniprot_search()` walks pages of UniProt search results using offset/limit, collecting until fewer than PAGE_SIZE records are returned (last page signal)
- **Retry logic**: `RetrySession.request()` retries 429 (respects `Retry-After` header) and 5xx with exponential backoff up to 3 attempts (capped at 64s). Does *not* retry client errors.
- **Error handling**: 404 → returns structured error dict (protein not found / compound not found); 429 → waits per Retry-After or backs off; 5xx → retries then fails visible; JSON parse errors caught separately
- **Output**: Single JSON report with `retrieval_summary`, `results` (protein, ensembl_mapping, compound_lookup, pagination_example), and `provenance` (endpoints, parameters, local filters, warnings)
