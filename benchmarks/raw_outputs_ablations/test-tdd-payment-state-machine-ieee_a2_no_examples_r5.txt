Before I start coding, I need to align on scope and priorities since the engineering standards require it. Here's what I'm planning:

**Proposed Design:**

```
billing_fsm/
├── __init__.py          # exports: SubscriptionFSM, State, BillingEvent, DomainEvent
├── states.py             # State enum: Draft, Pending, Active, PastDue, Canceled
├── events.py             # BillingEvent base + concrete domain events
├── fsm.py                # SubscriptionFSM — the state machine core
└── timeout_policy.py     # Timeout config & trigger mechanism
```

**State Transition Model:**
```
Draft ──activate──▶ Pending ──confirm_payment──▶ Active ──payment_failed──▶ PastDue ──timeout──▶ Canceled
                          │                        │                       │               ▲        │
                          │                        ├──recover──────────────┘               │        │
                          ▼                        │                                       │        │
                     validation_error           cancel──▶                             cancel──▶ Canceled
                                                                                              (terminal)
```

**Behaviors to test (prioritized — I'll do vertical slices, not all-at-once):**

1. **Happy path**: Draft → Pending → Active (core activation flow)
2. **Invalid transitions**: e.g., Draft → Active (skipping Pending), double-activation
3. **Payment lifecycle**: Active → PastDue → Active (recovery), PastDue → Canceled (timeout)
4. **Cancellation**: Active → Canceled, PastDue → Canceled, Canceled → anything (rejected)
5. **Timeout triggering**: PastDue auto-transitions to Canceled after configurable duration
6. **Concurrent transitions**: Thread-safe — two simultaneous transition attempts must serialize properly
7. **Domain events**: Every valid transition emits the correct typed event

**TDD Approach**: One test → one implementation → refactor → next test. Not "all tests then all code."

Does this design and priority order look right? Any transitions missing or wrong? Once approved, I'll start with the Draft→Pending→Active happy path.
