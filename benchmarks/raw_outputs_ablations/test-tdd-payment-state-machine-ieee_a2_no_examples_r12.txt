## Implementation Summary

**`skills/billing/fsm.py`** (~130 lines) — the domain module:

- **`SubscriptionState`** — str enum with five billing states (DRAFT, PENDING, ACTIVE, PAST_DUE, CANCELED)
- **`TransitionEvent`** — frozen dataclass carrying source, target, timestamp, and optional extra metadata; clean `→` arrow repr
- **`InvalidTransitionError`** — ValueError subclass for rejected transitions
- **`_TRANSITIONS`** — canonical transition table driving all validation (single source of truth)
- **`SubscriptionStateMachine`** — the FSM with:
  - `current_state` / `history` properties (history returns immutable copy)
  - `transition(action)` — validates via `_TRANSITIONS`, emits event, notifies handlers, thread-safe via RLock
  - `trigger_transition(action, now=...)` — special-case dispatch for `auto_cancel` timeout trigger
  - `_handle_auto_cancel(now)` — enforces 24-hour grace period, only from PENDING, coerces naive datetimes
  - `on_transition(handler)` / `remove_transition_handler(handler)` — callback system; handler exceptions are logged but don't crash other handlers
