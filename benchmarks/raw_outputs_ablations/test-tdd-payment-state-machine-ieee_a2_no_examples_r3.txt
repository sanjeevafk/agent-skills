## Implementation (`skills/billing/fsm.py`)

**Domain primitives:**
- `SubscriptionState` — frozen enum: `DRAFT`, `PENDING`, `ACTIVE`, `PAST_DUE`, `CANCELED`
- `InvalidTransitionError` — raised on blocked or unknown actions
- `TransitionEvent` — frozen dataclass with `source`, `target`, `timestamp`, `extra`; readable `→` notation in repr
- `TIMEOUT_GRACE_PERIOD_SECONDS` = 86400 (24 hours)

**`SubscriptionStateMachine`:**
- Dataclass with `state`, `created_at`, thread-safe RLock
- `_TRANSITION_RULES` configures which actions are valid from each state
- `_ACTION_TARGETS` maps actions to target state values
- `transition(action)` — validates against rules, emits event, notifies handlers
- `trigger_transition(action, now=...)` — dispatches `auto_cancel` timeout logic or delegates to `transition()`
- `_handle_auto_cancel()` — rejects if not PENDING, checks elapsed >= grace period, creates event with `reason="grace_period_expired"`
- `on_transition(handler)` / `remove_transition_handler(handler)` — pub/sub with dedup and exception isolation
- `history` property returns defensive copy; `current_state` accessor
