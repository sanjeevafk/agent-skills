### Implementation (`skills/billing/fsm.py`) — Production-grade

- **`SubscriptionState`** — StrEnum with 5 states (DRAFT → PENDING → ACTIVE → PAST_DUE → CANCELED)
- **`InvalidTransitionError(ValueError)`** — Custom exception for blocked transitions
- **`TransitionEvent`** — Frozen dataclass with source, target, UTC timestamp, and extra metadata dict
- **`SubscriptionStateMachine`** — Thread-safe FSM using `threading.RLock`:
  - `transition(action)` — Public API for direct state changes
  - `trigger_transition(action, now=...)` — Dispatchs to `transition()` or handles `auto_cancel` with grace period enforcement
  - `on_transition(handler)` / `remove_transition_handler(handler)` — Callback registration pattern
  - `history` property — Returns a defensive copy of `list[TransitionEvent]`
  - `current_state` property — Read-only access to current state
- **Configuration-driven transitions** — `_TRANSITION_RULES` maps action names to allowed source states; `_ACTION_TARGETS` maps actions to target states — easy to extend
- **Timeout support** — `TIMEOUT_GRACE_PERIOD_SECONDS = 86400` (24h); `auto_cancel` only fires from PENDING when elapsed ≥ grace period, with detailed error messages showing remaining seconds
