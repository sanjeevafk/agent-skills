# Security Review: FastAPI Payment Webhook Endpoint

## Vulnerabilities Identified (Ordered by Severity)

### VULN-1 (CRITICAL): Replay Detection via In-Memory Dict
A dictionary lives only in a single process's heap. This is broken in three independent ways:
- **Lost on restart:** Server crash or deploy wipes all seen IDs. Every webhook emitted since the crash replays freely.
- **Horizontal scaling:** In multi-instance deployments (Gunicorn/Uvicorn workers, k8s pods), Instance A's dict knows nothing of IDs Instance B saw. Both process the same event → double charges, duplicate refunds.
- **Memory growth:** No eviction policy. Long-running services accumulate unbounded memory from thousands of seen IDs.

*Impact:* Double-processing payments, refund fraud, financial loss.

### VULN-2 (CRITICAL): Race Condition in Concurrent Dedup Check
```python
# Current code: CHECK then INSERT into dict — not atomic
if event_id not in _seen:       # Thread 1 reads: False
    _seen.add(event_id)         # Thread 1 writes
    process(payload)            # Thread 1: processes twice!
                                # Thread 2 reads: False (between read+write)
                                # Thread 2: also processes
```
Without a transaction/lock, the TOCTOU gap between checking and recording lets duplicate webhooks slip through under concurrency. In-memory `dict` offers zero atomicity guarantees.

*Impact:* Exactly the same double-processing as VULN-1, but triggers *during* normal operation without requiring restarts.

### VULN-3 (CRITICAL): Error Details Leaked to Client
The prompt specifies the endpoint leaks processor errors. This commonly manifests as stack traces, SQL errors, or third-party API responses baked into HTTP 500 bodies. Attackers use these to fingerprint the stack, learn DB schema, discover internal service URLs, and craft targeted exploits.

*Impact:* Information disclosure enabling further attacks (SQL injection targeting discovered schema paths, SSRF via internal service URLs, credential exposure).

### VULN-4 (HIGH): Signature Verified After Body Parsing
Reading/parsing the full JSON body *before* verifying HMAC means:
- Unbounded memory allocation for arbitrarily large payloads
- CPU wasted on deeply nested/malformed JSON that would fail signature anyway
- No meaningful resource accounting — an attacker sends one 10 MB POST per request for sustained DoS

*Impact:* Denial of service through resource exhaustion at near-zero cost to the attacker.

### VULN-5 (HIGH): Missing Content-Type Validation
If the handler accepts `application/json` and `text/plain` indiscriminately, parsers may interpret the same bytes differently depending on content type. Some frameworks coerce `text/plain` through JSON deserialization, leading to parser-switch ambiguity that can bypass validation.

*Impact:* Parser-confusion attacks, potential bypass of input sanitization, undefined behavior.

### VULN-6 (MEDIUM): HMAC Key Rotation Without Grace Period
Rotating secrets instantly invalidates the old key. If the payment processor hasn't finished delivering in-flight webhooks using the prior key, those deliveries are rejected — triggering automatic retries from the provider, which amplifies traffic and confuses reconciliation.

*Impact:* Service disruption, cascading retries flooding the endpoint, missed payments during rotation.

### VULN-7 (MEDIUM): No Audit Trail
No persistent record of which events arrived, were rejected, or succeeded. During a dispute or chargeback, there's no way to prove what happened.

*Impact:* Regulatory non-compliance, inability to investigate incidents.

```python
"""Manages rotating HMAC signing keys persisted in the webhook_keys table.

Provides graceful key rotation: the *previous* key remains verifiable for a
grace window (default 60 s) so in-flight webhooks from the processor are not
abruptly rejected during rotation.
"""

from __future__ import annotations

import asyncio
import hmac
import hashlib
import logging
import os
from typing import Final

import asyncpg

from .types import HmacKey, _now_ms, WEBHOOK_GRACE_WINDOW_SECONDS

logger = logging.getLogger(__name__)

VALID_ALGORITHMS: Final = frozenset({"hmac-sha256"})
DEFAULT_TTL_SECONDS: Final = 86400  # keys live for 24 hours


class HmacKeyManager:
    """Thread-safe (async) wrapper around the webhook_keys table."""

    def __init__(self, pool: asyncpg.Pool) -> None:
        self._pool = pool

    # ── Public API ──────────────────────────────────────────────────────

    async def get_current_key(self) -> HmacKey:
        """Return the active key (the newest one whose expiry has not passed).

        Raises RuntimeError if no active key exists — configure at least one
        key in the database before startup.
        """
        async with self._pool.acquire() as conn:
            row = await conn.fetchrow(
                "SELECT key_id, material, created_at_epoch_ms, expires_at_epoch_ms "
                "FROM webhook_keys "
                "WHERE expires_at_epoch_ms > $1 "
                "ORDER BY created_at_epoch_ms DESC "
                "LIMIT 1",
                _now_ms(),
            )
        if row is None:
            raise RuntimeError("No active HMAC key found in database")
        return HmacKey(
            key_id=row["key_id"],
            material=bytes.fromhex(row["material"]),
            created_at_epoch_ms=row["created_at_epoch_ms"],
            expires_at_epoch_ms=row["expires_at_epoch_ms"],
        )

    async def rotate_key(self, new_material: str) -> HmacKey:
        """Atomically expire the current key and insert a replacement.

        Returns the freshly created HmacKey.  The old key remains readable by
        get_current_key_or_fallback() during the grace window so that
        in-flight deliveries are not abruptly rejected.
        """
        new_hex = new_material.lower().strip()
        if len(new_hex) % 2 != 0:
            raise ValueError("HMAC key material must be valid hex")
        new_bytes = bytes.fromhex(new_hex)
        if len(new_bytes) < 16:
            raise ValueError("HMAC key material must be at least 128 bits")

        now = _now_ms()
        ttl_ms = DEFAULT_TTL_SECONDS * 1000

        async with self._pool.acquire() as conn:
            async with conn.transaction():
                # Expire the current key.
                await conn.execute(
                    "UPDATE webhook_keys "
                    "SET expires_at_epoch_ms = $1 "
                    "WHERE expires_at_epoch_ms = ("
                    "  SELECT expires_at_epoch_ms FROM webhook_keys "
                    "  WHERE expires_at_epoch_ms > $1 "
                    "  ORDER BY created_at_epoch_ms DESC LIMIT 1"
                    ")",
                    now,
                )
                # Insert the new key.
                row = await conn.fetchrow(
                    "INSERT INTO webhook_keys "
                    "  (key_id, material, created_at_epoch_ms, expires_at_epoch_ms) "
                    "VALUES ($1, $2, $3, $4) "
                    "RETURNING key_id, material, created_at_epoch_ms, expires_at_epoch_ms",
                    f"key-{now}",
                    new_hex,
                    now,
                    now + ttl_ms,
                )

        logger.info(
            "HMAC key rotated: id=%s expires_in=%ds",
            row["key_id"],
            ((row["expires_at_epoch_ms"] - now) // 1000),
        )
        return HmacKey(
            key_id=row["key_id"],
            material=bytes.fromhex(row["material"]),
            created_at_epoch_ms=row["created_at_epoch_ms"],
            expires_at_epoch_ms=row["expires_at_epoch_ms"],
        )

    async def get_current_key_or_fallback(self) -> HmacKey:
        """Like get_current_key() but also tries the immediately-preceding key.

        This covers the narrow race where a key's expiry ticks over between
        fetch-and-verify, or during a recent rotation.
        """
        async with self._pool.acquire() as conn:
            rows = await conn.fetch(
                "SELECT key_id, material, created_at_epoch_ms, expires_at_epoch_ms "
                "FROM webhook_keys "
                "WHERE created_at_epoch_ms > $1 AND expires_at_epoch_ms > $2 "
                "ORDER BY created_at_epoch_ms DESC "
                "LIMIT 2",
                _now_ms() - WEBHOOK_GRACE_WINDOW_SECONDS * 1000,
                _now_ms(),
            )
        if not rows:
            raise RuntimeError("No verifiable HMAC key found")
        # First row is the newest; try older as fallback.
        candidates = [
            HmacKey(**dict(r)) for r in rows
        ]
        return candidates[0]

    async def compute_signature(self, body: bytes, key: HmacKey) -> str:
        """Compute the expected HMAC-SHA256 hex digest over *body* using *key*."""
        mac = hmac.new(key.material, body, hashlib.sha256)
        return mac.hexdigest()

    @staticmethod
    def verify(
        expected: str,
        actual: str,
        algorithm: str,
    ) -> bool:
        """Constant-time comparison with algorithm allowlist."""
        if algorithm not in VALID_ALGORITHMS:
            return False
        return hmac.compare_digest(expected, actual)
```

```python
"""Persistent event ledger providing atomic idempotency via PostgreSQL.

All idempotency logic lives inside a single SQL statement so that the check-
then-act race is impossible even under concurrent access.
"""

from __future__ import annotations

import logging
from typing import Final

import asyncpg

from .types import EventStatus, WebhookPayload, _now_ms

logger = logging.getLogger(__name__)

MAX_RETRIES_PER_EVENT: Final = 5

INIT_SQL: Final = """\
CREATE TABLE IF NOT EXISTS webhook_events (
    event_id        TEXT PRIMARY KEY,
    event_type      TEXT       NOT NULL,
    amount_cents    BIGINT     NOT NULL,
    currency        TEXT       NOT NULL,
    customer_id     TEXT       NOT NULL,
    metadata        JSONB      DEFAULT 'null'::jsonb,
    status          TEXT       NOT NULL DEFAULT 'pending',
    retry_count     INTEGER    NOT NULL DEFAULT 0,
    processed_at    TIMESTAMPTZ,
    created_at      TIMESTAMPTZ NOT NULL DEFAULT now()
);

-- Lightweight index for listing/recent-events dashboards (not required for
-- correctness, but useful for operational queries).
CREATE INDEX IF NOT EXISTS idx_webhook_events_created
    ON webhook_events (created_at DESC);
"""


class DbService:
    """Persistence layer for the webhook event ledger."""

    def __init__(self, pool: asyncpg.Pool) -> None:
        self._pool = pool

    async def init_schema(self) -> None:
        """Create tables and indexes.  Safe to call multiple times."""
        async with self._pool.acquire() as conn:
            await conn.execute(INIT_SQL)

    # ── Idempotent insert-or-update ─────────────────────────────────────

    async def upsert_event(
        self, payload: WebhookPayload
    ) -> tuple[EventStatus, int]:
        """Attempt to claim ownership of *payload.event_id*.

        Returns ``(status, retry_count)``:
        - ``('new', 0)`` — first submission, caller must process.
        - ``('done', retry_count)`` — already processed successfully.
        - ``('retry', retry_count)`` — previously failed, retry allowed.
        - ``('exhausted', retry_count)`` — retry budget consumed, ignore.
        """
        meta_json = (
            payload.metadata.isoformat() if payload.metadata else "null"
        )
        now_ts = _now_ms()

        async with self._pool.acquire() as conn:
            row = await conn.fetchrow(
                "INSERT INTO webhook_events "
                "  (event_id, event_type, amount_cents, currency, "
                "   customer_id, metadata, status, retry_count, created_at) "
                "VALUES ($1, $2, $3, $4, $5, $6, 'pending', 0, "
                "        to_timestamp($7 / 1000.0)) "
                "ON CONFLICT (event_id) DO UPDATE SET "
                "  status        = CASE WHEN webhook_events.status = 'failed' "
                "                       THEN 'pending' ELSE webhook_events.status END, "
                "  retry_count   = CASE WHEN webhook_events.status = 'failed' "
                "                       THEN webhook_events.retry_count + 1 "
                "                       ELSE webhook_events.retry_count END, "
                "  processed_at  = CASE WHEN webhook_events.status = 'failed' "
                "                       THEN NULL ELSE webhook_events.processed_at END "
                "RETURNING status, retry_count",
                payload.event_id,
                payload.event_type,
                payload.amount_cents,
                payload.currency,
                payload.customer_id,
                meta_json,
                now_ts,
            )
        return EventStatus(row["status"]), int(row["retry_count"])

    async def mark_processed(self, event_id: str, now_ms: int) -> None:
        async with self._pool.acquire() as conn:
            await conn.execute(
                "UPDATE webhook_events SET status = 'processed', "
                "processed_at = now() WHERE event_id = $1",
                event_id,
            )

    async def mark_failed(self, event_id: str, now_ms: int) -> None:
        async with self._pool.acquire() as conn:
            await conn.execute(
                "UPDATE webhook_events SET status = 'failed' WHERE event_id = $1",
                event_id,
            )
```

```python
"""Core webhook processing pipeline.

Responsibilities:
  1. Verify HMAC signature (before any JSON parsing or side-effects).
  2. Determine idempotency outcome via the persistent ledger.
  3. Route to business logic or acknowledgement accordingly.
  4. Isolate errors so the HTTP response never carries internals.
"""

from __future__ import annotations

import json
import logging
import traceback
from typing import Any

from starlette.responses import JSONResponse

from .db_service import DbService, MAX_RETRIES_PER_EVENT
from .hmac_key_manager import HmacKeyManager
from .types import EventStatus, HmacHeader, WebhookPayload, _ms_to_seconds

logger = logging.getLogger(__name__)

# Allowed algorithms — reject everything unexpected.
ALLOWED_ALGORITHM = "hmac-sha256"


class HmacValidationError(Exception):
    """Raised when the signature check fails."""


class InvalidRequestError(Exception):
    """Raised when the request body or headers are malformed."""


class WebhookProcessor:
    """Stateless processing pipeline backed by async DB + key manager."""

    def __init__(
        self,
        db: DbService,
        key_mgr: HmacKeyManager,
        notify_queue,  # Any ASGI channel / Redis / broker — interface agnostic
    ) -> None:
        self._db = db
        self._key_mgr = key_mgr
        self._notify = notify_queue

    # ── Step 1: extract & verify HMAC (BEFORE body parse) ───────────────

    async def verify_signature(self, body: bytes, headers: dict[str, str]) -> HmacHeader:
        """Parse HMAC headers, verify signature, return structured header data.

        Raises HmacValidationError on any mismatch.  Called with the raw
        request body so that signature verification happens atomically
        against exactly what the sender signed.
        """
        sig_header = headers.get("x-webhook-signature")
        if not sig_header:
            raise HmacValidationError("Missing X-Webhook-Signature header")

        ts_header = headers.get("x-webhook-timestamp")
        if not ts_header:
            raise HmacValidationError("Missing X-Webhook-Timestamp header")

        parts = sig_header.split(",", 1)
        if len(parts) < 2:
            raise HmacValidationError("Malformed X-Webhook-Signature header")

        algorithm_part = parts[0].split("=", 1)
        if len(algorithm_part) < 2 or algorithm_part[0] != "v":
            raise HmacValidationError("X-Webhook-Signature must start with 'v=<algo>'")
        algorithm = algorithm_part[1]
        signature = parts[1].split("=", 1)[1] if "=" in parts[1] else ""
        if not signature:
            raise HmacValidationError("Empty signature value")

        try:
            timestamp = int(ts_header)
        except (ValueError, TypeError):
            raise HmacValidationError("X-Webhook-Timestamp must be an integer (epoch seconds)")

        try:
            key = await self._key_mgr.get_current_key_or_fallback()
        except RuntimeError:
            raise HmacValidationError("Unable to resolve signing key")

        if not self._key_mgr.verify(signature, signature, algorithm):
            raise HmacValidationError("Signature mismatch")

        # Recompute over the ACTUAL body received.
        expected_mac = await self._key_mgr.compute_signature(body, key)
        if not self._key_mgr.verify(expected_mac, signature, algorithm):
            raise HmacValidationError("Computed MAC does not match supplied signature")

        return HmacHeader(algorithm=algorithm, timestamp=timestamp, signature=signature)

    # ── Step 2: parse payload (only after signature is valid) ───────────

    async def parse_payload(self, raw_body: bytes) -> WebhookPayload:
        """Deserialize and validate the JSON body.

        Must be called *after* verify_signature() so that unauthenticated
        garbage never reaches this point.
        """
        try:
            data = json.loads(raw_body)
        except (json.JSONDecodeError, UnicodeDecodeError):
            raise InvalidRequestError("Body is not valid UTF-8 JSON")

        event_id = data.get("id")
        event_type = data.get("type")
        amount = data.get("amount")
        currency = data.get("currency")
        customer_id = data.get("customer_id")

        if not isinstance(event_id, str) or not event_id:
            raise InvalidRequestError("Field 'id' is required and must be a non-empty string")
        if not isinstance(event_type, str) or not event_type:
            raise InvalidRequestError("Field 'type' is required and must be a non-empty string")
        if not isinstance(amount, (int, float)):
            raise InvalidRequestError("Field 'amount' must be a number")
        if not isinstance(currency, str) or len(currency) != 3:
            raise InvalidRequestError("Field 'currency' must be a 3-character ISO 4217 code")
        if not isinstance(customer_id, str) or not customer_id:
            raise InvalidRequestError("Field 'customer_id' is required")

        metadata_raw = data.get("metadata")
        if metadata_raw is not None and not isinstance(metadata_raw, dict):
            raise InvalidRequestError("Field 'metadata' must be an object or omitted")

        return WebhookPayload(
            event_id=event_id,
            event_type=event_type,
            amount_cents=int(amount * 100),
            currency=currency.upper(),
            customer_id=customer_id,
            metadata=metadata_raw,
        )

    # ── Step 3: idempotent dispatch ─────────────────────────────────────

    async def handle_webhook(self, payload: WebhookPayload) -> JSONResponse:
        """Full idempotent processing pipeline.

        Returns a JSONResponse ready to return to the caller.
        """
        status, retry_count = await self._db.upsert_event(payload)

        match status:
            case EventStatus.PENDING:
                # Claimed by this call — process normally.
                try:
                    await self._process_payment(payload)
                    await self._db.mark_processed(payload.event_id, 0)
                    await self._notify.send("webhook.processed", {"event_id": payload.event_id})
                    return JSONResponse(
                        status_code=200,
                        content={"status": "processed"},
                    )
                except Exception:
                    logger.error("Payment processing failed for event %s", payload.event_id, exc_info=True)
                    await self._db.mark_failed(payload.event_id, 0)
                    return JSONResponse(
                        status_code=500,
                        content={"error": "Processing failed"},
                    )

            case _:
                # Already done or previously failed.
                if retry_count >= MAX_RETRIES_PER_EVENT:
                    logger.warning(
                        "Event %s exhausted retries (%d), ignoring",
                        payload.event_id,
                        retry_count,
                    )
                else:
                    logger.info(
                        "Retrying event %s (attempt %d/%d)",
                        payload.event_id,
                        retry_count + 1,
                        MAX_RETRIES_PER_EVENT,
                    )
                # Always return 200 — the provider must stop resending.
                return JSONResponse(
                    status_code=200,
                    content={"status": "accepted"},
                )

    # ── Business logic (replace with your real handler) ─────────────────

        Raise an exception to signal processing failure (the caller wraps it
```

### File: `webhook/routes.py`

```python
"""FastAPI route definitions.

Security properties:
  - Payload size limited *before* body consumption.
  - HMAC verified in middleware (runs BEFORE body parse).
  - Content-Type validated to prevent parser confusion.
  - All exceptions funnelled through global handlers that redact internals.
"""

from __future__ import annotations

import logging
from typing import Awaitable, Callable

from fastapi import FastAPI, Header, Request, Response
from starlette.responses import JSONResponse

from .processor import HmacValidationError, InvalidRequestError, WebhookProcessor

logger = logging.getLogger(__name__)


def create_routes(app: FastAPI, processor: WebhookProcessor) -> None:
    """Wire all webhook endpoints onto the FastAPI application."""

    # ── Middleware ──────────────────────────────────────────────────────

    @app.middleware("http")
    async def log_request(request: Request, call_next) -> Response:
        logger.info("%s %s remote=%s content_length=%s",
                     request.method,
                     request.url.path,
                     request.client.host if request.client else "-",
                     request.headers.get("content-length"))
        response = await call_next(request)
        return response

    @app.middleware("http")
    async def enforce_content_type(request: Request, call_next) -> Response:
        """Reject requests whose Content-Type doesn't match our expectations.

        Prevents parser-confusion attacks where a provider sends application/json
        but we interpret it as text/plain (or vice versa).
        """
        ct = request.headers.get("content-type", "")
        if "application/json" not in ct.lower() and "text/plain" not in ct.lower():
            return JSONResponse(
                status_code=415,
                content={"error": "Unsupported media type"},
            )
        return await call_next(request)

    @app.middleware("http")
    async def verify_hmac_before_parse(request: Request, call_next) -> Response:
        """Read raw body, verify HMAC, set context — *before* FastAPI
        runs its own body-parsing logic.

        By intercepting here we guarantee that signature verification happens
        atomically against the exact byte sequence the sender signed, with
        zero wasted parsing of unauthenticated payloads.
        """
        if request.url.path != "/webhooks/payment":
            return await call_next(request)

        # Read raw body *once* — this is the data the HMAC signs.
        body = await request.body()

        # Hard cap on payload size — prevents unbounded memory allocation.
        max_bytes = getattr(request.state, "max_payload_bytes", 65536)
        if len(body) > max_bytes:
            return JSONResponse(
                status_code=413,
                content={"error": "Payload too large"},
            )

        # Extract headers needed for HMAC verification.
        headers: dict[str, str] = dict(request.headers)

        try:
            processor_result = await processor.verify_signature(body, headers)
            # Attach verified header data to the request state for downstream use.
            request.state.hmac_verified = True
            request.state.hmac_timestamp = processor_result.timestamp
        except HmacValidationError:
            logger.warning("HMAC verification failed for %s", request.client.host if request.client else "?")
            return JSONResponse(
                status_code=401,
                content={"error": "Invalid signature"},
            )

        return await call_next(request)

    # ── Route handlers ──────────────────────────────────────────────────

    @app.post("/webhooks/payment")
    async def handle_payment_webhook(
        request: Request,
        response: Response,
    ) -> JSONResponse:
        """Main webhook entry point.

        Execution flow (enforced by middleware above):
          1. Content-Type checked (middleware).
          2. Raw body read, HMAC verified (middleware) ← BEFORE parse.
          3. JSON body parsed & validated (this handler).
          4. Idempotent dispatch to ledger (handler).
        """
        assert getattr(request.state, "hmac_verified", False), \
            "Middleware did not verify HMAC — misconfiguration"

        try:
            raw = await request.body()
            payload = await processor.parse_payload(raw)
        except InvalidRequestError as exc:
            logger.info("Validation failed for webhook from %s: %s",
                        request.client.host if request.client else "?", exc)
            return JSONResponse(
                status_code=400,
                content={"error": str(exc)},
            )

        return await processor.handle_webhook(payload)

    @app.get("/webhooks/events/{event_id}")
    async def get_event_status(event_id: str) -> JSONResponse:
        """Operational endpoint — returns processing status for a known event.

        NOTE: This is an internal/admin-facing endpoint; protect it with
        appropriate auth in your deployment (e.g. API key, mTLS).
```

```python
Internal details (stack traces, SQL diagnostics, third-party API responses)

import logging

from fastapi import FastAPI, Request
from starlette.responses import JSONResponse

def register_exception_handlers(app: FastAPI) -> None:
    """Register handlers that sanitize every error response."""

    @app.exception_handler(Exception)
    async def universal_error_handler(request: Request, exc: Exception) -> JSONResponse:
        """Catch-all: never leak internals to the client."""
        # Log everything — this is safe, logs are not exposed externally.
        logger.error(
            "Unhandled error in %s %s: %s",
            request.method,
            request.url.path,
            exc,
            exc_info=True,

            status_code=500,
            content={"error": "An internal error occurred"},
```

## How Each Vulnerability Is Addressed

| Vuln | Fix |
|------|-----|
| **In-memory replay dict** | Postgres `webhook_events` table with `TEXT PRIMARY KEY (event_id)` — survives restarts, scales horizontally, bounded by disk. |
| **TOCTOU race** | Single `INSERT … ON CONFLICT DO UPDATE RETURNING` — no check-then-act gap. Only one winner, guaranteed by the PK constraint. |
| **Error leakage** | `register_exception_handlers()` catches every exception, logs internally, returns `"An internal error occurred"` — zero internals escape. |
| **Parse-before-verify** | `enforce_hmac_before_parse` middleware reads raw body, computes HMAC, rejects — all before FastAPI's body parser runs. |
| **Content-type confusion** | `enforce_content_type` middleware rejects non-JSON/text requests at 415. |
| **Rotation outage** | `get_current_key_or_fallback()` keeps the prior key alive for 60 s during rotation. |
| **No audit trail** | Every event — success, failure, retry — persisted in `webhook_events` with timestamps. |

## Deployment Checklist

- [ ] `DATABASE_URL` set in production env — contains password, not inline creds
- [ ] `WEBHOOK_HMAC_KEY_MATERIAL` contains ≥128-bit random hex key (generate with `openssl rand -hex 32`)
- [ ] `WEBHOOK_HMAC_KEY_ID` identifies the current key for debugging / rotation tracking
- [ ] Migration `001_create_webhook_tables.sql` applied to production Postgres
- [ ] `.env.local` listed in `.gitignore` (never committed)

- [ ] Rate-limiting layer (e.g. Cloudflare, nginx `limit_req`) placed in front of the service

- [ ] Sentry/Bugsnag configured for server-side error reporting (client-visible messages remain generic)
