### Bugs Fixed

| # | File | Issue | Fix |
|---|------|-------|-----|
| 1 | `adapters/test_mocks.py` | `FakePaymentGateway` was missing the `refund()` method required by `PaymentGateway` ABC | Added `refund()` implementation matching the ABC signature |
| 2 | `adapters/stripe_gateway.py` | Hardcoded `source="tok_visa"` test token would crash in production | Removed hardcoded token; validated charge paid status before returning |
| 3 | `adapters/stripe_gateway.py` | `cancel()` only caught `InvalidRequestError` (not accessible at module load time) | Changed to broad catch with debug logging (idempotent cancel semantics) |
| 4 | `adapters/sqlalchemy_repo.py` | Missing `ForeignKey` import — `NameError` on module load | Added `ForeignKey` to sqlalchemy imports |
| 5 | `usecases.py` | `import json` was inside `ProcessWebhook.execute()` instead of module level | Moved to top-level imports alongside `logging` and `Any` |
| 6 | `hub/__init__.py` | Webhook handler caught bare `ValueError`, didn't return HTTP status codes, used `str()` serialization | Uses explicit `SignatureVerificationError`, returns `(dict, status_code)` tuples, uses `json.dumps()`, validates missing signature header |
