    @property

### Valid Transition Graph

| From | To | Event |
|------|-----|-------|
| DRAFT | PENDING | `payment_method_added` |
| PENDING | ACTIVE | `trial_ends` / `charge_succeeded` |
| PENDING | DRAFT | `timeout_expired` (auto-rollback) |
| ACTIVE | PAST_DUE | `payment_failed` |
| PAST_DUE | ACTIVE | `payment_retry_successed` |
| PAST_DUE | CANCELED | `grace_period_expired` / `manual_cancel` |
| Any* | CANCELED | `admin_cancel` |

*\*Except already CANCELED.*

### Behaviors to Prioritize

1. **Core state transitions** — the happy path through the graph
2. **Invalid transition rejection** — e.g. ACTIVE → DRAFT must fail
3. **Domain event emission** — callback receives typed event with metadata
4. **Timeout auto-rollback** — PENDING→DRAFT after configurable grace period
5. **Concurrent safety** — thread-safe transitions preventing race conditions
6. **Final state enforcement** — CANCELED cannot leave its state
