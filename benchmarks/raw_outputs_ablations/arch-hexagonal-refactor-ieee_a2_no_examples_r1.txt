**Key architectural decisions:**

1. **Domain layer is pure Python** — no FastAPI, no SQLAlchemy, no Stripe SDK, no SendGrid. You can unit-test `Order.create()`, `Order.confirm()`, `Order.start_payment()` without any mock infrastructure.

2. **Ports are `Protocol` classes** (structural subtyping) for outgoing dependencies, meaning adapters don't need to `inherit` from anything — they just need the right method signatures. This avoids fragile base class problems.

3. **Composition root uses lazy property accessors** — engines, gateways, and sessions are initialized only when first used, and cached as singletons. `Container.lifespan()` handles startup (`CREATE ALL TABLES`) and shutdown (`DISPOSE POOL`).

4. **Webhook processing mirrors the security-review patterns** already in `payment_webhook_v2.py` — HMAC verification happens at the adapter boundary before the payload reaches the port, atomic `ON CONFLICT DO NOTHING` prevents double-processing, and generic error responses prevent info leakage.
