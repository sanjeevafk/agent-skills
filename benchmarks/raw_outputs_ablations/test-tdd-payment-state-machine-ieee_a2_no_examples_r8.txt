## Subscription State Machine — Implementation Review

### States & Valid Transitions

```
DRAFT ──(pending)──> PENDING ──(activate)──> ACTIVE ──(past_due)──> PAST_DUE ──(resume)──> PENDING
                                                      ↑                           │
                                                      │                           ↓ (cancel)
                                                      │                      CANCELED (sink)
                                                      └───────────────────┘
```

| Transition | From | Target | Action |
|---|---|---|---|
| pending | DRAFT | PENDING | `transition("pending")` |
| activate | PENDING | ACTIVE | `transition("activate")` |
| past_due | ACTIVE | PAST_DUE | `transition("past_due")` |
| resume | PAST_DUE | PENDING | `transition("resume")` |
| cancel | PENDING, PAST_DUE | CANCELED | `transition("cancel")` |

### Key Design Decisions

1. **Strict transition table** — `_TRANSITION_RULES` maps action names to allowed source states; any mismatch raises `InvalidTransitionError`. No escape hatch through the back door.

2. **Thread safety via `threading.RLock`** — The lock wraps both the state check and mutation atomically. Concurrent identical transitions serialize properly (first wins, second gets rejected). Different actions from the same state are also serialized without deadlock.

3. **Auto-cancel timeout** — PENDING subscriptions can be auto-canceled after a 24-hour grace period (`TIMEOUT_GRACE_PERIOD_SECONDS = 86400`). Triggered via `trigger_transition("auto_cancel", now=...)`. Only PENDING state triggers this; ACTIVE and PAST_DUE reject it. Naive datetimes are coerced to UTC.

4. **Event-driven callbacks** — Registered handlers via `on_transition(handler)` receive every `TransitionEvent`. Handlers are isolated (exceptions in one don't affect others), deduplicated (same handler registered once), and removable via `remove_transition_handler()`.

5. **Immutable history** — `history` property returns a shallow copy so external mutation can't corrupt internal state. Initial state seeds the log as a `__init__` event.

6. **Sink state** — CANCELED accepts no outgoing transitions whatsoever.
